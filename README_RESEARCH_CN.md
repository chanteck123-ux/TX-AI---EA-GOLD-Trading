# FxPro GOLD 3-SOP 研究版

**研究版，未批准实盘；四个合格 Champion 均为 NONE。**
此分支基于冻结的 R-C01，不覆盖 V4.00、R-C00、R-C01 或 S-C01。
本轮仅 Codex 开发，仅 FxPro 黄金/USD；USD Hedging 账户。
研究 EA 主文件 `src/GSM_FxPro_RESEARCH.mq5`，MetaEditor 属性版本4.23。

## 策略边界

- Scalping：M5，保留区域/首次回踩/收盘反转/RSI，固定 SL80/TP70课程单位。
  当前 SET 的1课程单位=0.10价格，故价格距离为8/7。无保本、追踪、减仓、尾仓。
  EMA 开关继续独立；本轮 EMA-OFF 的 S-C02 已失败，不默认关闭。
- Intraday：M30，保留实际 SET 的 SL120/TP70（价格12/7），不是源码默认TP240。
  每日次数上限0代表不限合规机会，不代表跳过信号或风险条件。
  `InpIntradayRunner` 默认false；true是独立退出实验，见流程与报告。
- Swing：保留原 D1/H4、H4区域、M30确认及保护参数，仅试验取消每日上限。
- 三策略独立 OR、Magic 和状态。每策略一仓，组合三仓。关闭策略开关只停新仓。

## 风险与使用条件

主测试2000USD，1:100，每单计划风险不超过1%，合计初始风险不超过3%。
500USD单独作适配性诊断，不建议通过增加资金或风险来追逐回测成绩。
按实际品种规格/SL/费用向下取整手数；最小手数超预算则跳过。
费用每标准手7USD是研究预算估计，不是对券商费率的设置或承诺。
尾仓另预留一次入场和最多两次出场的货币精度舍入费用。
未知仓位、挂单、执行未决或恢复失败，均保守阻止新开仓。
保本后仍按剩余手数保留初始风险预算。滑点、跳空、费用可令实际亏损超过计划。
真实账户被源码拒绝；本次没有开启实盘或自动改变账户杠杆。

## 编译与回测

交付目录中的 MQ5 和自有 MQH 放在同一 EA 源码目录。
标准 `#include <Trade/Trade.mqh>` 由 MT5 的 `MQL5/Include/Trade` 标准库提供。
如果标准库缺失，应修复 FxPro MT5/MetaEditor 安装，不能删掉 include 假装修复。
已编译 EX5 运行时不需要另加载源码依赖。编译证据记录所有实际依赖哈希。

策略测试器选择 GOLD（或本账户实际黄金/USD名称）、真实 Tick、USD、1:100，
按各引擎 SET 和配置中的日期/资金运行。不要把修改后的 SET 成绩冒充已有报告。
测试原始 SET 保持面板关闭以降低回测开销；图表展示开关仍保留在 EA 参数中。
报告中的0ms与10/25/50ms固定延迟、原生随机延迟分别记录。
原生随机延迟不等于随机10-50ms。

## 证据规则

净利润 -> 最大相对净值回撤 -> PF -> 完整持仓数 -> 胜率 -> 拒单。
DD>30%否决，15%-30%人工复核；净利润/最大净值回撤金额>3；每策略及组合>100笔。
按持仓标识汇总全部费用、成交和分批退出；部分平仓不增加交易笔数。
保留 MT5 原生 PF/Recovery，但完整持仓净值口径另算；口径不一致明确标注。
已看过的2026历史区间不是 untouched OOS，未来6个月验证仍待完成。
成本后处理压力只是固定成交路径估计，不能替代改变行情成本后的真实重测。

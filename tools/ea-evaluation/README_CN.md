# EA 综合评估工具表 v1.0

2026-10-03。用户要求提供综合评估工具表。本目录交付可填写、含公式的 Excel 模板，不含任何 EA 实际成绩。

[下载 Excel 工具表](GSM_EA_综合评估工具表_v1.0.xlsx)

| 工作页 | 用途 |
| --- | --- |
| 综合评估 | 当前最佳与三个候选并列；报告原值、五项分数、加权贡献、差额、收益结构、手数与提款情景 |
| 评分政策 | 同条件比较组、适用项目、事前登记、七个正式锚点、固定权重与来源 |
| 策略与验证 | 用途／位置／触发、指标组合、变更原因、编译与回测、独立验证、证据和下一轮 |

## 使用

1. 每一批另存一份，先填写“评分政策”的黄色格。选择适用项目，冻结比较组、资金、时段、风险、成本及执行条件，再登记七个正式评分锚点及理由。初始全部留空，不将示例数字当正式目标。
2. 在“综合评估”填写 candidate_id、run_id、比较组和报告数据。D列是人工指定的有证据的当前最佳，E至G列为三个候选。确认同条件、交易聚合和成本口径后，公式自动计算。不同区间、风险档或成本压力场景另存表，不混排。
3. 原始回撤和保证金百分数字段输入 `10` 表示 `10%`；总评分和胜率由公式输出百分比。Gross Loss、平均亏损和摩擦费用使用正的绝对金额。
4. 在“策略与验证”填写同一列的设计、证据和研究结论。每次调整对应新回测；源码变化需新编译，参数变化可核验复用同一 EX5。保留失败表与最佳恢复点。超过三个候选时另存同批续表并保留同一基准和政策，勿直接扩列后假设公式自动延伸。

## 自动计算与边界

- 权重为净利润35%、净值回撤25%、原生PF20%、完整交易数10%、每往返标准手成本10%。固定锚点线性映射并封顶，不用本批候选的最大最小值抬分。80%表示80/100，不是胜率或自动通过线。
- 正式锚点未填齐时显示 `N/A / SCORE_TARGETS_UNSET`；无效锚点、未冻结政策、缺失数据、重复身份、无交易、无配对手数或未核对成本不能得到可比总分。已知分项仍可以显示诊断值。
- 原生 PF 与 `Gross Profit / abs(Gross Loss)` 的一致性容差为 `max(0.005, 比率×0.000001)`，用于兼容显示舍入；超差需检查报告原值，不自动用重算值替换原生值。分母零、哨兵或不一致值均不得满分。精度不同的报告需要先核对真实原值。
- 成本为配对完成量对应的非负摩擦费用，分别填佣金／实际费用、负隔夜费、非重叠点差及不利滑点。费用全部明确且完成配对后才除以 RT_lots。开1手平1手计1往返手。返佣、正隔夜和有利滑点另列；诊断费用不从已经扣成本的净利再扣一次。
- 最大净值DD金额、金额DD对应百分比和全程最大相对DD分别保存。评分使用全程最大相对DD。原生Recovery与Equity Recovery分开；原生Recovery核对仍需人工检查报告和余额DD。
- **适用项目默认未选定。** 仅选择“GSM旧版升级”时启用该项目主区间数值初筛：DD目标15%、超过30%拒绝、完整交易至少101、原生Recovery严格大于3。其他项目显示“核对所选项目标准”，不自动套用这些数值；OOS样本也不能套主区间数量线。初筛不能代替完整§11验收。
- 验证状态来自填写者录入的状态与证据入口，工具不自动读取或认证报告，不自动选Champion。夏普、统计显著性、稳定性、新闻和关联市场等保留为复核事项，不偷偷加减分。
- 提款后权益、保证金水平和储备差额只是同一时点静态算式，不是路径模拟、可提款额建议、券商许可或不爆仓保证。连续亏损、压力、重启及提款后的持续运作仍要实际验证。
- 模板无宏、无 MT5 连接、不修改 EA 或实盘。黄色格为输入，其他格为公式或固定说明；未设置密码保护，勿覆盖公式和固定权重。

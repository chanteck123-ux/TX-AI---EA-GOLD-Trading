# 资料管理决定记录

## 2026-09-10：GitHub 作为记忆书与图书馆

用户已明确授权 Codex 自己安排整理，不需要逐项确认。落实为：自主分类、索引、维护当前状态、保留研究经验、按项目流程提交同步；资料和研究顺序由 Codex 根据证据决定。

本轮采用保留原路径并增加导航的整理方式。目录、分支与固定提交形成入口，源码、编译成品、参数和原始证据继续位于其原有位置。相同内容标记关系，保留测试/交付所需副本。

新知识先有来源和适用条件，研究结果标明实际验证范围；历史错误状态添加有日期的新说明，原始记录保留以便追溯。每次任务先读记忆、核对变化，结束后写入新事实与下一步。

公开仓库的目录只包含公开资料；含私有仓库信息的跨仓库总目录在私有仓库维护。外部参考仓库按实际读取权限学习，不复制未知许可的源码或把别人的仓库当作自有项目。

本次文件分类与路径验证不产生新的策略测试结果，也不合并、晋级现有研究 PR。后续研究继续遵循用户已确认的 SOP、实验与冻结规则。

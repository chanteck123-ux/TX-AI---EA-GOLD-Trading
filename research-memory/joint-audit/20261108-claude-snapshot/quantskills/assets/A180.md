# A180 skill-refinancing-monitor — Claude 全文审核（2026-11-05）

## P0216 尾段（FULL_READ；FILES 1817–1819：portable-loader、README.en、README）
- 定位：A 股再融资（定增和配股）事件监控，覆盖进程漏斗、稀释比例、发行价相对现价的折价或破发、配股认购缺口和行业分布。中英文 README 一致（英文版较短）。
- **问题**：
  1. **破发判断没有考虑除权**：用"发行价对比 get_stock_daily 现价"，现价低于发行价即判为破发。但发行之后若有送转或分红，现价应与**除权调整后的发行价**比较，否则会把除权造成的价格下降误判为破发。A158 也指出 get_stock_daily 返回的是未复权价格。
  2. 依赖 A158 的 get_stock_private_placement 和 get_stock_allotment，A158 中事件类数据的 info_date 存在 PIT 问题，"窗口内新增事件"的时间口径可能不准确。
  3. 稀释比例以 get_share_float 的总股本为分母，没有说明取哪个时点的股本（公告时还是当前），口径会随时间漂移。
- 优点：预案不等于已募资；定增与配股分开列示；跨进程先去重再计数；明确标注快照日；空数据时如实报告。
- refinancing-playbook 和 SKILL 在后续包中，待读。对 V1.2 没有直接关系。

## P0217 前段（FULL_READ；FILES 1820–1821：refinancing-playbook、SKILL）
- **"折价"的定义混淆了两个时点**：playbook 把折价定义为 `(最新收盘价 − 发行价)/最新收盘价`，用的是**当前**收盘价。通常所说的定增折价，是**定价日或定价基准日**的价格与发行价之差；用当前价算出来的，其实是"发行后至今的价格表现"，与"破发"只是同一件事的两种说法。两个指标因此并不独立。
- 稀释比例的分母写作"事件前总股本"，但 `get_share_float` 返回的是查询时点的股本，SKILL 没有说明怎么取得事件前的股本（与上一段第 3 点相同）。
- 优点：
  - 预案阶段的字段常常为 None，此时标为"待披露"，绝不填补；
  - 去重键有具体说明（symbol 加预案，没有预案 id 时用"symbol + 公告簇 + 发行类型"）；
  - 配股有自己的进程（预案 → 核准 → 股权登记 → 除权）；
  - 报告由 validate_report.py 做结构校验；
  - 措辞克制。

## A180 结论
- 事件处理规则（分列、去重、预案与实施的区分、空数据处理）严谨。但定价分析有两个口径错误：①破发判断没有对发行价做除权调整；②"折价"用的是当前价，实际变成了破发的另一种表述。对 V1.2 没有直接关系。scripts 未审。

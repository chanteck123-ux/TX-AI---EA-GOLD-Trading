## P0106 部分（FILE 1042–1047 全文：agents/portable-loader、README.en、README、references/agent-integration、fundamental_ops、requirements.txt）

要点：
- 从 PandaData 拉取财报、预计算因子、业绩预告和股东/回购数据，构建 PIT 基本面面板（80 个字段，7 个信号族）；
- LLM 从文档、URL 或自然语言生成 alpha 表达式，经验证器校验（失败最多重试 5 次），自动输出可回测的日频 CSV；
- PIT 规则：财报按"披露日 + pit_lag_days(1)"生效，含重述；预告与股东数据按公告日加滞后；
- A 股 YTD 累计口径下：TTM = 上年 FY + 本年 YTD − 上年同期 YTD；YoY 为 YTD 对 YTD。

独立发现（静态阅读，未运行）：
1. **自定义特征示例与 YTD 口径冲突**：示例 `fcf_yield_mrq = (ocf_mrq1 × 4) / mktcap`，描述为"最新单季 OCF 年化"。但文档声明 A 股报表项为年内累计（YTD），`*_mrq1` 是最新一期报告值。若 `ocf_mrq1` 是 YTD 累计值，×4 只在 Q1 报告期正确；Q2、Q3、Q4 会分别高估约 2 倍、3 倍、4 倍，并随报告季呈锯齿。文档没有说明 mrq 字段是单季还是 YTD。
2. **"预计算因子按构造即 PIT"未经验证**：`get_factor` 的 `ratio_*`、`cfd_*` 等被称为"每个值都是查询日当时的值"。这是对供应商的断言，文档没有核验方法（例如是否使用了后来重述的财报）。
3. **LLM 自定义算子可注入代码**：`new_operator` 允许在 `operators.json` 中追加带 `numpy_impl` 的条目，"验证器与生成器自动加载，无需改代码"，相当于执行 LLM 提供的代码字符串。沙箱未说明。
4. **引用可能被编造**：规则要求每个 alpha 带 `source`（APA/MLA）与 DOI/arXiv 链接，但没有引用核验步骤。LLM 可能生成看似合理但不存在的文献（同 A081、A091 的归属核验问题）。
5. **截面中位数填充**：`fillna_median` 用当日截面中位数填补稀疏基本面字段，会把"未披露或亏损不适用"的公司拉到中性位置，可能掩盖覆盖偏差。文档只建议在低覆盖时使用，没有要求报告填充比例。
6. 默认日频区间 2024-01-01 至 2025-08-01（约 1.6 年），用于基本面因子评估过短；`--doc URL` 会联网抓取任意 URL 并解析 PDF（PyPDF2），属于外部内容处理面。

与黄金 EA 的关系：本资产为 A 股基本面，与 XAUUSD 无直接关系。可借鉴的是 PIT 生效规则（"披露时点 + 滞后"、"重述只在发布后可见"），可对应 NR08 宏观数据（如 CPI、NFP 的首发值与修订值需按发布时点区分，修订值不得回填）。不引入代码。

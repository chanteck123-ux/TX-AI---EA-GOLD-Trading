# A131 skill-llm-rag-financial-qa（A 股财报/公告 RAG 问答，社区项目 #42，GPL-3.0-only）— 文本审核

## P0135 部分（FILE 1380 portable-loader、1381 README.en 全文）

要点：
- 三路路由：
  - 数值问题走 `get_fina_reports`，按公告日点时取数，用 pandas 精确计算；数字"永不进入检索层"；
  - 文本问题走纯 Python BM25 + 元数据过滤 + RRF；
  - 原文全文仅限官方渠道，默认关闭。
- 每条结论都带四段式引用 [api|field|date|symbol]，增速引用中写明算式；语料不覆盖时返回 `insufficient_evidence`。
- 默认不生成成稿，只返回 evidence、citations 和 answer_contract，由调用方 agent 撰写。

初步发现：
1. "数字不进检索、不让模型心算"是有效的反幻觉设计，PIT 优先使用原始披露而不是后续重述。
2. 示例数值（宁德时代 2024Q4 归母净利润增速 +15.01%，即 5.074e10 ÷ 4.412e10）：两数相除确实约等于 1.150，**算式自洽，但原始财报数值未核实**。
3. 文档自称"原任务规格中的 3 个接口在最新 187 个方法中不存在"，因此按实际可用的 7 个字段重新设计语料。接口清单**未核实**。
4. 拒答分两档：硬拒答（代码不在语料中，由引擎保证）与主题不覆盖（由调用方按契约声明）。后者依赖调用方自律，引擎不保证。
5. 示例语料只有 154 篇文档、11 只股票，覆盖面很小。
6. Quick start 示例 `export PANDA_USERNAME=<phone>`：凭证放在环境变量，属文档示例，不含真实值。

待续：P0136 读取 README、SKILL、开发产物 api_guide / quality_evidence / SKILL、生产产物 SKILL。

## P0136 补读（FILE 1382 README、1383 SKILL、1384 开发产物/api_guide、1385 quality_evidence、1386 开发产物/SKILL、1387 生产产物/SKILL 全文）

补充要点：
- 数字路调用 `get_fina_reports(..., is_latest=False)`，返回每季全部版本，在 qa 层去重：先取 if_adjusted==0（原始公告），其中再取最新。
- 文本路底仓：7 个来源接口，doc_id = `source_api:symbol:info_date:seq`，按 doc_id 去重时 keep=last。
- 抓取速率与配额：限速 1 秒、每题最多抓 10 页；全量拉取按 31 天分段，遇错切 7 天重试。
- 质量证据记录了 9 项缺陷修复，较重要的有：
  - 增速被当成绝对值回答；
  - PIT 取到了重述版本；
  - "2025年报"被静默取成最新一季（方向都反了）；
  - 跨公司查询静默只答一家。

发现（续）：
7. **修复后文档没有同步**：
   - quality_evidence 缺陷 5 说 PIT 已改为"原始优先"，宁德 2024Q4 的引用应落在 **20250315**（原始年报）；
   - 但 README、根 SKILL、开发产物 SKILL 与 api_guide 第二节仍以 **20260310**（重述日）作为示例和"真机实测结论"。
   - 同理，quality_evidence 第四节第 2 条仍写"年报/中报未映射时回退最新季度"，而缺陷 6 已新增 resolve_quarter 修复。
   - 文档内部存在新旧两种状态，以哪一份为准**未核实**（scripts 不在计划内）。
8. **历史回放的 as-of 过滤缺失**：
   - 文档称"历史回放与实时问答口径一致、不偷看未来公告"；
   - 但数字路固定用 `date="20261231"` 取全部版本，去重只按 if_adjusted 与公告日先后，**没有"公告日 ≤ 决策日"的过滤**；
   - 若按历史某日回放，同季的原始年报可能在决策日之后才公告，因此会前视。
   - 文档声明的"可作 Alpha 因子特征"在回测用途下不成立，除非另加 as-of 截断（静态推导，未读代码）。
9. 文本路的 info_date 是公告日，可用 date_range 截断，口径比数字路清楚。
10. "23/23 通过" 与 quality_evidence 列出的 18 条及另述 5 条大致对应，**未运行核实**。
11. quality_evidence 写入了维护者本机的绝对路径（含用户名）与凭证文件位置，属于泄露个人环境信息的轻微问题；本审核不转录。
12. 负基数同比"按符号处理"没有给出公式（例如基数为负时分母是否取绝对值），口径不明。
13. 硬拒答只覆盖"代码不在底仓"；"主题不覆盖"由调用方 LLM 判定，文档如实承认，属诚实边界。

**A131 结论**：文本全部覆盖（共 8 份全文）。"数字不进检索层"和"四段式引用"是值得参考的反幻觉设计；但修复后文档未同步、数字路缺少 as-of 决策日截断，不能直接用于历史回测特征。与黄金 EA 无直接关系（A 股财报），**未实现**。

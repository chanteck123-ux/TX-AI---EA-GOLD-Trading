# A154 skill-pair-correlation（双标的相关性、对冲 beta、价差 z）— 文本审核

范围：P0157 FILE 1609 portable-loader、1610 examples/output/pair_correlation.txt、1611 README.en、1612 README、1613 references/example_output、1614 SKILL.md 全文。

要点：
- 先按共同交易日 inner-join 两条腿再计算统计量；相关系数取全窗口及近 20/60 日；beta = cov(ra, rb)/var(rb)；spread = ln(Pa) − beta·ln(Pb)，在窗口内计算 z 值；分母为 0 时返回 null。

发现：
1. **"对冲手数"的解读错误**：示例写"对冲 beta 0.884 → **每 1 手 A 约用 0.884 手 B 对冲**"。收益率回归得到的 beta 是**市值（名义金额）对冲比例**，不是手数比例。A=402、B=78.5，两边每手都是 100 股（Claude 所知，需核实），按名义金额应为 0.884 × 402/78.5 ≈ 4.5 手 B；按示例操作只对冲了约 0.884 × 78.5/402 ≈ **17%** 的敞口。
2. **beta 口径错配**：价差使用的是"对数价格水平"，而 beta 来自"日收益率回归"，两者并不对应同一个协整系数。另外，没有任何协整或平稳性检验（如 ADF），"z < −2 均值回归"的前提缺乏依据。
3. **z 值有样本内偏差**：beta 在全窗口估计（包括 z 窗口本身），再用同一段数据计算 z 值，均值和标准差都是样本内数值。
4. **跨市场配对存在非同步收盘**：README 以 0700.HK 对 BABA.NB 作为可行例子，但港股收盘早于美股开盘，同一日期的收益并不同步，相关系数会被压低，并产生滞后结构；文档只提到"样本会缩小"。
5. **示例当作真实结论呈现，并含交易提示**：示例数值取自 schema（已注明），但"一句话解读"和 `interpretation_hint` 写了"long A / short B 的均值回复 setup"，属于交易提示性表述。示例内部核算：402/78.5 = 5.121 ✓。

**A154 结论**：文本全部覆盖（共 6 份全文）。日期对齐做得对，但对冲手数的解读错误、beta 与价差口径错配、没有协整检验，**不能作为配对交易依据**。与 EA 的关系：可作为 XAUUSD 与 DXY 等关联市场（NR07）的反面提醒——相关不等于协整，跨时区收盘不同步会造成偏差。**未实现**。

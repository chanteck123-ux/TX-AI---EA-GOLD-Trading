## P0121 补读（FILE 1238 README.md、1239 consensus-playbook、1240 SKILL.md 全文）

中英文 README 逐段对照，内容等价（中文版多出 Codex/Cursor 安装方法与社群二维码）。

独立发现：
1. **"修订 = 基础值 − 后缀值"的语义未经证实**：playbook 假定 `buy_num_week`、`high_week` 等后缀字段表示"一周前的值"，所以差值即修订。但后缀也可能表示"本周新增或变化量"，或"近一周窗口的统计"。文档只要求"在 pandadata-api 中确认后缀是否存在"，没有要求确认**后缀的语义**。若语义理解错误，修订方向与大小都会错。
2. **与 A113 矛盾，数据日无法标注**：
   - A112 要求每个一致预期标注"数据日"；
   - 同一组接口的姊妹资产 A113 明确写"当前聚合目标价/评级**没有可用的具体业务日期**"，只能标为"最新可用快照"；
   - 因此 A112 报告中的"数据日"实际上很可能只是抓取日。目标价上行空间 = 目标价（日期未知）/ 现价（日期已知）− 1，存在时点错配。
3. **两个目标价来源**：recommendation 族的 mean/median 与 ncycl 族的 `TP` 都可以用来计算上行空间。规则只要求"注明使用的是哪个"，没有要求固定口径；做篮子排名时可能择优。
4. "一致预期偏多 + 价量分位仍低时更有意义"是一条未经验证的经验搭配，被写在定位说明里。
5. `validation_level: runnable`，但 validate_report.py 只检查格式（章节、来源标注、免责声明），不检查数值正确性。

## P0227 尾段与 P0228 前段（FULL_READ；FILES 1943–1946、1948；1939–1942 agents 适配器和 1947 requirements 为 HASH_REUSE，与 calendar-anomaly-scanner 同哈希，已审过）
- 定位：截面信号的稳定性诊断，包括 lag 秩自相关与半衰期、Top 和 Bottom 篮的 Jaccard、Kendall tau-b、五分位迁移矩阵、年化成本拖累，最后给出 STABLE/MIXED/UNSTABLE 的结论。中英文 README 一致。
- **公式问题（已验算）**：单向换手的代理值取 `1 − Jaccard(top)`，但 Jaccard = |A∩B|/|A∪B| 并不等于换出比例。设两期 Top 篮大小都是 k、重叠 x 只，实际换手 = 1 − x/k，而 1 − J = 1 − x/(2k − x)。以重叠一半为例，实际换手是 **0.50**，代理值是 **0.667**，**高估约 33%**；重叠越少，高估越接近 2 倍的上限。年化成本拖累 = 换手 × 2 × cost_bps × (252/rebalance_days)，会把这个偏差一起放大。文档只说这是"研究代理"，没有指出它系统性偏高。
- 其他：STABLE/MIXED/UNSTABLE 的阈值没有在文档中给出；半衰期用指数拟合，秩自相关衰减不一定呈指数形态；"由半衰期推荐调仓频率"的规则也没有写明。
- 优点：明确说明稳定不等于有效、可交易或未来盈利；成本按实际调仓间隔年化；不联网。

## A192 结论
- 诊断思路有用，但换手代理的公式系统性高估，阈值没有公开。对 V1.2 的指标稳定性检查，可以借鉴"秩自相关、半衰期加成本拖累"的思路，但换手必须按实际换出比例 1 − |A∩B|/k 计算。脚本未审。

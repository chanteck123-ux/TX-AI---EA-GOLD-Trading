# A030 skill-alpha-f8-family-main-divergence（全文审核笔记）
- 读取（P0032）：AGENTS.md、CLAUDE.md、HERMES.md、OPENCLAW.md、README(.md, .en.md)、根目录 SKILL.md、开发版 SKILL.md 与 references/data_guide.md、production/SKILL.md。
- 内容："家人"席位（东方财富、徽商、平安）与"主力"席位（永安、中信、国泰君安）的净仓位分歧，按主力一致性加权：
  - raw = (major_ratio − family_ratio) × clip(2·consistency − 1, 0, 1)
  - denom = Σ|net| + 2·min(family_bull, family_bear)
  - 截面百分位前 10% 买入、后 10% 卖出。
- 好的做法：major_total = 0（无法计算一致性）时剔除该品种，而不是当作 0；buy/sell 的分位门槛对称（与 A28 不同）。
- **独立发现**：
  - ①**分母的口径说明含糊**：family_bull 和 family_bear 指的是 3 家"家人"席位分别的净多和净空合计，加回 2·min 是为了抵消家人内部的多空对冲；但 Σ|net| 本来就已经按席位分别取绝对值，再加回 2·min 等于把内部对冲量**重复计入**分母。文档没有解释为什么需要这样做。
  - ②**家人缺失当作 0**（同 A29），而主力缺失则剔除——两类席位缺失的处理不一致。
  - ③**席位名单硬编码、按字符串精确匹配**：期货公司合并或更名后会静默失配，validate 只检查"至少出现一家"。（例如"国泰君安"相关机构在 2025 年前后有合并更名的报道，**本次未核实**，列为待核实风险。）
  - ④用到了 open_interest 和 start_delivery_date 字段，但公式里没有出现——可能用于主力切换或临近交割的过滤，文档没有说明。
  - ⑤研究口径与 A28/A29 相同（t 收盘 → t+1 收盘），需要以可交易口径为准。
- 对黄金 EA：①对象名单（经纪商、数据源、品种代码）不能只靠硬编码字符串精确匹配，要有映射表和"出现率骤降"告警；②两类输入的缺失处理必须一致，或者明确说明为什么不一致。

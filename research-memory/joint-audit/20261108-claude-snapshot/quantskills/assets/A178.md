## P0216 前段（FULL_READ；FILES 1801–1811：README、collaboration-contract、data-snapshot-policy、lookahead-audit-boundary、manifest-contract、overlap-review、scan-and-confirm、source_boundary、SKILL、两个 fixture report）
- 中英文 README 一致。规则清晰：
  - **观测时间不等于可得时间**；数据源不提供发布或修订元数据时，相关检查记为 not_checked 或 insufficient_metadata；
  - 出现高风险发现时，不能给出 verified 结论，并要标记 `result_validity: compromised`；
  - **缺失的证据绝不能当作隐含通过**；
  - 外部数据不可用或快照不一致时，复现结果记为 failed，**不能用替代数据冒充复现成功**；
  - 不会自动覆盖旧的 manifest；
  - overlap-review 坦承只检查了公开仓库，不能证明整个组织范围内没有重叠。
- fixture 中的冲突指标（Sharpe 1.20 对 1.30）用于测试"冲突值不得悄悄二选一"。
- 是否真的能做到，只能看 scripts 和 schemas，它们未审。

# A177 skill-quant-research — Claude 全文审核（2026-11-05）

## P0215 中段（FULL_READ；FILES 1788–1795：portable-loader、CLAUDE.md、README.en、README、data-contract、risk-and-reporting、statistical-validation、SKILL）
- 定位：把研究问题转成可证伪的假设、可复现的实验和有边界的报告。中英文 README 一致。
- **方法质量高，并且与本项目 §11.1 和 §11.9 的规则高度吻合**：
  1. 数据契约区分可得时间与经济事件时间，as-of join 带确定性的平局规则，并要加入**故意写入未来日期的负向测试**；历史成分股必须用当时的成员名单；连续期货要写明换月规则（A160 和 A169 的缺陷正是违反了这一条）。
  2. 研究分 discovery / selection / confirmation / monitoring 四阶段，确认集只能评估一次；标签重叠时做 purge 和 embargo；walk-forward 时，scaler、imputer 和特征选择都必须在训练窗口内拟合。
  3. 回报有序列相关、异方差和厚尾，要用块或平稳 bootstrap，报告有效样本量；**Sharpe 必须写明频率、年化因子、算术或几何口径、无风险利率处理，以及是否做序列相关调整**，与本项目"夏普只作辅助诊断，先核对频率、收益序列、无风险利率和年化方式"的规则一致。
  4. 多重检验：要登记搜索空间和被丢弃的试验，列出 FDR、White RC、Hansen SPA、PBO、Deflated Sharpe，并说明"校正不是保证"。
  5. 成本压力至少测 2 倍和 3 倍的价差、滑点和冲击，执行延迟 1 根或更多 K 线，包含跳空和停牌日。
  6. 决策标签分为 reject / exploratory / promising but unvalidated / research-ready / production-candidate，"绝不说回测证明了未来收益"。
- 缺口：
  - (a) 以股票截面研究为主，单品种时序策略（如 GOLD）的部分较薄，只有"signal level、position mapping、forecast error、按市场状态的收益贡献"一句；
  - (b) 没有给出 PBO 或 DSR 的计算细节，只列了名称；
  - (c) scripts/validate_quant_data.py 未审。

## P0104 补读（FILE 1014 README.en.md、1015 README.md、1016 references/input_schema.md 全文）

两个 README 双语逐段对照完毕，内容基本等价。差异有两处：
- EN 的相对路径解析顺序多写了"then the current working directory"；
- ZH 版"与其它 Skill 的关系"表只列本仓库，EN 版列出 4 个关联 skill。

论文来源写明：Duan, Zhang, Li, FactorMAD, ICAIF '25, pp.605–613, DOI 10.1145/3768292.3770377，并声明非官方代码。资料自述，未外部核实。

要点：
- 两个 LLM Agent 辩论、批评、修正，产出可执行 Python 因子函数；
- 做代码检查和轻量 Pearson IC/RankIC/ICIR 筛选；
- 设有样本内与样本外区间字段，`hybrid` 模式要求两种 ICIR 都达标且样本内方向一致；
- 可选本地因子库，接受的因子写入库并作为后续 few-shot。

基本面 PIT 语义较规范：
- manifest 必须声明 `future_backfill=false`；
- `_ytd_ann` 不是 TTM；
- 禁止负 shift/diff/pct_change、bfill、居中滚动；
- 字段覆盖筛选不得使用封存的样本外区间。

独立发现（静态阅读，未运行）：
3. **样本外区间的用途表述不一致**：README 写 `outsample_time_range` "用于计算 O-IC/O-ICIR"，因子记录也含 O-* 指标；input_schema 写"记录供后续验证参考"。文档没有说明：辩论 Agent 在多轮修正中能否看到 O-* 指标；`best_factor` 排序是否只用样本内。若 O-* 进入辩论反馈或排序，样本外就被污染。需看 runtime 源码（未核查）。
4. **跨运行的累积选择**：因子库只保存"通过轻量筛选"的因子（invalid/similar 不入库），并作为后续运行的 few-shot，相当于把历次样本内胜者喂给下一代生成，形成跨运行的选择链。没有累计试验数记录（库中只有幸存者，失败者不入库）。
5. **接受阈值偏低且口径不明**：推荐 `icir_threshold=0.05`、`rank_icir_threshold=0.05`，未说明是原始期 ICIR 还是年化 ICIR。若为原始值，阈值极低，几乎任何弱信号都能被接受。
6. **标签口径**：
   - 默认标签 `price=vwap, span=10`，`span` 按"行/期"计；停牌缺行时，期限会被拉长（同 decay 与 drift 脚本）。
   - 缺 amount 时 amount=close×volume，进而 vwap = amount/volume = close，vwap 标签与 vwap 因子会无提示地退化为 close（同 A072、A088）。
7. **执行 LLM 生成的代码**：候选是任意 Python 函数，由 runtime 执行做检查与评估，文档未说明沙箱。
8. **凭证与费用**：真实运行必须提供 OpenAI 兼容 key，回退读取通用 `OPENAI_API_KEY`（作用域过宽，见发现 1），会产生 LLM 费用（`llm_fee` 字段）。按本次授权，不调用、不读取凭证。
9. 小问题：Registry 元数据 "Status: `activate`" 拼写错误，与头部 `status: active` 不一致。

## P0105 补读（FILE 1017–1021 全文：references/output_contract、source_boundary、validation_notes、requirements.txt、SKILL.md）

补充要点：
- output_contract 明确 IC/ICIR 等指标使用样本内区间，O-* 使用样本外区间；主结果保存发给辩论 Agent 的完整 `factor_requirement`，便于审计提示内容。
- validation_notes 的内部检查包括：
  - 生成代码中禁止 import；
  - 静态拒绝负 shift、bfill、居中滚动；
  - "**截短日期重算**"的前瞻信号检查；
  - 跨标的尺度可比、标的顺序稳定性。
- 文档承认静态分析不能证明没有间接前瞻路径，轻量 IC 指标也可能过拟合。

结论与发现更新：
- 发现 3 收窄：O-* 指标确在样本外区间计算并写入每条记录，但文档仍未说明辩论 Agent 在修正轮次能否看到 O-* 指标。只要能看到，就构成样本外泄漏，需源码核实（未核查）。
- **"截短日期重算"是可迁移的方法**：用截至 t 的数据重算 t 时刻的信号，与用全量数据算出的 t 时刻值比较，不一致即存在前瞻。这可以直接用于本项目 MQL5 指标与 LEAN 信号的前瞻自检（作为测试设计参考，不引入代码）。
- requirements 含 `openai>=1.0`。按本次授权不安装、不调用。

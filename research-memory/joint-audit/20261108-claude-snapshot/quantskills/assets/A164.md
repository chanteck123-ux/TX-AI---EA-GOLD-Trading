# A164 skill-portfolio-checkup — Claude 全文审核（2026-11-05）

## P0205 后段（FULL_READ；FILES 1707–1708：portable-loader、README.en）
- 定位：A 股持仓组合体检，串联 15 个以上的 PandaData 接口，分 5 个模块：结构与集中度/HHI、加权估值与质量、风险暴露汇总（解禁、质押、减持、ST）、基准偏离、资金面叠加。输出固定 8 段报告。
- 优点：先声明权重口径；分母缺失时报告覆盖权重，部分覆盖不冒充全覆盖；明确 get_stock_pledge_stat 是市场级统计，不能当个股值；指出 get_stock_detail 不返回市值，替代估算必须标注。
- 初步关注点：
  - (a) 风险分级阈值（解禁 15%、质押 15%、减持 10%）是固定经验值，没有依据；
  - (b) "90 天解禁"依赖 A158 的 restricted_list，而 A158 中事件类数据的 info_date 存在 PIT 问题；
  - (c) 加权 PE/PB 的聚合方式（算术平均还是调和平均，负 PE 怎么处理）待在 checkup-guide 中核实；
  - (d) portfolio.json 示例包含真实上市公司名称（属公开信息）。
- 中文 README、checkup-guide、SKILL 和 portfolio.json 待读（P0206）。

## P0206 前段（FULL_READ；FILES 1709–1711：README（中文）、checkup-guide、SKILL）
- 中英文 README 逐段对照，内容一致。唯一差异是示例中宁德时代的权重：README 为 0.14，SKILL 为 0.12，示例不一致（小问题）。
- **checkup-guide 质量较高**：
  - HHI 写明了两种刻度，并给出 N_eff=1/HHI；
  - PE 聚合推荐调和平均（按盈利收益率加权），负 PE 必须标注或剔除；
  - 风险敞口以覆盖权重为分母；
  - pledge 只取未解押记录的最新值；
  - ST 状态有撤销行时清除；
  - 评分在覆盖率低时封顶，并重新归一化。
- **问题**：
  1. **区间收益和相关性是回溯计算**：`r_p(t)=Σ w_i·r_i(t)` 用**当前**持仓权重套回过去一年，得到的是今天这份持仓的假想回溯，不是组合的真实历史表现，带有事后选股偏差。文档没有说明这一点。
  2. 收益由 get_stock_daily 的 close 计算简单收益，没有提到复权（与 A163 的问题相同）。
  3. 默认事件窗口有两种说法：Default Scope 写"未来 12 个月"，敞口阈值用 90 天，两者并存。
  4. 风险阈值（15%、5%、50% 质押等）以及评分权重 25/30/15/20/10 都是主观设定，文档也承认"rubric, not a verdict"。
  5. `get_fina_reports` 设 is_latest=True 获取当前快照，用于"体检"本身没问题，但不能用于历史回测（A158 已指出）。
  6. SKILL 声称"Methods below are verified against the Pandadata method index"，但 frontmatter 是 `status: draft`、`validation_level: rules-only`，属规则文档，没有可运行的实现。
- 优点：强制使用固定免责声明句；行动建议只做风险提示；与 dossier、event-risk-alert 的分工清楚。

## A164 结论
- 是一套规则型的组合体检规范，口径与覆盖率处理严谨。主要缺陷是"当前持仓回溯收益"有事后偏差，以及收益未复权。没有实现代码，阈值是主观设定。对 V1.2 价值有限，只有"覆盖权重与降级说明"这条可以作为报告规范参考。portfolio.json 的示例内容未在本清单内（不是 .md/.txt 文件，未审）。

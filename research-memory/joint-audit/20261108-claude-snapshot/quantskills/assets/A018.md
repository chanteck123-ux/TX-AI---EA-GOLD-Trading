# A018 skill-a-share-market-risk-radar（全文审核笔记）
- 读取（P0021）：agents/portable-loader.md、CLAUDE.md、README(.md, .en.md)、SKILL.md。
- 内容：从 8 个维度扫描 A 股（宏观、融资、估值、趋势、资金流、轮动、个股事件、技术面），输出 RED/YELLOW/GREEN/UNKNOWN；维护者 cikeqi，version 1.0.1，GPL-3.0-only。
- **核心规则（高价值，且与 A002 形成对照）**：`UNKNOWN` = 数据不足或接口失败，**不得当作低风险处理**；`GREEN` 只代表已覆盖的维度未见共振，不代表未来无风险；报告必须区分观测事实、代理指标和推断。A002 曾把缺失数据计为 95 分，这里是正确的反例。
- 自述局限：评分以经验阈值和信号计数为主，未经历史回测和样本外检验；"市场走势"用指数涨跌代理跌停家数；依赖或凭证缺失时停止，不自动安装、不自动登录。（与 A17 自动安装的做法相反；两种都可以，关键是写明。）
- 待核：阈值和计数逻辑在 scripts/*.py 中，不在本次文本清单内，**未做静态核查、未运行**。
- 对黄金 EA：①DR01 或新闻/日历模块（NR08）的数据缺失状态必须单列为 UNKNOWN 并按保守规则处理（暂停新增风险，不阻断已有仓位的保护）——与项目现有规则一致，可作为外部佐证；②风险等级到动作的映射（RED 降暴露、YELLOW 控仓）只能作为预登记规则草案，阈值不能照搬。

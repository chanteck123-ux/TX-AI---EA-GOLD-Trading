# A169 skill-portfolio-risk-parity — Claude 全文审核（2026-11-05）

## P0208 尾段（FULL_READ；FILES 1737–1738：README.en、README）
- 定位：ERC 风险平价，使用手写的 Ledoit-Wolf（常数相关目标）协方差，scipy SLSQP 求解，月末调仓，协方差窗口 60 个交易日。默认 9 个资产：3 个指数、3 个期货主力合约（铜、螺纹钢、**黄金 AU**）、3 个 ETF（300ETF、国债 ETF、**黄金 ETF 518880**）。中英文 README 逐段对照，内容一致。
- **问题**：
  1. **资产池重复**：沪深300 指数和 300ETF、上证50 和沪深300、黄金期货和黄金 ETF 实质上是同一类暴露。ERC 按"资产"平分风险，同一暴露出现两次就会得到两倍风险预算，所谓"风险平价"因此失去意义。文档承认存在高相关块，却只依靠 LW 收缩来稳定，没有在资产层面去重。
  2. **收益口径不一致**：价格指数不含分红，ETF 的价格有分红除息；期货主力合约 `XXX_DOMINANT` 是连续拼接，换月时会跳空（与 A160 的问题相同），文档没有提到复权或换月处理。三类资产用 inner join 并 dropna 对齐，会丢掉部分交易日。
  3. **"真实数据全链路通过"的说法不足为凭**：只有 231 个交易日（约 1 年），Sharpe 0.21，在统计上没有意义。"ΣRC_i = σ_p"在定义 RC_i = w_i(Σw)_i/σ_p 时是欧拉恒等式，**恒成立**，把它当作验证项只是同义反复。条件数 462 对比 502，LW 的改善有限。
  4. 回溯窗口说法矛盾：输入配置写"结束日往前 350 天"（日历日），已知局限写"约 350 交易日"，实际是 231 个交易日。`update_time` 用"A 股收盘 15:30"，而 A 股实际收盘时间是 15:00（期货另有夜盘）。
  5. 权重按名义敞口计算，期货的保证金只用于计算资金占用，这个处理正确（与 A160 按保证金反推手数的错误做法相反）。但"名义=本金、不加杠杆"意味着它不是真正的风险平价基金做法（文档已承认）。
- 与 V1.2 的关联：资产池包含黄金期货和黄金 ETF，可以作为 NR07（黄金关联市场）的参考：境内 AU 主力合约、518880 与 XAUUSD 的关系。但它只用日线，而且对换月不做处理，**不能直接作为数据来源**。

## P0209 前段（FULL_READ；FILES 1739–1741：data_guide、requirements、SKILL）
- **LW 收缩强度公式缺少一项**：文中写 δ = clip(π̂/(γ̂·T), 0, 1)。Ledoit-Wolf (2003) 常数相关目标的原式是 κ = (π̂ − ρ̂)/γ̂，δ = max(0, min(1, κ/T))。这里**漏掉了 ρ̂ 修正项**（相关结构的渐近协方差项），一般会使 δ 偏大，即收缩过度（凭我对原论文的了解，没有对照原文，属 PLAUSIBLE）。sklearn 的 LedoitWolf 使用缩放单位阵目标，这一点描述正确。
- **资产池是按结果挑出来的**：notes 记录"曾用国债指数，ERC 给它 65.7% 权重使组合债券化，改用上证50 后组合波动从 2.19% 升到 6.39%（更均衡）"。ERC 给低波动的债券高权重，正是这个方法应有的行为。根据结果偏好去替换资产，是在同一样本上做选择，属于数据窥探。SKILL 的输入表仍写"国债指数"，与现在的默认池不一致。
- 期货元信息获取失败时，**静默回退**到默认值 multiplier=1.0、margin_rate=0.10，资金占用的报告会因此失真。"16:00 收盘后含当天"与 README 中的 15:30 不一致。
- 调仓日 t 用截至 t 日（含）的数据估计协方差，从 t+1 开始持有，前提是在 t 日收盘成交，这一点没有写明。
- 优点：RC、MRC 和欧拉守恒的推导正确；明确说明期货按名义敞口计算、保证金只用于资金占用；缓存命中要求区间和品种都覆盖请求。

## A169 结论
- ERC 的数学是对的。主要问题：
  - 资产池存在重复暴露，同一暴露拿到双份风险预算；
  - LW 的 δ 可能缺少 ρ̂ 项；
  - 资产池按结果替换；
  - 连续合约和指数未复权、不含分红；
  - "ΣRC=σ_p"的验证是同义反复；
  - 只有约 231 个交易日的"真实数据通过"。
- 对 V1.2 的 NR07：资产池里的黄金期货和黄金 ETF 可以作为关联市场的候选，但必须自行处理换月和时区（境内日盘加夜盘与 XAUUSD 24 小时交易的对齐问题）。脚本未审。

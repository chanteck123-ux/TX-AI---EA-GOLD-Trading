## P0250 后段（FULL_READ：FILES 2135–2140，包括 portable-loader、README.en、README、references/pandadata-map、references/rotation-guide、SKILL）
- 定位：描述性的美股行业轮动报告。按 Pandadata 的 sector 字段对成分股收益取中位数，给出 1D、1W、1M、3M、YTD 表现、PE/PB 快照和排名变化。中英文 README 一致。
- **优点**：
  - 只用成分股聚合，不用 ETF 或指数替代；
  - 不对行业分类做二次映射；
  - **快照不得写成历史分位**；
  - 估值要注明截至日期，财报截止日的滞后须说明；
  - 不同 PE 口径不得混合聚合；
  - 不混用 USD、HKD、CNY；
  - 同时列出有效成分数和缺失成分数。
- **问题**：
  1. **自动化时间的依据错误（已推算）**：文档建议在"Asia/Shanghai 21:30 之后运行，以覆盖美股收盘后的日线刷新窗口"。美东夏令时期间，上海 21:30 正是纽约 09:30，即**美股开盘**；冬令时为 08:30，开盘前。美股收盘对应北京时间次日 04:00 或 05:00。所以 21:30 运行拿到的是**前一交易日**的数据，并非"覆盖收盘后刷新"。这与 V1.2 必须核对服务器日、时区和夏令时属同一类问题。
  2. **只取在市股票，存在幸存者偏差**：成分股取自 `get_us_detail(status=1)`，窗口内退市的股票被排除，3M 和 YTD 的行业收益因此偏高。
  3. **拆股未调整**（PLAUSIBLE）：1W 到 YTD 的收益直接用窗口起点和终点的收盘价计算，没有说明 `get_us_daily` 是否复权。A207 已记录美股日线存在拆股造成的极端离群值；中位数虽然稳健一些，但拆股后的成分仍会被算错。
  4. 行业收益用等权中位数，小盘股数量多，会主导结果，与市值加权的行业表现不同，文档没有提示。
- 个人信息：README 和 SKILL 中有创建者 handle，未转录。

## A215 结论
- 描述性规则写得清楚，但时区依据错误，并有幸存者和拆股两个偏差。对 V1.2 的教训：所有定时任务都要按交易所时区和夏令时推算，不能只写一个固定的北京时间。脚本未审。

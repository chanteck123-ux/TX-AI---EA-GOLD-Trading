# A184 skill-risk-model — Claude 全文审核（2026-11-05）

## P0220 尾段（FULL_READ；FILES 1850–1852：README、methodology、requirements）
- 定位：Barra 式结构化风险模型。风格因子（SIZE、12-1 动量、21 日反转、60 日波动、120 日 beta）加行业哑变量；逐日按 √市值加权做 WLS 估计因子收益；因子协方差 F 用 EWMA（半衰期约 90 天）并修正为 PSD；特异方差 Δ 用 EWMA（半衰期约 60 天）；Σ = XFXᵀ + diag(Δ)。风险归因用 CCTR_k = b_k(Fb)_k。与 A167 是同一作者体系。
- 方法核对：
  - WLS 按 √市值加权、12-1 动量、Σ 的结构形式、σ² = b'Fb + w'Δw 的分解（在 Δ 为对角阵时成立）、CCTR 的欧拉分解（各项之和等于 b'Fb），**都正确**。
  - 行业哑变量本身张成了市场因子，所以不再另设截距或国家因子，并加入微小的 ridge 防止共线，处理合理。
- **问题**：
  1. 特异方差只用逐只股票的 EWMA，**没有贝叶斯收缩或结构化特异风险模型**（Barra 的做法有这一步），小盘股和新股的 Δ 估计噪声会很大；也没有波动率状态调整（volatility regime adjustment）。
  2. 与 A167 一样：
     - README 写数据层使用 `get_market_cap` 和 `get_industry`，**这两个方法都不在 PandaData 的方法索引中**（PLAUSIBLE，data_source.py 未审）；
     - **无凭证时自动回退到合成数据**；
     - panda_data 版本为 0.0.9；
     - 有"简体中文 | English"字样，但没有英文 README 文件。
  3. demo 中等权组合的年化波动只有 4.63%，对股票组合来说低得不合理，说明合成数据的参数不接近真实市场，只能用于检验代码能否跑通。
- SKILL.md 在 P0221 中，待读。

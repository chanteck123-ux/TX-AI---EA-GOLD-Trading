## P0207 尾段（FULL_READ；FILES 1726–1728：README、methodology、requirements）
- 定位：用 scipy SLSQP 求解 5 种目标（均值方差、最小方差、最大夏普、风险平价 ERC、最大分散化），支持权重上限、行业中性、因子暴露中性和换手约束。
- 方法核对：
  - ERC 的目标 Σ(RC_i − σ_p²/n)² 与 Maillard 等人一致，正确；与 A160 把 Σ⁻¹σ 误称为风险平价相比，本资产是对的。
  - 最大分散化的 DR 定义正确；Ledoit-Wolf 收缩后再截掉负特征值，正确。
- **问题**：
  1. 最大夏普"原始形式非凸，用 SLSQP 从等权起点求解"：最大夏普可以通过 Charnes-Cooper 变换转成凸问题，用 SLSQP 求局部解可能停在次优点，文档只建议风险平价和最大分散化使用多起点。
  2. **无凭证时自动回退到合成数据**：没有凭证时用合成数据跑出结果，用户可能不知道结果来自假数据。这与 A166"不要回退到伪造数据"的原则相反。
  3. **方法名可能是编造的**：README 写数据层使用 `get_market_cap` 和 `get_industry`，但这两个方法名都**不在** A158 方法索引的 218 个方法中（我在 method-index 原文中检索过，均为 0 次命中；索引里只有 `get_stock_industry`）。由于 data_source.py 未审，属 PLAUSIBLE。requirements 注释中的 panda_data 版本是 0.0.9，比 A158 要求的 0.0.12 旧。
  4. README 中的 demo 输出全部来自合成数据：风险平价的 maxw=0.100，恰好等于 10 只标的的等权，可能是合成协方差结构过于对称所致，不能作为方法效果的证据。
  5. README 开头写"简体中文 | English"，但没有英文 README 链接（只有 README.md 一个文件）。
- 优点：行业中性会隐含美元中性，文档对此有说明，并要求不带行业约束的多空组合显式设置 net_exposure；文档提醒等式约束与权重上限冲突时问题会不可行。
- SKILL.md 在 P0208 中，待读。

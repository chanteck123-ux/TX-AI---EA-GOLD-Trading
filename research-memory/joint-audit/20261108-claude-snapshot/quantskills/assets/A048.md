# A048 skill-causal-alpha-discovery（全文审核笔记）
- 读取（P0048）：agents/portable-loader.md、README(.en.md, .md)（SKILL.md、references、config 见后续包）。
- 内容：声称用因果发现（PC、LiNGAM、NOTEARS、do-calculus）从 OHLCV 中找"体制不变"的 alpha：88 个以上衍生特征 → 因果发现 → 取前 3 个"因果父节点"，按 ATE 加权 → 跨体制不变性检验（波动率、牛熊、年度）→ 回测。训练期 2015–2020，测试期 2021–2025（时间切分本身是对的）。
- **独立发现（文档层面）**：
  - ①**"因果"名不副实**：快速开始中第 2 步默认 `--method ic_selection`，README 也写"默认 rank-IC 选择 + 多样性约束"——**默认流程就是相关性选择**，与宣传的"因果而非相关"直接矛盾。
  - ②**测试集污染**："自动波动率门控"的规则是"若不变性检验发现高波动体制下 ATE 反转，就乘 (1 − rank(vol))"；而第 5 步的不变性检验是在**测试期**（causal_factor_test）上运行的。如果门控根据这个结果来决定，测试期就参与了因子构造，2021–2025 不再是样本外。（步骤顺序与门控的触发时机需在 SKILL 或源码中进一步核实。）
  - ③**过度宣称**："如果是，那么这种关系就是不变的——无论牛市、熊市、震荡、高波动都成立"。从观测性 OHLCV 数据做因果识别，需要因果充分性（没有隐藏混杂）、忠实性等强假设；README 对此没有任何讨论。不变性检验通过也只能说明在已检验的体制中稳定。
  - ④股票池用 `--indicator 000300`，是否为历史时点的成分没有说明（可能存在幸存者偏差）。
  - ⑤报告章节数不一致："18 节"与"约 16 节"两种说法。
- 对黄金 EA：①**宣传的方法与默认实现不一致**是审核时首先要查的问题；②任何"体制门控"规则只能在训练期确定，否则测试期就被污染——对应 DR01/NR02 的体制规则必须预先登记、冻结后再验证。
- 续读（P0049）：references/{causal-discovery, how-it-works}.md、requirements.txt、SKILL.md（全部逐行阅读）。
- **已由原文确认的独立发现**：
  - ②**测试集污染——已确认**：how-it-works 第 497–498 行写"把**测试期**数据切成 6 个体制"做不变性检验；SKILL.md 第 789 行对 `causal_factor_test.csv` 运行不变性检验，第 798–799 行再用这份报告（`--invariance invariance_report.json`）对 `features_test.csv` 生成门控因子，并在**同一测试期**（2021–2025）回测。也就是说，"是否加波动率门控"是看测试期结果决定的，门控后的回测成绩**不是样本外成绩**。
  - ①**默认方法是相关性选择——已确认**：causal-discovery.md §2.4 "Rank-IC Selection（Default, Recommended）"——按平均截面 rank IC 选特征。SKILL.md 的 summary_zh 也写"基于 IC 选择"。被称为"因果父节点"的，实际上是 IC 最高的特征。
  - ⑥**把"未拒绝原假设"当成证明**：不变性检验中，p > 0.05 时判为"Strongly Invariant — genuine causal mechanism"，how-it-works 也写"如果 p > 0.05，就未拒绝不变性假设——因子通过因果检验"。这是典型的统计误用：用 bootstrap 标准误、6 个体制，检验功效低，不显著并不能证明不变；SKILL.md 的描述里甚至写了"formal invariance guarantees（形式化的不变性保证）"。
  - ⑦**把回归斜率称为 ATE**：每个体制内的"ATE"是"收益对因子的线性回归系数"，没有做混杂调整，只是关联，不是干预效应。
  - ⑧**多周期目标调优**（5/10/20 日中选"因果信号最强"的）、**特征池 88 个以上**、"前 3 个"——都是数据窥探，试验次数没有登记，也没有做多重检验校正。
  - ⑨**文档相互矛盾**：
    - 默认目标周期：how-it-works 第一处写"20 日（推荐默认）"，第二处写"5 日（默认）"；SKILL.md Phase 2 的示例用 20 日，Calling Pattern 用 5 日；
    - 训练/测试切分：README 和 SKILL 写 2015–2020 / 2021–2025，how-it-works 写 2015–2019 / 2020–2025；
    - 特征数："88+"与"30–50"；
    - SKILL 称"self-contained — no API keys"，但实际使用 PandaData 需要凭证；
    - causal-discovery.md 有两个第 7 节。
  - ⑩作者在局限一节承认"没有隐藏混杂"的假设在现实中可能不成立——但这与正文"genuine causal mechanism"的结论相矛盾。
- **A48 逐资产结论**：**反例资产**——宣传因果，默认实现是相关性选择；用测试集决定门控；把不显著当作不变性证明。validation_level: listed，status: draft。**未做静态实现核查，未运行**。
- 对黄金 EA（重要教训）：①**任何"体制门控"或"过滤器"都只能用训练段确定**（对照 A26 的 IC gate 问题，这是第二个同类案例）；②**"检验不显著" ≠ "稳定/不变"**——DR01/NR02 的体制规则不能用"各体制间差异不显著"来证明稳健；③宣传方法与默认实现必须一致。

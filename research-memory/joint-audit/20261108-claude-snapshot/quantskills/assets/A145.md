# A145 skill-news-sentiment-analyst（A 股新闻 → LLM 识别个股 → 行情"验证"，Apache-2.0）— 文本审核

范围：P0150 FILE 1535 LICENSE.txt（Apache-2.0 标准文本，版权行为社区账号）、1536 README、1537 references/data_sources、1538 references/pandaai_api_list、1539 requirements、1540 SKILL.md 全文。scripts 不在计划内，**未读**。

要点：
- 流程：AKShare 采集东财、富途、同花顺快讯 → 由 LLM"用自己的知识"判断受影响的个股、板块和情绪 → 用 PandaAI 当日行情（OHLCV、振幅、成交额、融资、行业）做"验证" → 生成"投行级"终端报告并写入 Parquet。

发现：
1. **README 示例数据违反 A 股涨跌停规则**：
   - 000977（深市主板，涨跌幅限制 10%）示例为 **+21.01%**；
   - 002057 **−19.03%**、天齐锂业 **−18.26%**、永兴材料 −16.66%，均为主板或中小板股票，单日不可能超过 ±10%（除首日等特殊情况）；
   - "上海合晶 20cm 涨停"，同一行却写 +12.77%（科创板涨停是 +20%）。
   - 示例表格不可能是真实的单日行情，**疑似拼凑或错误计算**，却以"真实报告样式"展示（需结合当时交易规则核实，但主板 ±10% 限制是确定的规则）。
2. **"验证"不是预测检验**：用新闻当日或盘中的价格来"验证"AI 的方向判断，属于同期相关；新闻本身可能就是对价格的事后解释。"预期偏差"（AI 看多但实际大跌）只是事后对照，不能证明新闻情绪有预测力。
3. **盘中快照被当作当日结果**：示例生成时间为 11:14（上午盘中），`get_stock_rt_daily` 返回的是未收盘数据，报告却列为"收盘 / 涨跌幅"；文档没有未收盘标记（对比 A129 的 complete:false）。
4. **LLM 凭知识映射个股**：
   - 易产生幻觉代码，或引入训练知识中的"未来信息"（若用于历史回放）；
   - SKILL 要求"不确定时留空、不要猜测"，但没有校验机制，例如用 `stock_info_a_code_name` 核对代码与名称。
5. data_sources 称 AKShare 是"唯一数据源"，README 和 SKILL 却同时依赖 PandaAI，口径矛盾。
6. 推广内容："Elite 套餐（¥153/月）"属商业推广；"Analyst: … Sisyphus Alpha"带有品牌署名。
7. requirements 中 panda_data 没有设版本，akshare 只设下限，接口变动风险高。
8. 许可证为 Apache-2.0，与套件多数资产不同，仅作信息记录。

**A145 结论**：文本全部覆盖（共 6 份全文）。示例数据违反涨跌停规则，"验证"属于同期相关，盘中数据未标记——**不能作为情绪因子证据**。与 EA 的 NR08 新闻研究相比，反面教训是：新闻时间戳必须早于价格反应窗口，并且只能使用已收盘的 bar。**未实现**。

# A168 skill-portfolio-pnl-attribution — Claude 全文审核（2026-11-05）

## P0208 中段（FULL_READ；FILES 1730–1733、1736；1734 source_boundary.md 和 1735 requirements.txt 为 HASH_REUSE，已在 agent-corporate-governance-scanner 和 skill-ag-futures-seasonality 中审过）
- 定位：已实现收益的核算。逐日计算 weight×asset_return 得到证券贡献，按行业汇总，再做毛收益−费用=净收益，以及相对基准的主动收益。对账误差超过 1e-10 视为缺陷。中英文 README 一致。
- **问题**：
  1. **持仓时点的语义没有定义（关键）**：契约只说"持仓与**同日**收益连接"，没有说明 `date` 上的 weight 是**当日开盘前**（前一日收盘）的持仓，还是**当日收盘后**的持仓。如果是收盘后的持仓（已包含当日交易），乘以当日收益就是前视，结果会把当日调仓的收益计入组合。SKILL 写的是 "point-in-time positions"，但没有落到具体的约定上。
  2. **没有多期链接**：summary 给出的是"累计毛、净、主动收益"，而证券贡献是逐日算术相加的，多日加总不等于几何累计收益。对账只在单日成立，契约没有说明累计口径（对比 A162 使用了 Carino）。
  3. 主动收益是净收益减基准的算术差；权重和不为 1 时只告警、仍保留结果，现金部分的贡献会被漏掉，或者被当作 0。
  4. 本地校验需要 `node scripts/validate-qsh-form.mjs`，依赖 Node.js（与 Python 技能混用）。
- 优点：重复键、缺少同日收益时直接报错；绝不前向填充，不把缺失补 0；明确不做事前风险归因。

## A168 结论
- 是一个简洁、守卫严格的核算工具。主要缺口是持仓时点语义没有定义（可能前视），以及累计收益没有多期链接。对 V1.2 的启示：RiskExecution 的盈亏对账必须规定"仓位快照时点（成交前还是成交后）"，并对日内多笔成交按成交时点分段计算。脚本未审。

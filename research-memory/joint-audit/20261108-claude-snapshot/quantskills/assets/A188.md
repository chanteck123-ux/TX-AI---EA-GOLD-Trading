# A188 skill-rotation-radar — Claude 全文审核（2026-11-05）

## P0222 后段（FULL_READ；FILES 1882–1889：claude-code、openclaw、portable-loader、README.en、README、playbook、test-cases、SKILL）
- 定位：行业和 ETF 轮动与市场状态识别的分析框架，分状态、领导力、确认三层，要求"至少两个确认信号同向"且必须给出失效条件。不获取数据，不执行交易。中英文 README 一致。
- 问题：
  1. **基本上是提示词层面的定性框架**：rotation_score 中"weighted(...)"的权重、"高"分的阈值、risk-on/off 的判定标准都没有定量定义，结论主要依赖 LLM 的判断，同一份数据可能得到不同结论。
  2. test-cases 只是 6 个提示词和期望行为（例如"必须包含宽度检查"），check_test_cases.py 只能检查文字结构，**不能检验判断是否正确**。
  3. "宽度 = 上涨成分数 / 可交易成分数"在只有一天数据时噪声很大，窗口内怎么汇总没有说明。
- 优点：不把涨幅排名当作轮动；窗口必须与配置周期一致；宽度恶化时降级；结论必须带失效条件；跨资产信号冲突时标记为过渡期。

## A188 结论
- 纪律性的提示词框架，对规范 LLM 输出有帮助，但没有可复现的定量定义。对 V1.2 的 NR02（趋势与震荡状态扩展）只有概念参考价值（状态判定加失效条件），不能直接作为状态分类器。

- 定位：时间序列诊断，覆盖 KDE 和 QQ、Hurst、ADF 和 KPSS、对数差分 1/5/10、价差半衰期、Engle–Granger 协整，按"结论先行"生成报告。中英文 README 一致。多品种汇总报告是三份单品种报告的拼接，抽查数字一致。
- **已验证的问题**：
  1. **Hurst 估计器与半衰期自相矛盾**：demo spread 是 AR(1) 均值回复过程（λ = −0.2258，半衰期 3.07 bars），这种过程的 Hurst 理论上应小于 0.5；报告却给出 **Hurst = 0.70–0.72**，并标为"trending but stationary"。期货报告中日收益（log diff 1）的 Hurst 也达到 0.73（IF）和 0.55（CU）。这说明 Hurst 估计在 60–240 个样本的小窗口下**系统性偏高**（属 R/S 一类估计的小样本偏差，PLAUSIBLE 待脚本核实）。依据 interpretation.md"Hurst > 0.55 视为趋势"的阈值，会把噪声判成趋势。
  2. **重叠差分会制造虚假的持续性**：log diff 5 和 10 是重叠的多期收益，相邻观测有 4/5 或 9/10 重叠，必然产生正自相关，Hurst 随滞后期上升（CU：0.55 → 0.68 → 0.72）。报告据此给 log diff 10 贴上"strong trend"标签，这是构造方式造成的伪象，文档没有提示。
  3. **协整检验临界值错误（与 A198 相同）**：demo pair 报告的 `adf_critical_values` 为 −3.47、−2.88、−2.58，这是**普通 ADF 的临界值**。两变量 EG 残差检验应使用 MacKinnon 临界值，约为 −3.90、−3.34、−3.04。
  4. **主力连续合约未做调整**：真实示例用 `*_DOMINANT` 主力连续合约，换月跳空会进入 log diff 并带来厚尾（IF 日收益峰度 10.7，5 日 17.3）。报告把它解读为"厚尾分布、需尾部风险过滤"，没有排除换月伪象。这与 A160 的问题同类。
  5. 样本只有 2024 年一年（242 个观测），却给出"趋势类投研方向"；同一份报告里对数差分用 1/5/10，KDE 和 QQ 用 1/5/20，两套滞后口径并存。
- 优点：
  - anti-patterns 写明"Hurst、ADF、KPSS 不能单独作为交易信号"；
  - ADF 与 KPSS 结论冲突时标为"conflicting signals"，不强行判定；
  - 如实显示 KPSS 查表截断的警告；
  - 输出只写成研究方向；
  - 运行包不依赖 PandaData。

## A208 结论
- 对 V1.2 NR02（趋势与震荡识别）的启示：不要用小窗口的 Hurst 加固定阈值来划分状态；多期收益要用不重叠的样本，或者做 HAC 校正；协整检验要用 EG 临界值；连续合约要先处理换月。脚本未审。

## 源码批次 S003（2026-11-06，FULL_READ：src/skill_time_series_analysis 下 __init__、analysis.py（988 行）、reporting.py、types.py；tests 下 5 个文件；未运行）
- **Hurst 偏高的原因（PLAUSIBLE → CONFIRMED，并找到具体原因）**：`TimeSeriesAnalyzer.calculate_hurst` 的处理是：
  1. **是否先取对数收益，取决于数据的正负**：`if (s > 0).all()` 时对 `log(s).diff()` 做 R/S，否则**直接对原始水平值**做 R/S。价格序列因此按收益计算；demo spread 含负值，按**水平值**计算。对一个 φ≈0.82 的 AR(1) 水平值做 R/S，短滞后段会呈现"持续性"，所以得到 0.70。如果一个价差恰好全为正，又会被先差分。同一个函数对不同输入的含义不一样。
  2. 使用经典 R/S，**没有 Anis–Lloyd 小样本校正**，片段完全重叠（每个起点都取），滞后范围只有 `w//6` 到 `w//3`（60 窗口时为 10–20），回归只用几个点。这个设定下，即使是白噪声，Hurst 也明显高于 0.5。阈值"大于 0.55 即趋势"会把噪声判为趋势。
  3. log diff 5 和 10 是重叠的多期收益（`np.log(price).diff(lag)`，没有抽样稀疏化），这类序列本身就有持续性，再叠加上面的偏差。
- **协整（CONFIRMED）**：`engle_granger_cointegration` 对 OLS 残差直接调用 `adfuller`，`is_cointegrated = adf_pvalue < 0.05`，使用普通 ADF 临界值，没有调用 `coint` 或 MacKinnon 的 EG 表。
- **新发现**：
  4. **ADF 与 KPSS 的确定性项不一致**：ADF 用默认的 `regression='c'`，KPSS 用 `regression='ct'`，两个检验的原假设口径不同，组合判定（trend_type）因此偏向"非平稳"。
  5. **两个技能的半衰期公式不同**：这里是 `−ln2/λ`，A198 是 `−ln2/ln(1+λ)`。λ=−0.2258 时分别为 3.07 和 2.71。
  6. **spread 报告的结论没有显著性门槛**：只要 λ<0 就写"优先作为价差均值回复投研样本"，**不看** λ 的 p 值，也不看 ADF。
  7. **测试只验证结构，不验证估计值**：Hurst 只检查 `np.isfinite`；EG 测试用的是 `y = 2x + 3` 这种零残差的退化样本（直接走 std<1e-12 的分支，p 记为 0）；没有任何"白噪声的 Hurst 约为 0.5"或"AR(1) 的 Hurst 小于 0.5"之类的校验。
  8. 真实期货的集成测试读取 `.env` 中的明文账号密码（`os.environ.setdefault`，不覆盖已有环境变量），没有凭证时跳过；主力连续合约 `*_DOMINANT` 没有做换月调整（CONFIRMED）。
- **结论更新**：A208 中 Hurst 和协整两项诊断的数值都不可信，不能作为 V1.2 NR02 状态识别的依据。可借鉴的只有报告结构，以及"结论先行，证据附后"的写法。

## P0218（FULL_READ；FILES 1832–1839：README（中文）、backtest_engine、data_sources、factor_audit_and_robustness、factor_validation_checklist、output_contract 18.5 KB、replication_lessons_learned、requirements）
- 中英文 README 逐段对照，内容一致。
- **优点**：
  - 输出契约非常完整：19 张图、20 多个数据文件；IS/OOS/walk-forward；基准对照（反向因子、固定种子随机因子、等权持有、零收益）；回测对齐审计；RAG 打分卡；
  - 每张图下要有五段式的初学者解释；
  - 结论标签分为 effective / weakly / ineffective / regime-dependent / inconclusive；
  - 失败报告必须写明失败阶段、命令、错误、已有产物、可能原因和下一步；
  - **子代理治理**：子代理视为不可信助手，只能写入隔离的 scratch 目录，产出须由主代理复核、复跑校验和 quality gate 后才能采用，最终结论不能依赖子代理的说法。这与本项目"不以聊天转述代替独立审查"的规则一致。
- **问题**：
  1. **回测引擎只用 close 一列**（date、symbol、close），执行本质上是收盘到收盘（虽然可以配置执行延迟）。没有 OHLC、成交量和涨跌停信息，无法处理 A 股涨停买不进、跌停卖不出、停牌这些情况，与 checklist 中"execution price / tradability"的要求不符。
  2. 下载器的 stock 类型调用 `get_stock_daily`（A158 中确认是未复权价格）。data_sources 要求记录"Adjustment rules"，但没有规定必须使用复权价，除权日的价格跳变会进入因子收益。
  3. RAG 打分卡"由客观指标计算"，但红黄绿的阈值没有在文档中给出。
  4. requirements 锁定 panda_data==0.0.9，与 A158 要求的 0.0.12 冲突；numpy 限制 <2.0。
  5. "全文翻译"研报，包括表注和脚注，文档没有讨论版权和转载授权边界。

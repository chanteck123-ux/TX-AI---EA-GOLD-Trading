# A200 skill-stock-score — Claude 全文审核（2026-11-05）

## P0239 后段与 P0240 前段（FULL_READ；FILES 2007–2014：portable-loader、HERMES、README.en、README、references/某白酒龙头评分底稿、references/scoring-guide、reports/半导体 TOP10、SKILL）
- 定位：A 股五维基本面评分（财务 30、消息 20、行业 20、债务 15、增减持 15），并支持行业 TOP10 排名。中英文 README 一致。
- **已验算的规则矛盾和计算错误**：
  1. **净利润趋势规则自相矛盾**：scoring-guide 1.1 中"P2 > P3 > P1 → 6 分（高位微调）"和"P3 < P2 但 P3 > P1 → 4 分"是同一个条件，却给出不同分数。样例底稿三期净利润约为 775、862、823 亿，正好落在这个条件上，底稿取了 4 分。
  2. **事件情绪的映射区间重叠**："-1~+1 → 3"、"0~+2 → 4"、"-2~0 → 3"三档都包含 0；"-6~-5 → 1"和"-5~-3 → 2"都包含 -5。**样例底稿把事件净额 -3 映射为"中性 3 分"**，按它自己的表应为 2 分（-5~-3 档），这是计算错误。
  3. **SKILL.md 与 scoring-guide 的阈值不一致**：
     - 有息负债率：SKILL 为 <20% 得 3 分，guide 为 <10% 得 3 分、10–20% 得 2.5 分；
     - 资产负债率：SKILL 按相对行业中位数打分，guide 按绝对阈值打分；
     - 流动和速动比率：两份文档规则不同；
     - 解禁：SKILL 看 3 个月，guide 看 12 个月；
     - 无回购：SKILL 给 1 分，guide 给 1.5 分；
     - 审计意见：SKILL 写"在财务状况得分基础上扣减"，并漏掉"带强调事项段扣 5 分"，guide 写的是从总分扣。
     两份文档对同一只股票会算出不同分数。
  4. **重复计分**：SKILL 中消息面的"一般利好"包含高管增持和回购计划，guide 中的"一般利空"包含股东减持计划，而这些在维度五中又被单独计分。行业政策在维度三 3.3 中只占 3 分，SKILL 却写成"强扶持 +6~8 分"，量纲不一致。
  5. **TOP10 报告违反自己的规则**：
     - 消息面"全部按基础分 6 分"。按 guide 中各子项的无数据或中性取值相加（3+2+3+1）应为 9 分，6 分没有依据；
     - 维度三全行业统一给 16.5 分，维度五全部为中性 9.5 分（按 guide 验算 3+2+1.5+3=9.5，这一项是对的），排名实际上只由财务和债务两项决定；
     - 并列第 1 的两只股票财务分相同，按规则应再比较市值（3080 亿 vs 889 亿），**应分出 1、2 名，但报告给了并列**；
     - 只对流通市值前 50 的股票打分，存在规模偏差；
     - 报告声称"实际机构覆盖密集"，但没有任何数据支持。
- **合规与边界问题**：
  - 触发词包括"能买吗、值得持有吗、推荐…股票"；
  - 输出模板中有"建议关注/持有/谨慎"，等级说明有"适合中长期配置"；
  - TOP10 报告中有"建议关注"表，按稳健型、成长型、弹性型对真实上市公司点名推荐。
  这些实际上就是投资建议，与免责声明相互矛盾。
- **数据与接口问题**：
  - 底稿的数据来源写着"公开财经媒体报道、行业研究报告"，没有引用出处，研报评级也没有具体券商和日期；
  - guide 4.4 写"从利润表提取 st_borrow"，但借款科目在资产负债表；
  - 1.5 用的是港股的行业中位数接口；
  - 高管交易使用 `get_stock_insider_trade`（"A 股可通过相同 API"），属 PLAUSIBLE 待对照 A158 方法索引核实；
  - 全部评分没有 PIT 约束，没有任何回测或有效性检验。
- 具名机构加分（头部公募、私募和券商）针对的是机构，不涉及个人；本笔记不转录公司推荐结论。

## A200 结论
- 规则文档自相矛盾，样例算错，报告违反自己的排序规则，输出实际是投资建议，对 V1.2 没有用处。可作为反例写入 GAPS_CN："一个评分体系有两份阈值来源，必然漂移"。本仓库无脚本可审。

## P0240 尾段与 P0241 前段（FULL_READ；FILES 2015–2019：portable-loader、README.en、README、references/screener-guide、SKILL）
- 定位：把自然语言选股条件拆成原子过滤器（指标、运算符、阈值、窗口、日期口径、接口、缺失策略），按漏斗逐层筛选，输出带证据的结果。中英文 README 一致。
- **优点**：
  - 筛选日作为必填的一等输入；
  - 财务和事件数据只用披露日不晚于筛选日的行；
  - 每层记录进出数量、接口、参数和数据日；
  - 结果展示实际数值，而不只是通过或不通过；
  - 因数据缺失而留下的标的单独标注，不计入严格通过；
  - 硬过滤与排名分开；
  - 歧义先复述确认；
  - 先在小样本上冒烟测试，再全市场执行。
  这套"原子过滤器契约"可作为 V1.2 指标和门控条件登记格式的参照。
- **问题**：
  1. **历史成分股不是 PIT**：时点约束只覆盖财务和事件数据。行业和概念成分股用的是当前名单，历史筛选时会带入幸存者偏差和成分变动偏差；指数成分使用 `get_index_weights` 时也没有要求取筛选日当时的权重。文档对此未作说明。
  2. **前复权价格不适合历史价格阈值**：guide 建议均线用复权数据（`get_stock_daily_pre`）。但前复权会用筛选日之后的除权事件改写历史价格水平，因此"价格 < X"、"市值"等**绝对水平条件不能用前复权**；只看比率的均线交叉不受影响。文档没有区分这两种情况。
  3. 股息率只说"按筛选日价格计算"，没有区分 TTM 与会计年度，也没有处理特别分红。
  4. 只有文档，没有脚本，`validation_level: runnable` 与实际情况不符。
- 个人信息：README 和 SKILL 中有创建者 GitHub handle，未转录。

## A201 结论
- 方法框架可取，PIT 约束需要扩展到成分股与价格复权口径。不涉及 V1.2 的交易路径。

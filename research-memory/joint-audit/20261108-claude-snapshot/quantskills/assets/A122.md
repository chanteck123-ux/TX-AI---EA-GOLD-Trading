# A122 skill-index-valuation-rotation — 文本审核

阅读范围：**全文**——FILE 1298 portable-loader、1299 README.en、1300 README（与英文版等价）、1301 SKILL。资产只有 SKILL 与 agents，**没有脚本**。

要点：
- 指数 PE/PB 历史分位（至少 5 年）对应温度带（< 20% 低、20–80% 中性、> 80% 高），并叠加 20/60/120 日收益；
- 行业 20/60/120 日动量、排名及其变化、持续性；
- 优先使用行业指数，否则用成分股等权聚合并标注；
- 默认宽基池：上证 50、沪深 300、中证 500、中证 1000、创业板指。

独立发现：
1. **行业轮动可能使用当前成分回填历史**：
   - 行业指数不可用时，用 `get_industry_constituents` + `get_stock_daily` 聚合；
   - 该接口返回的是**当前**成分（A108 的 factcheck 中也是单次快照，返回 5517 行）；
   - 用当前成分计算过去 20/60/120 日以及"上期排名"，会带入幸存者偏差与行业调整后的成分；
   - 文档没有要求使用历史成分，也没有披露这一点。
2. **指数 PE 历史不平稳**：
   - 5 年内成分调整、PE 口径（TTM/静态、负盈利是否剔除）变化、指数编制规则变更，都会改变 PE 分布；
   - 分位法默认历史分布可比，文档没有提示这一点；
   - 负 PE 或 PE 缺失时，分位没有意义，处理方式也未说明。
3. 分位 = ≤ 最新值的比例，分母包含最新值本身，最小值为 1/N。数值影响小，但"分位 0%"永远不会出现。
4. **"定投参考"有建议性**：示例问法"中证 500 适合定投吗"。文档把它定位为"估值纪律与风险预算"，但实际输出的就是基于温度带的配置倾向，与"不构成建议"存在张力。
5. 温度带阈值 20/80 为人为设定，没有经过检验（例如分位与未来收益的关系），只能作描述用途。
6. `status: stable`，`validation_level: runnable`，但资产中没有任何可运行的脚本（目录结构只有 SKILL 与 agents），等级标注与内容不符。

与黄金 EA 的关系：低。可迁移的原则：历史分位或 regime 判断要使用历史上当时可得的成分与口径。黄金单一品种不涉及成分问题，但涉及合约换月与报价口径（参见 A101）。

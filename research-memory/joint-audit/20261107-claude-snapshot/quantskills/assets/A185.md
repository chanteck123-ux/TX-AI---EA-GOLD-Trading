# A185 skill-risk-return-metrics — Claude 全文审核（2026-11-05）

## P0221 中段（FULL_READ；FILES 1854–1859：portable-loader、examples/output txt、README.en、README、references/example_output、SKILL）
- 定位：单标的风险收益画像，计算总收益、CAGR、均值年化收益、波动、Sharpe、Sortino、最大回撤和当前回撤、Calmar、胜率；按代码后缀路由，A 股用 panda_data，港美股用 tqx_data。分母为 0 时返回 null。中英文 README 一致。
- **示例数值自相矛盾（已验算）**：示例中 total_return 为 +8.29%，观测 98 根，按文中公式 CAGR = 1.0829^(252/98) − 1 ≈ **22.7%**（即使把 98 根收盘当作 97 个收益也只有约 23.0%），而示例写的是 **24.31%**。Sharpe = 0.2510/0.2874 ≈ 0.873，Calmar = 0.2431/0.1532 ≈ 1.587，这两项与示例自身的数值相符。可见 CAGR 这一项与 total_return 对不上，示例是编出来的（文档承认"示例数值取自 SKILL.md schema，非实时行情"），但它用的是**真实代码 0700.HK**，还配有"夏普 0.87 属中等偏上"这类解读，容易被当成真实数据。
- 其他问题：
  1. SKILL 说指标基于 "daily log-of-simple returns"，公式却全部使用简单收益和 cumprod(1+r)，表述与公式不一致。
  2. 用 98 个交易日的数据年化 CAGR 和 Sharpe，误差极大，文档没有给出置信区间，也没有提示短窗口年化的问题；示例解读中直接说"年化约 24%"。
  3. Sortino 中 `downside_std` 的定义（只取负收益的标准差，还是相对 0 的下行偏差 √mean(min(r,0)²)）没有说明，两种口径结果不同。
  4. 港股的年化也用 252 天，港股实际交易日约 247 天，差异较小；复权"仅按上游口径"，A158 的 get_stock_daily 是未复权价格，除权日会产生伪回撤。
- 优点：分母为 0 时返回 null 而不是 NaN；非法代码在发起网络请求前就拒绝；不提供买卖建议。

## A185 结论
- 公式表本身规范，但示例数值不自洽，且用真实代码配假数据；短窗口年化没有风险提示；收益是否复权取决于上游。与本项目"夏普只作辅助诊断，先核对频率、收益序列、无风险利率及年化口径"的规则对照，这个技能恰好缺少这些核对。脚本未审。

- 固定训练/验证窗口加 embargo；mRMR 只用训练行，SAGE 在训练行拟合、在验证行估计贡献。

独立发现（静态阅读，未运行）：
1. **示例配置与自身指引矛盾**：validation_notes 和 README 要求"embargo 至少等于重叠标签期限"，但 input_schema 两个示例都是 `embargo_days: 0`。照抄示例会在训练/验证边界产生标签重叠（同 A079）。
2. **mRMR 相关性是池化而非截面**：F 统计量在 (date, ticker) 全部行上计算。当缺失率相同时，它是池化 Pearson r² 的单调函数，会被跨日共同变动（市场整体涨跌、因子水平随时间漂移）主导，衡量的不是截面选股能力。行间不独立（同日同期限、重叠标签），F 值本身也不具备显著性解释，只能作为排序依据。文档称其为"statistical relevance ranking"，措辞较准，但未提醒池化问题。
3. **SAGE 的验证段已用于选择**：SAGE 用验证行估计贡献并据此选 Top-K，验证段因此成为选择集。文档要求的外部锁定测试是必要的，但它在 Skill 之外，无法强制。
4. 相关因子共享或不稳定的归因（marginal imputer）已在文档中声明，处理诚实。
5. 优点：
   - 输入哈希与运行清单可复现；
   - `available_date` 缺失时记录时点提示；
   - 与随机 Top-K 基线比较（防止"任何 K 个都差不多"）；
   - 算法来源与许可完整。

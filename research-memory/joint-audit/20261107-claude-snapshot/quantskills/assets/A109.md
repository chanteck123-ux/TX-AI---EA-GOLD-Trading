## P0119 部分（FILE 1211–1217 全文）

要点：
- 用行业/概念关系构建点时（point-in-time）股票图，对 PandaData 日频因子通道（动量、流动性、风险）做固定的对称归一化传播（S = D^-1/2 A D^-1/2）；
- 不训练 GNN，不搜索字段；
- 输出：
  - `low = S²x`；
  - `high = x − low`；
  - `neighbor_lag = S·x(T−1) − x(T)`；
  - 三个组合因子（扩散确认、残差反转、价格/流动性分歧）；
- 通道在评价前固定，每个通道两个字段都必须齐全，缺失不替代；
- smoke test 只验证了接口（2 只股票 × 2 天），明确声明不构成有效性证据，状态为 draft/listed。

初步发现：
1. **边界写法规范**：静态 synthetic fixture 必须显式加 `--allow-static-fixture`，正式运行必须提供 effective_date，可防止把当前行业分类倒填到历史。
2. `neighbor_lag` 的符号含义：`S·x(T−1) − x(T)` 为正，表示邻居过去的值高于自身当前值（"追赶"假设）。合理性待看 SKILL 与测试。
3. 中文 README 中 "relationships.json is a static…" 一句未翻译（与英文版混排），属轻微问题。

## P0120 补读（FILE 1218–1225 全文：7 份 references + SKILL.md）

补充要点：
- 图构建：S = D^-1/2 A D^-1/2，合并重复边，去自环；孤立节点不产生图因子（fail closed）。相关性边在 v1 中仅作诊断；若启用，必须只用 < T 的数据并单独计算指纹。
- 每个通道先做 median/MAD 标准化，MAD = 0 时整个截面置零；k = 2 在评价前冻结。主因子 = 0.5 × 动量 neighbor_lag + 0.5 × 流动性 neighbor_lag；`graph_residual_reversal = −z(momentum_high)` 为单独候选。
- 时点：T 日因子与 T 日图在收盘后生成，供 T+1 使用；财务与事件字段在 v1 中排除。
- 验证分 7 层：形式接受需要完整年度的开发/验证/冻结期，并声明成本，且测试后不得再选字段或传播深度。
- overlap-review 承认组织扫描（225 个仓库）无法覆盖私有、隔离等资产，需要人工做语义复核。

独立发现：

2. 主因子使用固定 0.5/0.5 权重，并预先登记"残差反转为单独候选"，**未见测试后的选择**——属规范做法。
3. qsh-form 再次出现 `{{#attachments}}` 无闭合段（与 A93、A102 同类）。
4. SKILL 的状态（draft/listed）与证据层级一致，没有夸大。这是本批次中最克制的资产之一。

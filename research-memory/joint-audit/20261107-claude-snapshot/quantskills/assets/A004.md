# [4] agent-cross-market-event-radar 全文复核

- 全文已读（P0003）：AGENTS.md、agents/portable-loader.md、examples/prompt.md、README.en.md、README.md、references/{agent-boundary, data-and-outputs, methodology}.md、requirements.txt。
- 新增要点：
  - 统一事件 schema：`event_id, event_type, event_date, symbol, market, title, detail, data_completeness, source_method, extra`；data_completeness 为关键字段缺失比例的补集。
  - 关联规则：定增→解禁 30 天、预告↔快报 30 天并校验落区间/方向、分红×财报 7 天重叠、同公司 30 天 ≥3 事件为聚集。
  - 优先级 = 40% 临近度 + 35% 事件类型先验权重 + 25% 完整性 + 关联加分；**"历史影响"只是按事件类型给的固定先验（预告 0.85、定增 0.75…），并非用历史数据估计**，文档自己也承认只是排序参考。
  - 默认数据地址为 http（`http://pandadata.pandaaiquant.com`）。
  - 每次拉取记入 `pull_log`（方法、参数、行数、耗时），可复现性设计值得借鉴。
- 黄金 EA 用途：NR08 经济日历的事件表可借鉴统一 schema + data_completeness + pull_log；"预告↔快报一致性"类比为"预期↔实际"的口径校验。
- 结论：维持首轮"采纳 schema 思路，不采纳内容"；补充：其"历史影响权重"不是实证估计，不可当作事件重要性证据。

# A205 skill-survivorship-universe-auditor — Claude 全文审核（2026-11-05）

## P0243 后段（FULL_READ；FILES 2044–2047、2049、2051、2052：portable-loader、README.en、README、references/methodology、references/pandadata-integration、SKILL、validation/README；FILES 2048 output-contract 和 2050 requirements 为 HASH_REUSE）
- 定位：审计证券的上市、退市生命周期和成员资格，按输入中的 symbol-date 快照重建历史股票池，并标出缺失的退市收益。脚本离线运行、结果确定。
- **优点（本批中数据纪律较好的一个）**：
  - 稳定标识符优先于 ticker；
  - 退市证券必须保留到实际退市日；
  - **退市收益缺失时明确标注，不得填 0**，并引用了退市偏差的经典文献；
  - pass、fail、insufficient-evidence 三种状态分开，"缺失证据不能写成通过"；
  - 不就地修改原数据，结果另存新文件；
  - SDK 或凭证不可用时返回 insufficient-evidence，不伪造数据；
  - 中英文 README 都写明"不能证明完整性，除非有完整的历史证券主表"。
- **问题**：
  1. **把可交易列表当作成员资格，属 PLAUSIBLE**：推荐用 `get_trade_list` 的逐日可交易列表生成 eligible=1。停牌证券在当日不可交易，会因此被排除出股票池；而停牌常常发生在重大利空之前，这样做会在幸存者偏差之外再引入一种"停牌偏差"。文档没有区分"上市存续"和"当日可交易"。
  2. 高估量 `return − delisting_return` 只能在两者成对存在时计算。PandaData 不提供标准化的退市收益（文档已披露），所以对 A 股来说，定量检测在多数情况下只会返回 insufficient-evidence。
  3. `validation_level: runnable` 指的是本地单元测试的范围（文档已说明）；PandaData 接入"用脱敏结果单独测试过"，没有可复核的证据。
- 个人信息：SKILL 元数据中有创建者 handle，未转录。

## A205 结论
- "退市收益不得填 0"和"缺失证据不算通过"两点，可直接作为 V1.2 数据审计的原则。XAUUSD 是单一品种，不存在股票池幸存者问题，但同样的原则适用于数据缺口和交易时段缺失的处理。脚本和测试未审。

# A129 skill-kline-pattern-vision（K 线形态识别，社区项目，GPL-3.0-only）— 文本审核

范围：P0134 FILE 1360–1367 全文（portable-loader、CLAUDE.md、README.en、README、references/methodology、references/pandadata_contract、requirements.txt、SKILL.md）。scripts/ 与 tests/ 不在本审核计划中，**未读**。

要点：
- 三种模式：截图、PandaData 数据、混合。全部只读：不下单、不回测、不优化。
- 数据管线：validate → resample（A 股午休分段，不跨、不插值；末根不足一个周期标 complete:false）→ 指标 → HH/HL/LH/LL 摆点 → 候选形态 → 图表。
- 门槛：至少 20 根有效 bar；状态取 ok / empty / error / unsupported 之一；失败不静默换源。
- 形态一律称"候选/疑似"，必须附确认、失效、替代解释和置信度；不计算未经验证的胜率。

发现：
1. 设计纪律良好：区分事实、解释和不确定性；末根未收盘显式标记；摆点确认窗口需写明，"不把尚未确认的未来点当作实时事实"。这些正对应摆点类指标常见的**重绘/前视**风险（以后点确认前点）。但文档没有规定确认窗口的取值，具体是否前视取决于 scripts/pattern_detection.py，**未读未核实**。
2. requirements 钉死了 `panda_data==0.0.9`、`numpy<2.0`，有环境老化风险；`pytest` 被写进运行依赖。
3. 只覆盖 A 股的午休时段（09:30–11:30 / 13:00–15:00）；期货的夜盘与日内多段休市没有说明，按 A 股规则聚合会出错，**文档缺口**。
4. 截图读数是近似值，混合模式要求分栏列出、不互相覆盖，做法正确。
5. 维护者为社区个人账号，README 声明"未经独立审核、非官方认证"。

与黄金 EA 的关系：
- 可借鉴"末根未收盘标记 + 摆点确认延迟显式化"，对应用户 Scalping SOP 的"反转闭柱确认"，即只用已收盘 K 线；
- 只作参考，不改变用户 SOP，**未实现**。

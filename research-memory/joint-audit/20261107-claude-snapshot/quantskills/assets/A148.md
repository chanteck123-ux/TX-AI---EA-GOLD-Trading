# A148 skill-oil-brief（原油日报生成，GPL-3.0）— 文本审核

范围：P0154 FILE 1561 portable-loader、1562 CLAUDE.md、1563 README、1564 references/sources、1565 requirements、1566 SKILL.md 全文。src 不在计划内，**未读**。

发现：
1. **"最新研报观点"是用技术指标生成的**：README 写"基于技术面的机构观点汇总 / 数据驱动自动生成"，也就是由程序合成"机构观点"，并以"研报观点"的名义呈现，**有误导性**。
2. **含交易建议**：章节包括"交易计划（顺势/震荡/反转策略 + 仓位管理）"和"AI 总结（核心观点 + 操作建议）"，CLAUDE.md 还要求"AI 总结需……可操作"，与"不构成投资建议"的声明矛盾。
3. **"价格预测需附带置信区间"**：实际用的是 ATR 区间加"方向概率"，没有校准依据，所谓概率只是启发式数字。
4. **数据源口径不一致**：
   - SKILL 和 portable-loader 写"Pandadata + EIA + OPEC 月报"，README 写分析目标 Brent 来自 Yahoo Finance（BZ=F），新闻来自 Google News RSS；
   - OPEC MOMR 没有接口，不清楚如何获取；
   - CLAUDE.md 还列了 Reuters 和东方财富。
   - 多个来源混用（Yahoo 连续合约、EIA 现货、SC 主力），时区和收盘时点不同，"日涨跌幅"无法放在一起比较（示例中 Brent +2.66%、SC −3.17%，口径差异没有说明）。
5. 写有"SC 涨跌停 ±8% 或 ±13%"，属于规则描述，**未核实**；交易所会动态调整。
6. requirements 中 yfinance 只设很低的下限，Yahoo 接口不稳定；numpy<2.0。

与 EA 的关系：原油可作 NR07 关联市场的参考品种，但本资产属于报告生成类，方法不可直接借鉴。**未实现**。

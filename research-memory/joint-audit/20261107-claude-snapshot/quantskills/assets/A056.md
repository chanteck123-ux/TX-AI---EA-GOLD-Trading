## 要点
- A股五类资产（股票30/长债40/中债15/黄金7.5/商品7.5）基准偏好 ÷ 60日波动率归一；明确声明"不是严格ERC"，另以60日协方差报告 RC_i、最大贡献与HHI，只警示不反向优化。
- 宏观象限：CPI同比(PI0000047)、不变价GDP累计同比(NA0000014)；63交易日变化→60日多数平滑→20日磁滞；公布滞后近似 CPI+15、GDP+30 自然日；明确承认无 vintage，修订值前视无法消除。
- 时序：目标日 t 只用 t-1 及以前信息，下一共同交易日执行；完整季度末才出目标、残缺首季度不出、末季须自然季末确认；持仓按收益漂移，换手=漂移后实际权重→目标的 L1，过门槛才执行，成本=L1×cost_bps。
- 工程纪律：run_id 绑定参数；数据/源码 SHA-256 不一致拒绝覆盖；400自然日预热且不计入绩效；五类资产覆盖率≥80% 否则失败，不填0；HTTPS 强制、拒绝重定向、令牌仅进程内；RESEARCH_ONLY 标记。
## 独立发现
1. 收益口径疑点：数据层用 log(close/pre_close)，methodology §4 第4步写"用当日各资产简单收益更新"——若实现未做 exp(r)−1 转换会系统性偏差；脚本不可见，标"未核"。
2. 逐日回退链把 ETF、价格指数、期货主连拼接成同一资产序列：价格指数无分红/票息（000012.SH 是否全收益未说明）；国债期货收益不含抵押现金收益；拼接点口径跳变未单独诊断。
3. 期货主连的 pre_close 是否为同一合约前收（换月日）取决于供应商定义，文档称"可减少换月跳变"但未提供验证；与 A50 的"合约内收益链接"相比证据较弱。
4. 覆盖率通过后"只保留五类共同有收益日"：被删日期上其他资产的收益会被丢失（非顺延到下一日），净值可能失真；文档未说明对被删日的收益处理。
5. 宏观信号对月度/季度数据做63交易日变化+60日平滑+20日磁滞，加上公布滞后，总滞后可达数月；该设计偏稳健但象限识别迟钝，文档无滞后代价测算。
6. README 声明 MIT 许可（与其他多数资产 GPL-3.0 不同）；依赖第三方 panda_data 0.0.12 许可证未知，资料自己已标注。

- **dd_from_high 用的是哪种收盘价（PLAUSIBLE → CONFIRMED）**：
  - `drawdown_series` 使用 `close_adj`，由 `get_factor` 提供后复权收盘，口径正确。
  - 但 `load_price` 中有一句 `close_adj = close_adj.fillna(close_raw)`，**按天逐行**用不复权价补缺。如果 factor 接口某几天缺数据，同一条序列里就会混入后复权和不复权两种量纲。后复权价往往是不复权价的数倍，补入的这几天会形成虚假的"深度回撤"或"创新高"，直接影响 S4 破裂判定和 conviction 计数。注释称"趋势跨除权略失真，可接受"，低估了这个问题。
- **新发现**：
  1. **历史序列有前视，末日诊断没有（CONFIRMED，代码推演）**：
     - CogF 用 `ret2 = close.shift(-2)/close − 1`，即公告后 2 日收益，而分数从**公告当天** `out.iloc[pos:]` 开始生效。
     - ParF 用 `lead_corr = p_lead.rolling(win).corr(f_move.shift(-10))`，每一天都用到 10 日后的 F_slope。
     - `analyze(as_of=...)` 先截断数据再计算，所以末日诊断是干净的：公告日距末日不足 2 天的事件被跳过；末日的 lead_corr 因为 NaN 被置 0，lead_score 恒为 50。
     - 但 `compute_series` 的全序列结果会被 render 画成"阶段时间序列 score 折线"，这条历史曲线中的 CogF、ParF 分量（score 的 30%，即 dual 项）**使用了未来数据**。看图回溯会高估信号的历史表现。
     - test_pit_as_of 只比较末日的 stage 和 score，无法发现历史序列的泄漏。
  2. **ParF 的"价格领先基本面"分量在决策时恒为中性**：由于 `shift(-10)`，as_of 当天的 lead_corr 总是 0，ParF 只剩资本行为脉冲 `cap_pulse`（权重 0.4）在变化。文档宣称的功能在决策时点并不存在。
  3. 状态机 `_raw_stage` 和 `_run_state_machine` **不使用** CogF、ParF，只使用 P、F_slope、FB_long、DD 等，没有前视。阶段判定本身不受上述泄漏影响。
  4. **数据缺失时静默放行（fail-open）**：`_safe_call` 吞掉所有异常。质押接口失败或无记录时返回 `0.0`，而不是 NaN，`fragile` 因此不会触发，等于在数据缺失时默认"不脆弱"。融资和股东户数失败时为 NaN，没有 warning。
  5. 漏斗宇宙 `funnel_universe` 用不复权收盘计算 60 日对数收益，并按绝对值取前 300，涨跌都会入选。涨停判断用 `limit_up`，缺失时按板块比例推算，没有处理 ST 股 5% 的涨跌幅限制。
  6. 财报事件：`is_latest=False` 取出全部版本，每个季度优先取 `if_adjusted==0` 中最早公告的一版，按公告日生效，满足 PIT（CONFIRMED，做法正确）。
- **结论更新**：末日诊断和阶段机制没有前视，这是本批中少见做得对的地方。但历史 score 曲线有泄漏、复权价逐行回退会混入不复权价、质押数据缺失按 0 处理，这三点必须修正后才能用于回溯。对 V1.2 的启示：**任何"评估用"的未来收益都不能进入展示或回溯序列**；缺失的风险数据不能默认为安全值。

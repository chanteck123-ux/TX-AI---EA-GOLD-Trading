# A029 skill-alpha-f6-family-position-reverse（全文审核笔记）
- 读取（P0031）：AGENTS.md、CLAUDE.md、HERMES.md、OPENCLAW.md、README.en.md、开发版 SKILL.md 与 references/data_guide.md、production/SKILL.md（README.md 和根 SKILL.md 在后续包）。
- 内容：所谓"家人席位"（东方财富、徽商期货、平安期货，按字符串精确匹配；通常被视为散户集中的期货公司）的净仓位做反向信号。raw = −family/total；factor = 截面百分位 ×2 − 1；前 10% 买入，后 10% 卖出。Method A 收益口径同 A28，另有可交易口径（扣换月成本）。
- **独立发现**：
  - ①**缺失当作中性**：家人席位当天全部没出现在榜单上时 family_margin = 0，记录照常保留——"没上榜"被当成"零净仓"，而实际上可能只是排名不够进入数据源的覆盖范围。
  - ②席位名单硬编码且按字符串精确匹配：期货公司更名或分支机构名称变化都会导致静默漏匹配；validate 只要求"至少出现一家"。
  - ③研究口径的执行时点问题同 A28 ③。
  - ④期货品种只有几十个，截面前后 10% 每边只有几个品种，统计量很小。
- 对黄金 EA：COT 报告中的"非商业/散户"分类做反向，是同类思路；但缺失要标为 UNKNOWN，不能当 0，对照 A18 的规则。
- 续读（P0032）：README.md、根目录 SKILL.md。内容与前一包一致，没有新的公式；多了 test.py 合成数据离线自测（未运行）。

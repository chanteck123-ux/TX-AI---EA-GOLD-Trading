# A183 skill-residual-guided-factor-selection — Claude 全文审核（2026-11-05）

## P0219 后段（FULL_READ；FILES 1841–1843：portable-loader、README.en、README）
- 定位：残差引导的前向因子选择。用当前因子集合拟合 Ridge 或 LightGBM，计算候选因子与残差每日横截面相关系数的均值，取绝对值排序后扩展路径（单路径、Beam、穷举池）；按 CV 评分选出检查点并冻结，再单独执行 evaluate-oos；收益层回测交给 `$factor-backtest`。维护方为社区组织，README 明确写"未经官方审核"。中英文 README 一致。
- 优点：Train < Valid < OOS 三段有序且不重叠；用 embargo_bars 隔离重叠标签；OOS 只在冻结后由 evaluate-oos 使用；有 one-standard-error 规则；用 Jaccard 约束限制路径重叠；把组合与成本的计算交给下游；示例数据明确标为合成数据。
- **初步关注点（待读 algorithm 和 usage 后核实）**：
  1. **Ridge Beam 用 Train+Valid 开发期的样本内残差排序候选**，在 `search_objective: residual` 下还用开发期的加权 R² 保留路径。这样 Valid 既参与拟合残差，又参与路径选择，**已经不是独立的验证集**，只有 OOS 是真正的样本外。
  2. 单路径用 Train 的**样本内**残差：随着因子增加，样本内残差会被过度拟合，候选排序会偏向能拟合噪声的因子。
  3. `run-pool` 在容量溢出时删除"**完整样本** Ridge 绝对系数最小的因子"。如果"完整样本"包括 OOS，就会造成泄漏，要核实其定义。
  4. 股票池可以按"Train 标签覆盖率"固定：只保留在 Train 期有未来收益标签的股票，有轻度的幸存者偏差。
  5. 处理后的缺失值一律填 0，相当于填成截面均值或中位数，会稀释信号，在覆盖率低的因子上影响明显。
  6. 搜索空间很大（多次随机起点、Beam 宽度、深度、多种目标），文档没有要求登记全部试验次数，也没有做多重检验校正。

## P0220 前段（FULL_READ；FILES 1844–1849：algorithm、backtest_integration、downstream_evaluation、usage、requirements、SKILL）
- **对上一段关注点的核实结果**：
  1. run-pool 的容量裁剪：algorithm 写的是在"**完整开发期**"用 pruning_alpha 拟合 Ridge 后再删除，usage 写的是 "full-sample"。两处措辞不一致，但按 algorithm 的说法**不包括 OOS**，所以**不构成 OOS 泄漏**，只是在开发期内用样本内系数做裁剪。
  2. Beam 的 CV 折要求 fit 严格早于 score，并且整个折必须落在 Train+Valid 内，这是**因果 CV**。但 Ridge Beam 的候选排序用的是开发期**样本内**残差，`residual` 目标还用开发期样本内的 R² 保留路径，**这条路径下的 Valid 不是独立验证**（CV 指标只作为附带证据）。`cv` 目标下由因果 CV 决定，问题较小。单路径用 Valid mean IC 选检查点，Valid 的用途合理。LightGBM 使用 OOF 残差，做法正确。
  3. 股票池：`train_label_min_coverage: 0.95` 只保留 Train 期标签覆盖率达 95% 以上的股票，并沿用到 OOS，**会排除 Train 期间上市或退市的股票，造成幸存者偏差**；OOS 期间退市的股票因标签缺失被排除在指标之外，进一步高估。
  4. 示例 `embargo_bars: 1`，对 5 日或 20 日的重叠前瞻标签显然不够；文档要求"按标签期限设置"，但示例没有示范。
- 其他：
  - 回测交接只导出 prediction，**明确不导出 target**，有确定性的哈希和 manifest，ticker 映射要求唯一，防止数字前缀冲突；evaluate-oos 默认不覆盖已有结果。工程纪律良好。
  - SKILL 写明"冻结前不查看 OOS 输出"，但工具本身无法强制，需要靠使用者遵守。
  - `materialize` 支持 Alpha101、Alpha158、Alpha191 公式库，候选池可能上千个；`run-many`、`run-many-beam` 会做多次随机起点搜索，**没有要求登记总试验次数，也没有做多重检验校正**，即使 OOS 是封存的，选择偏差也只能靠这一次 OOS 来检验。
  - 处理后的缺失值填 0，覆盖率低的因子信号会被稀释（文档已说明）。

## A183 结论
- 这是本批中时序隔离做得最认真的因子选择工具：Train/Valid/OOS 三段、embargo、因果 CV、OOS 封存、one-SE、OOF 残差。
- 需要注意：①residual 目标下 Valid 不独立；②按 Train 标签覆盖率固定股票池，会带来幸存者偏差；③示例的 embargo 太短；④没有登记搜索空间。
- 对 V1.2：其"冻结后只评估一次 OOS、导出时不带 target、交接有 manifest"的纪律，可以作为指标组合选择的参考。scripts 未审。

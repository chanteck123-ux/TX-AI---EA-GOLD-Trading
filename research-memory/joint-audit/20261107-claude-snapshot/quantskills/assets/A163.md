## P0203（FULL_READ；FILE 1701 实现计划 part 1/2，Task 1–6 前半）
- 定位：以沪深300 指数权重为先验，用三条十分位多空视图（20 日动量、5 日反转、20 日换手）构造 Black-Litterman 组合，最后做 long-only 截断。计划按 TDD 写成，每个 Task 都给出测试和实现代码。
- **数据与前视问题**：
  1. **使用未复权收盘价**：`load_prices` 通过 `get_stock_daily` 取 close，协方差、动量和反转都直接用 `pct_change` 计算。A 股除权除息日的价格下跳会被当作真实收益，导致协方差、20 日动量和 5 日反转被系统性污染（分红集中的 6–7 月尤其严重）。应改用复权价，或用 pre_close 计算收益。
  2. 先验权重缺失时**退回等权**，只打一条 WARN 就继续计算，π 因此失去"市值均衡"的含义。测试中权重为 0.5、1.5、2.0（百分数），靠 universe 归一化处理，单位约定没有写明。
  3. universe 的文档说"1 年窗口内有效收盘价不少于 200 个"，代码实际统计 scan_date 之前的全部行（由 fetch_days=400 间接限定），与文档不一致。协方差中任何含 NaN（停牌）的股票都会被整体剔除，再与先验对齐，计划里没有说明这一步。
  4. 停牌股的前值填充或零收益没有处理；换手来自 get_factor，单位未知（A158 中 get_factor 的口径也有问题）。
  5. 测试 `test_ledoit_wolf_cov_uses_only_dates_strictly_before_scan_date` 只断言了形状，自己也注明"just assert non-crash"，**名称宣称验证无前视，实际并没有验证**。views 的无前视测试是有效的（注入 T 日极端价格）。
- **BL 设定问题**：
  1. 三条视图的 Q 都固定为 q_hat=0.05，而 Σ 和 π 是年化的，20 日或 5 日视图的收益期限没有换算，口径不一致。
  2. 动量和反转窗口重叠，视图之间相关，但 Ω 取对角（He-Litterman 惯例，可以接受，但应说明）。
  3. 因子方向（反转、换手取负号）是固定的先验假设，没有经过验证。
- **测试夹具的文字错误**：He-Litterman 测试的注释说"8-country""full 8-country table""match to 4 decimals"，实际是 7 个国家，容差 atol 为 0.006。π 的期望值（3.9、6.9、8.4、9.0、4.3、6.8、7.6%）和权重与原文大体一致（凭我对该文献的了解，没有对照原文，属 PLAUSIBLE）。
- 工程问题：硬编码 `/Users/since/...` 本地路径；`init_token` 没有传 base_url（A158 要求显式提供）；凭证读自环境变量 `PANDA_DATA_USERNAME/PASSWORD`，与 A158 的变量名不同；计划要求每个 Task 都 git commit，并带 "Co-Authored-By: Claude"。
- 优点：线性代数统一用 solve 而不用 inv，奇异时加 jitter 重试；退出码有约定；T-1 原则写入全局约束；views 的无前视测试设计得当。

## P0204（FULL_READ；FILE 1701 part 2/2，Task 6 后半至 Task 11、Self-Review、Execution Handoff）
- bl.py 中 π=δΣw、Ω=diag(τPΣPᵀ)、M=[(τΣ)⁻¹+PᵀΩ⁻¹P]⁻¹、μ_bl=M[(τΣ)⁻¹π+PᵀΩ⁻¹Q]、Σ_bl=Σ+M，都是标准形式。"求逆"仍用 solve(A,I) 实现，实质上仍在显式构造逆矩阵，"从不用 inv"的约束只是形式上满足。
- **优化器问题**：先求无约束解 `w=(δΣ)⁻¹μ_bl`，再把负权重截为 0 并归一化。这**不是** long-only 均值方差的最优解（应解带约束的 QP）。N≈300 时 Σ 接近病态，无约束解往往是极端多空，截断后权重会高度集中在少数股票，而且对 Σ 的估计噪声很敏感。monotone 测试只用了对角 Σ，暴露不出这个问题。
- 退化路径（所有权重被截掉，回退到先验）仍然返回 exit=0；顶层 `except Exception` 把所有异常都折叠成 exit 1 且不打印 traceback，调试信息全部丢失。
- 默认 scan_date 为今天；self-check 在单日做全市场探测（symbol=None），请求量很大。
- Self-Review 中"No gaps""internally consistent"是作者（LLM 计划）自己的评价，不是独立复核；我在 part 1 和 part 2 中找到的未复权价、Q 期限不一致、前视测试名不副实、截断优化器等问题，它都没有发现。测试数 8+6+4+7+6+4+3+1=39，算术正确。
- 来源：计划由 superpowers 工作流生成，每个 commit 都带 "Co-Authored-By: Claude"，是 AI 生成的计划。SKILL 已知局限中承认了 Q 是全局常数、Σ_bl 计算出来但没有用、没有成本和换手约束、没有滚动回测。

## A163 结论
- BL 数学部分（π、Ω、后验）是标准写法，solve 与 jitter 的处理较稳健，views 的无前视测试有效。
- **主要缺陷**：
  1. 使用未复权收盘价（文档里已有 pre_close 和 trade_status 可用）；
  2. "截断无约束 MV"不是 long-only 最优解，在 N=300 的病态 Σ 下权重会极度集中；
  3. 协方差的"无前视"测试只检查形状；
  4. μ_bl 复现这一验收项没有实现，Self-Review 却自称无缺口；
  5. 凭证处理不安全（明文写入 zshrc，并把账号回显到对话）；
  6. 校准结论没有证据。
- 对 V1.2：单品种黄金用不到 BL。可以迁移的经验是：AI 写的计划，其"自审通过"不能当作独立复核，验收项必须逐条对照设计核实。这与本项目"禁止将未执行写成通过"的规则一致。

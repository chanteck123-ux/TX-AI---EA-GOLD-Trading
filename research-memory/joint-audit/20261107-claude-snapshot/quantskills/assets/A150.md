# A150 skill-option-strategy-builder（A 股 ETF/指数期权策略卡）— 文本审核

## P0154 部分（FILE 1582 portable-loader、1583 examples/sample_report、1584 README.en 全文）

要点：
- 输入标的、观点、到期日和结构，自动选腿、定价，计算损益曲线、盈亏平衡点、净希腊字母和保证金。希腊值缺失时用 BS 补算，并标注为近似值；关键腿缺失时返回非零状态，不输出部分信号。

样例核算（50ETF 牛市价差：买 2.75C、卖 2.80C，合约单位 10000）：
- 净付权利金 (0.0572 − 0.0353) × 10000 = 219 元 ✓；最大盈利 0.05 × 10000 − 219 = 281 元 ✓；盈亏平衡 2.75 + 0.0219 = 2.7719 ✓。

发现：
1. **希腊字母的缩放口径不一致**：样例称"已乘合约单位与合约数"。delta +1360（≈0.136 × 10000）确实已乘单位；但 theta −0.60（"每年"）、vega +2.30（"IV 变动 100%"）、rho +2.30 看上去**没有乘 10000**——一份 1 个月的平值价差，按 10000 单位计算，年化 theta 和每 100% IV 的 vega 应在数百元量级。正文"IV +1% ≈ +0.02 元"也与未缩放的数值一致。另外 rho 与 vega 的数值恰好完全相同，可疑（Claude 静态推算，未运行）。
2. theta 写作"每年时间价值损益"，又解释为"负 = 持仓每日损耗"，单位表述自相矛盾。
3. 买入腿也列出了"单位保证金 2510"，但买方并不缴纳保证金；合计只算了卖腿，展示方式容易误导。
4. 估算 IV 0.1666 与"标的现价（估）2.752"都是离线样本，已注明"后端 sample"。

## P0155 补读（FILE 1585 README、1586 references/greeks、1587 references/strategies、1588 requirements、1589 SKILL.md 全文）

发现（续）：
5. **同一仓库里关于希腊字母数据可得性的说法互相矛盾**：
   - README 写道（2026-07-27 实测）："`get_option_risk_indicators` 当日 5 万多条记录**全部是商品期权**，gamma/vega/theta/rho 全部为 None，**SSE/SZSE 的 ETF 期权当日 0 条**"；
   - greeks.md 和 SKILL 却写："ETF/指数期权五个希腊字母通常齐全，优先直接使用""完整希腊字母以 ETF 期权为准"。
   - 二者互相否定；按 README 的实测，样例报告中 50ETF 各腿标注的"希腊来源[interface]"也**不可能成立**。
6. **IV 缺失时的处理互相矛盾**：README 和 SKILL 写"不使用固定 0.20，没有真实价格时 status=failed"，greeks.md 却写"IV 缺失时默认 σ=0.20，并在 degraded 中声明"。
7. 模型适用性：
   - 统一使用欧式 BS，而商品期货期权多为**美式**（部分品种），BS 会低估提前行权价值；期货期权本应使用 Black-76。
   - 分红率 q 默认 0，ETF 有分红，除息期间认购和认沽的价格会有偏差。
   - 以上限制文档都没有说明。
8. 保证金估算只用"权利金 + 12% × 标的价 × 合约单位"一条规则，与交易所实际公式（含虚值额扣减和最低保障）不同，**未核实**；文档已写明"以券商或交易所为准"。
9. 日历价差在近月到期时用 BS 重估远月时间价值，需假设 IV 不变，文档已声明这一局限。

**A150 结论**：文本全部覆盖（共 8 份全文）。损益与盈亏平衡计算正确，但希腊字母的数据可得性和缩放口径、IV 默认值都存在文档自相矛盾，模型适用范围也没有写清。与 EA 无关。

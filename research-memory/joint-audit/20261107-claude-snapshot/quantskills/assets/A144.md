# A144 skill-…-mental-model（以投资人命名的"五维心智模型 + 一票否决"A 股评分）— 文本审核

说明：按项目规则，不复述资产名中的人名，只用 A144 和"五维心智模型评分"原型指代。

范围：P0149 FILE 1524 AGENTS.md、1525 CLAUDE.md、1526 HERMES.md、1527 references/data_guide、1528 子目录 SKILL.md、1529 生产产物/ANALYSIS_REPORT.md、1531 OPENCLAW.md、1532 README.en、1533 README 全文。FILE 1530 生产产物/SKILL.md 为 HASH_REUSE：与 skill-alpha-f5-member-position-concentration 的生产 SKILL **字节完全相同**，说明生产文档是从另一个因子资产原样复制的，与本资产不对应。

要点：
- 五个维度：财务（ROE、毛利率、OCF 与行业中位数比较）、竞争（行业内百分位）、激励（大股东/高管行为、质押）、"心理"（投资者活动与机构数）、负面清单（一票否决）。
- 判定：任一维度否决即判 veto；任一维度数据不足即 insufficient_data；五维全部通过才判 pass。

发现：
1. **同一维度有三套互不兼容的公式**：
   - 激励维度：data_guide 写"前十集中度 + 质押冻结 −20 + 高管净增持计数"；SKILL 写"三信号各占 33.33%，基线 60 分"；ANALYSIS_REPORT 又写"集中度安全区间 30–70%，超过 70% 时按 ((1.0−x)/0.30)×100 衰减"。
   - 心理维度：data_guide 用 /12（月频），SKILL 用 /60（周频）。
   - 实际实现以哪一套为准**无法从文档判断**（scripts 不在计划内）。
2. **运行结果不可复现**：ANALYSIS_REPORT 称财务维度从 33.33 变为 100.0 的"修正方法"是"**重新运行脚本后数据获取正常**"，同一输入两次运行的结果不同，与 SKILL 所称"同一股票同一日期结果应一致"相矛盾。机构数从 0 变为 346 是改了代码中的列名识别，属于缺陷修复，但改动后没有重新登记版本（data_version 仍是 "real-v1"）。
3. **PIT 声明与实现描述不符**：SKILL 写"每个维度仅使用 ≤ 基准日的数据"，data_guide 却写"Fetch latest financials per stock"（取最新财报）。用历史 end-date 回放时，可能使用基准日之后才公告的财报。validate.py 只检查 `trade_date ≤ 今天`，这**不是前视检验**。
4. **异常数据未被质疑**：报告称"前十大股东持股 100%"，并据此判为"治理严重缺陷"。前十大合计 100% 在上市公司中几乎不可能，更可能是字段口径（例如流通股东或计算错误）问题，却被当作事实写入投资评价。
5. **否决规则过严**：只要"历史中出现过多个不同的审计机构"就触发否决；报告自己承认这次是"知名大所正常轮换"，结论仍为 veto。报告还给出了"适合/不适合的投资者"这类建议性表述，与"不构成投资建议"的声明冲突。
6. 命名问题："心理维度"实际只统计调研次数和机构数，与心理或情绪无关；竞争维度中 20% 的"集中度奖励"恒为 0，满分实际只有 80。
7. ANALYSIS_REPORT 写入了作者本机的绝对路径（含用户名），本审核不转录；生产 SKILL"来自 alpha-f5-member-position-concentration"，即复用了别的资产的文档，可能与本资产不匹配（FILE 1530 待核）。
8. panda_data 版本写 "latest"（未钉版本）。

待续：P0150（根 SKILL.md）。

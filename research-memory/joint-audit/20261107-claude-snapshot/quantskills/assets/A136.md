# A136 skill-market-daily-review（A 股收盘复盘）— 文本审核

## P0139 部分（FILE 1412 portable-loader、1413 README.en、1414 README、1415 references/pandadata-map 全文）

要点：
- 流程：交易日检查 → 采集 5 组数据（指数估值、宽度、行业概念、龙虎榜与大宗、两融与北向）→ 计算指标 → 按模板渲染 → validate_report.py 校验 → 写入 reports/daily/YYYYMMDD.md。
- 每个交易日 18:30 定时运行，等两融、北向等延迟披露数据入库；两融与北向必须标注实际数据日（T+1）。
- 降级：全市场聚合失败时，保留指数和龙虎榜章节，"不估数"。

初步发现：
1. **章节数自相矛盾**：徽章和章节表写 7 个章节，校验器说明写"9 个必备章节"，待 P0140 的模板与 SKILL 核对。
2. 行业和概念涨幅"按成分股聚合"计算，但没有说明是等权还是市值加权，是否剔除停牌或新股；成分股是当日成分还是最新成分（幸存者偏差）也没有说明。
3. 估值分位所用的窗口没有说明。
4. 18:30 的固定时点是经验值，两融数据实际可能更晚，T+1 标注能缓解这个问题。
5. 幂等覆盖同名报告，会丢失历史版本（同 A133）。

待续：P0140。

## P0140 补读（FILE 1416 references/report-template、1417 SKILL.md 全文）

补充：
- 模板结构：标题 + 摘要 + 第 1–7 节（第 7 节为数据说明）。徽章说"7 个章节"，校验器说"9 个必备章节"，两者大致对得上（标题、摘要再加 7 节），但口径表述不一致。
- 宽度口径只写了"说明是否含 ST、是否含一字板"，没有规定默认值。北交所 30%、创业板与科创板 20%、主板 10% 的涨跌停幅度不同，文档也没有要求按板块判定。
- 元数据标为 `status: stable`、`maintainer_type: official`，但 creator 和 maintainer 是社区账号，**标注口径矛盾**；license 一处写 GPL-3.0-only，另一处写 GPL-3.0。

**A136 结论**：文本全部覆盖（共 6 份全文）。这是事实归纳型复盘模板，T+1 标注、绝对日期、不估数、降级记录都做得好；聚合口径（加权方式、板块涨跌停幅度、成分时点）没有写明。与 EA 无关。

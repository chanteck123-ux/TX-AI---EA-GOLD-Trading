# A138 skill-material-contract-alpha（A 股重大合同因子 A10，Draft，GPL-3.0-only）— 文本审核

范围：P0141 FILE 1427–1433 全文（portable-loader、README.en、README、references/data_guide、SKILL.md、生产产物/SKILL.md、生产产物/发布验收报告.md）。scripts/、parquet 和 json 不在计划内，**未读**。

要点：
- 因子 A10 = log1p(当日每只股票所有公告的 max(max_contract_amount, min_contract_amount) 之和)。
- 可成交口径：t 日（公告日）收盘后形成信号，t+1 开盘成交；跳过一字涨停、停牌和无有效价格的标的，收益从 t+1 起算。

发现：
1. **信号规则自相矛盾**：
   - README（中英文）写"横截面 z-score，>+1σ buy、<−1σ sell"；
   - data_guide 和 SKILL 写"min-max 缩放到 0–100，≥70 buy、≤30 sell"。
   - 两套规则不同，结果也不同。
2. **横截面只包含当日公告的股票**：
   - "sell"实际上是"当日也公告了合同、只是金额较小"的股票，经济含义可疑（公告本身可能是利好）；
   - 当日只有 1 只股票公告时，min = max，min-max 缩放的分母为 0；
   - 金额没有按营收或市值标准化，因子主要是在挑大公司；
   - currency 字段存在，却没有说明是否做了币种换算。
3. **L1"未来函数检查"是同义反复**：检查的是"trade_date 等于 max(info_date)"，这在构造上必然成立，并不能检验前视。L3"样本外"只检查测试集有信号、覆盖 ≥5 只股票、std>0.01，**不是绩效检验**。
4. **验收报告与结论矛盾**：
   - 报告数据：IC 均值 −0.0485、Rank IC −0.0413、ICIR −1.22；buy 平均净收益 −0.13%、胜率 47.48%、最大回撤 −29.34%、换手 99.65%；多空 L5−L1 为 −0.09%，L4 最差。
   - 但发布结论是"**通过（流程验收）**"，"标准成本与压力成本发布门禁：通过"。门禁显然只检查流程，不检查绩效，表述会误导读者。
   - 方向上，因子按降序做多，但 IC 为负，说明方向可能相反。
5. **报告内部数字不一致**：
   - "可成交评估交易日 20250303~20250331"（只有 1 个月），而回测分 3 期，到 20250731；
   - 覆盖股票数一处写 313，另一处写 347；
   - ICIR 只基于 3 期计算，统计意义极弱。
6. **生产文档与数据纪律矛盾**：SKILL 写"Data source: panda_data only"，生产 SKILL 却写"降级处理：主数据源失败时启用备用"；"支持实盘交易信号生成"与"仅研究"的定位冲突。
7. 认证经 `http://`（明文）的 base URL 发送账号和密码，属传输安全问题（文档示例，未含真实凭证）。
8. **跨资产矛盾**：本资产调用 `get_stock_material_contract`，而 A131 的 quality_evidence 称该接口"在 PandaData 最新 187 个方法中**不存在**"。二者至少有一方过时，**未核实**。

**A138 结论**：文本全部覆盖（共 7 份全文）。可成交口径（t+1 开盘、跳过一字板和停牌）写得正确，但因子构造、验证层设计和"通过"结论都有问题，验收结果显示 alpha 为负。与 EA 无关。

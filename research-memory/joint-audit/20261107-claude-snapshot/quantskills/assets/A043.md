# A043 skill-buffett-moat-screener-lavine-version（全文审核笔记）
- 读取（P0044）：agents/portable-loader.md、CHANGELOG.md、production/SKILL.md、README(.en.md, .md)、references/{data_guide, methodology, source_boundary}.md、requirements.txt、requirements-dev.txt（SKILL.md 见后续包）。
- 内容：同一个 Q44 主题的另一个实现——**硬条件交集**加**三态输出**：pass（全部适用规则通过）、fail（证据完整，但至少一条规则明确失败）、insufficient_data（缺失、冲突、非法、历史断档）。**已知的非正利润或 EPS 判为 fail，不算缺失**。
- **本批资料中工程纪律最好的资产之一**：
  - **fail closed**：缺失、非有限值、分母非正、最新版本冲突，一律判为 insufficient_data；未知行业**绝不默认按非银行处理**；
  - 无效日期**不按字符串比较**，空日期或非法日期永远不视为"可见"；
  - **财报修订**：is_latest=False 并保留 `if_adjusted` 标志（0 = 本期原值，1 = 被后续公告重述的比较期数值），在每个决策日选择当时实际可见的最后版本；
  - **可复现性**：缓存命名空间绑定 SDK 版本、base URL 哈希、匿名账号哈希和字段契约；每个缓存响应都有原子 manifest（抓取时间、schema、行数、规范化后的 SHA-256）；`source_snapshot` 是本次运行实际使用的全部响应的聚合哈希；`dataset_version` 绑定排序后的股票池哈希；输出带 rule_config_hash 和 runtime_versions；
  - **生产写入防护**：按主键 upsert 并保留其他日期；**子集运行不能写入正式数据库**；整库替换必须显式使用 `--replace-production`；
  - **方法冻结文件**：边界条件（≥ 还是 <）、ddof=0、"十年回报需要十一个连续年度资产负债表日期"等都写死并带版本号；
  - 37 项测试（自述），覆盖阈值边界、未来版本、同日冲突、缓存 manifest、并发认证、防覆盖、年度诊断等；
  - CHANGELOG 记录了：v1.1 把 Jaccard 换手改为等权单边换手；前瞻收益缺失时年度诊断直接失败；v1.2 把初始权益计入最大回撤、拒绝重叠的行业归属。
  - 已验证快照（2025-12-31，自述）：5,182 只股票中 pass 17、fail 3,386、insufficient_data 1,779，**明确说明这不是历史收益证据**。
- **独立发现**：
  - ①**债务部分缺失时偏宽松**：债务 = 三个已验证字段中"可用数值之和"，只有三个都为空时才视为缺失。如果只有一个字段有值、另外两个为空，空值实际上被当作 0——在"债务/利润 < 4"这道门槛上偏向通过，**与全局 fail closed 的原则不一致**。应改为任一字段缺失就降级为 insufficient_data，或至少单独标注"部分缺失"。
  - ②1,779/5,182（34%）为 insufficient_data——fail closed 的代价是覆盖率；报告里应同时说明 insufficient 的主要原因分布（顶层 diagnostics 已经提供，做法正确）。
  - ③与 A42 是同一编号（Q44）的两个不同实现（软评分与硬门槛），读取方需要靠 data_version 或 rules_version 区分，否则容易混用。
- **A43 逐资产结论**：工程实现标准很高。lavine_buffett 源码不在清单内，**未做静态实现核查；测试数量和快照是资料陈述，未运行**。

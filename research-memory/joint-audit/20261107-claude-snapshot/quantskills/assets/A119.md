# A119 skill-holder-structure-scan — 文本审核

阅读范围：**全文**——FILE 1274 portable-loader、1275 README.en、1276 README（与英文版等价）、1277 playbook、1278 SKILL。

要点：
- A 股股东户数及户均持股趋势、前十大合计占比（流通口径与总股本口径不混用）、自由流通占比；
- 按 end_date 对齐，至少看多期方向；
- 区分锁定型集中与可流通集中；
- 质押/冻结作为风险标记；
- 信号互相冲突时记为"稳定/混合"。

独立发现：
1. **户均持股会受股本变动干扰**：户均持股 = 股本 / 户数。送转、配股、定增、可转债转股都会提高户均持股，并非筹码集中。文档把"户均↑ = 集中"作为确认信号，却没有要求剔除股本变动（例如用户数环比代替，或以期初股本标准化）。
2. **两种口径的前十大不只是分母不同**：
   - `stock_type=flow` 返回前十大**流通股东**名单，`total` 返回前十大**股东**名单，两份名单本身就不同；
   - 文档把两者描述为"同一组股东的两个比例字段"（hold_percent_float 对 hold_percent_total）；
   - 若用 total 名单去加总 hold_percent_float，会混合两种口径。实际行为需要按接口核实。
3. **自由流通占比的分母**：A+H 两地上市的股票，total 与 total_a 差异很大，文档只要求"标注分母"，没有给出默认值。
4. `pledge`、`freeze` 是股数，需要除以对应股东的持股数才能判断风险程度；文档只说"作为风险标记"，没有给出比例口径。
5. 时点处理较为规范：按 end_date 对齐，同时保留公告日 date，并说明披露滞后。不过，若要用于任何信号，应以公告日为可得日（与 A096、A108 同类原则）。

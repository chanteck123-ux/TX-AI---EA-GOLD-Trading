## P0201 前段（FULL_READ；FILES 1685–1693：README、alpha-beta-timing、attribution-layers、brinson、factor-attribution、report-format、source_boundary、scripts/requirements、SKILL）
- 中英文 README 逐段对照，内容一致。
- **主要问题**：
  1. **Brinson 交互项被重复计入**：brinson.md 把"选择效应"定义为 Σ(w_p−w_b)(r_p,i−r_b,i) + Σw_b(r_p,i−r_b,i)（即交互项并入选择），同时又单独列出交互项 Σ(w_p−w_b)(r_p,i−r_b,i)，并声称"三者之和恒等于超额"。如果交互已经并入选择，再单独加一次就会重复计算，总和会比超额多出一个交互项，对账必然失败。文档自己在"常见陷阱"中提醒要声明采用哪种惯例，但公式表把两种写法混在了一起。实际以哪种为准取决于 `brinson.py`，该脚本未审。
  2. **没有多期链接**：通篇没有提到 Carino、Menchero 或 GRAP。逐日的算术效应相加不等于区间的几何超额，"对账小于 1e-6"只在单期或算术口径下成立；报告声称的区间对账依据不足。对比 A162，后者明确用 Carino 链接解决了这个问题。
  3. 缺少基准行业权重时，用"组合行业分布近似"，这会使 w_b=w_p，配置效应和交互效应恒为 0，结论被系统性扭曲，不能只"标注"了事。
  4. 第 3 层 Alpha 残差是按定义计算的残差，所以"Σ贡献 + Alpha ≈ 超额"恒成立，这项对账只是同义反复，证明不了任何东西。第 1 层的 `α + β·mean(R_m) = mean(R_p)` 也是带截距 OLS 的代数恒等式。
  5. frontmatter 写着 `repository: wangofcong/...`，但 organization 是 quantskills，`validation_level: listed`，`status: stable`，来源和状态标注不一致。
  6. 优点：口径要先声明；净收益和毛收益不能混用；Alpha 残差不等于可持续的 alpha；缺少材料时降级处理，不编造。
- 对本项目：V1.2 是单品种 GOLD，行业 Brinson 不适用。第 1 层（β 对基准）和"对账有恒等式，但不能被同义反复冒充"的原则可以参考。

# A209 skill-tqx-data-research — Claude 全文审核（2026-11-05）

## P0247 后段与 P0248 前段（FULL_READ；FILES 2086–2095：portable-loader、README.en、README、references 下 factor_codegen_assistant、output_contract、prompt_template、research_rules、source_boundary、strategy_codegen_assistant，以及 SKILL）
- 定位：用 `tqx_data` wheel 读取本地 Parquet，对港股和美股自动生成因子分析或回测代码，并**直接运行**。中英文 README 一致。
- **优点**：
  - 时点 t 收盘后形成的信号最早 t+1 生效，禁止当日信号吃到当日收益；
  - 截面 IC 要求每个日期至少有 5 只有效股票，不把单只股票的时序相关称作 IC；
  - 没有交易时要解释信号覆盖情况，不把风险指标写成 0；
  - 失败时返回阶段、原始异常和下一步，不伪造指标；
  - 可信度检查清单包括停牌和上市状态、复权、信号与成交错位、幸存者偏差、成本、参数敏感性。
- **问题**：
  1. **供应链风险**：必须安装"项目提供的 `tqx_data` wheel"，它是读取数据的唯一适配器，但来源、版本、哈希和许可证都没有说明。这是二进制依赖，Claude 不会安装或运行。
  2. **默认参数加自动执行会放大多重检验**：明确要求"不因未指定次要参数而停摆"。缺参数时，均线默认 5/20 日，区间默认最近 2 年，资金默认 100 万，然后直接运行。每次请求都会生成新代码并跑出新结果，但没有试验登记，不记录试验次数，与 V1.2 §11 的研究试验计数要求相冲突。
  3. **成本没有默认值**：只说"披露成本假设"和做"成本敏感性"，没有规定默认成本。如果成本缺省为 0，回测会偏乐观（PLAUSIBLE）。
  4. **复权与股票池口径**：复权虽在检查清单里，但 `get_hk_daily` 和 `get_us_daily` 返回的是否为复权价没有说明；股票池来自本地 Parquet，现有快照可能带有幸存者偏差，文档只在检查清单里提到，没有具体处理办法。
  5. 生成的代码写进 skill 自身的 `scripts/tests/`，研究产物和工具代码混在一起，无法区分版本。
- 没有发现个人信息。

## A209 结论
- 防前视规则可取。"缺参数就用默认值自动运行"的做法与 V1.2 的试验登记和冻结原则相冲突，不可采用。脚本未审。

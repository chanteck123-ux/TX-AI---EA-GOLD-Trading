# A149 skill-optimal-transport-cross-sectional-factor（一维最优传输截面因子，Draft）— 文本审核

范围：P0154 FILE 1567 portable-loader、1568 examples/collaboration-verification、1569 HERMES.md、1570 README.en、1571 README、1572–1580 references 九份、1581 SKILL.md 全文。

要点：
- 每个交易日把 date × symbol 特征截面看作加权经验分布，与**严格早于 T** 的 pooled 历史参考分布比较（默认 252 日，至少 80 个有效日）。
  - 精确计算一维 W1 = ∫|F_P − F_Q| dx；
  - 把每个观测的质量中点分位数映射到参考分位函数，得到 transport_target，位移 = target − x；
  - 多个特征按固定权重组合成 transport_pressure，特征缺失时不动态换权。
- 主视角是行业内传输并做组内中心化，全市场只作诊断。
- 评估交接：T 日收盘计算、T+1 生效；标签为 5 日开盘到开盘；Rank IC 为主，HAC lag 4，等权五组；开发/验证/冻结按自然年约 60/20/20 划分；探索性变体分组后做 BH-FDR 校正；主检验在看结果前登记。

评价：
1. **PIT 与预登记纪律良好**：参考分布严格滞后，行业标签需版本化且在 T 时可得，财务字段没有可得日的只能作探索用途，合成数据明确声明不等于真实验证，与 A142 的纪律一致。
2. 数学描述正确：一维 W1 等于两个 CDF 差的积分；单调传输由分位函数映射得到。
3. 经济含义有限："位移"本质上衡量的是"当前值相对于历史 pooled 分布的分位偏移"，接近于特征的时间序列标准化或排名变化。文档自己也说"不代表反转或交易方向"，因子能否有效尚待验证。
4. pooled 历史分布混合了不同时期的个股构成（宇宙漂移），参考分布会随成分变化而移动，文档没有讨论这一点。
5. overlap-review 提到"账户可见范围内 224 个仓库，其中 55 个为私有 Skill 仓库"，属于组织内部信息，本审核只作记录。
6. examples 只用合成数据验证，`validation_level: listed`，**没有真实数据结果**。

**A149 结论**：文本全部覆盖（共 16 份全文）。方法严谨、边界诚实，但目前只有机制验证，没有有效性证据。与 EA 的关系：W1 距离可作为"当前波动或点差分布相对历史是否异常"的诊断思路（属 DR01 一类的风险状态识别），**未实现**。

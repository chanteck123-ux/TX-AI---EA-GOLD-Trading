# A125 skill-investment-decision — 文本审核

## P0128 部分（FILE 1316 portable-loader、1317 README.en、1318 README、1319 agent-integration 全文）

中英文 README 等价。

要点：
- 输入任意公司，通过 Yahoo Finance（yfinance）与网络搜索获取信息，按 6 维加权评分，输出**长期 BUY / NEUTRAL / SELL 建议及"置信概率"**，并生成 .docx 报告。

独立发现：
1. **直接给出买卖建议**，并使用"Analyze 000001.SZ … give me a BUY/SELL recommendation"作为示例，与套件"只述不荐"的边界相冲突。末尾的免责声明不能改变产出的性质。
2. **"置信概率"实际上是评分的换算，不是概率**：smoke 样例中 total_score = 7.3 → confidence = 0.73，即总分除以 10。没有任何校准依据，却被称为 "confidence probability"，容易误导。
3. **"校验失败最多重试 5 次"**：让代理反复改写报告直到通过 validator，等于教代理去迎合校验器，校验因此失去独立性。
4. 数据源为 Yahoo Finance 的非官方接口（yfinance）与网页抓取，涉及服务条款与数据准确性；A 股和港股的财务字段在 Yahoo 上常有缺失或口径不一致，文档没有提醒。
5. 示例中出现 "AAPL.NB" 这一不常见的代码写法，可能是笔误。
6. 网络搜索获得的"分析师评级/新闻"直接进入评分，没有记录来源时点，不可复现。

与黄金 EA 的关系：无。

待续：SKILL.md、decision-contract 与 scripts 在后续 pack 中读取。

## P0129 补读（FILE 1320 decision-contract、1321 requirements、1322 SKILL.md 全文）

逐项核算（文本推导，**未运行**）：
- 权重 20/20/20/15/10/15 合计 100%。
- 示例 JSON：7×0.2 + 6×0.2 + 6×0.2 + 6×0.15 + 7×0.1 + 7×0.15 = 6.45 ✓。
- smoke 样例：8/8/6/7/8/7 → 7.30 ✓。

独立发现：
1. **评分映射存在空档**：BUY 为 ≥ 7.5，NEUTRAL 为 5.0–7.4，SELL 为 < 5.0。总分是连续值（示例 6.45），落在 (7.4, 7.5) 之间的值没有定义；R9 "推荐须与映射一致"在这一区间无法判定。
2. **置信度的定义自相矛盾**：
   - BUY：confidence = score/10；SELL：(10 − score)/10；NEUTRAL 未定义，但示例中 NEUTRAL 6.45 → 0.65、7.3 → 0.73，即同样取 score/10；
   - 结果是：总分越接近 BUY 门槛，"NEUTRAL 的置信度"反而越高（7.4 → 74%），语义颠倒；
   - BUY 的最低置信度为 75%，SELL 在 4.9 时只有 51%，两边不对称；
   - 这个数被称为 "confidence probability"，但没有任何校准。
3. **示例 JSON 内部错配**：meta 中是 ticker "MSFT"、"Microsoft Corporation"、market "us"，而正文是一家深圳的全国性股份制银行（上市日 1991-04-03、Banking、北向资金、thesis 中的银行名称）。R1–R13 都不检查 meta 与正文是否一致，validator 会让这份报告 PASS。
4. "股东户数收缩 = 吸筹信号"被写成固定解读，与 A119 自身的提醒（需结合股本变动等因素）相矛盾。
5. 1/3/5 年 PE 历史分位"由价格与财务数据自行计算"，但 yfinance 通常只提供约 4 年年报和最近几个季度的数据，5 年分位缺乏可靠的数据基础。文档却宣称 "NO N/A values"。
6. R8 只检查"日期不在未来"，不检查新闻、评级的时点与 data_period_end 是否一致，因此无法防止网络搜索带入数据截止日之后的信息。
7. "校验失败最多重试 5 次"在 contract §7 中被写成"自动纠错"，即让代理按校验器的提示改写报告直到通过。

结论：A125 文本全文读完（FILE 1316–1322）；scripts（fetch_data、validate_report、generate_report）**未核查、未运行**。与黄金 EA 的关系：无。可迁移的反例："置信度"不得由评分线性换算后冒充概率。

# A116 skill-hk-us-insider-radar — 文本审核

## P0123 部分（FILE 1259 portable-loader、1260 README.en、1261 README、1262 insider-playbook 全文）

中英文 README 等价（中文版多出定时任务、安装方法和二维码）。

要点：
- 港股用 `get_stock_insider_trade`，美股用 `get_stock_insider_transaction`，两者 schema 相同；
- 方向由有符号股数 + transaction_type 双重判定；
- 头条净额只计公开市场交易，期权、赠与、计划减持单列；
- 按 info_date 设窗口（PIT 正确），并说明申报滞后；
- 金额按币种分列。

独立发现：
1. **金额口径不一致**：
   - Value = |adjusted_trade_shares| × transaction_price；
   - adjusted 股数经过公司行动调整，而 transaction_price 是原始成交价（未说明是否调整）；
   - 拆股后两者相乘会得到错误的金额。
   
   playbook 一方面"优先使用 adjusted_*"，另一方面计算金额时没有配套调整价格。
2. **联合申报重复计数**：
   - 一份申报列出多名内部人（如董事本人与其控制的实体，同一批股票的间接持有）时，每人一行；
   - 按 symbol 汇总净额会把同一笔股票重复计算；
   - `is_main_role` 只用于"归属"，netting 规则中没有去重步骤。
3. **计划内卖出的识别**：
   - 依赖 transaction_type/acquisition_type 文本中的 plan 标记；
   - 若数据源没有该标记（例如美国 Form 4 的 10b5-1 勾选项是近年才有的字段），计划内卖出会被归入"公开市场卖出"，夸大减持信号；
   - 字段可得性**未核实**。
4. 聚集检测要求"点名内部人"——报告会列出真实个人的姓名与交易。这属于公开申报数据，但在本项目的资料审核中，按规则**不复述任何人名**。
5. 文档提到 0004.HK"六次卖出至清仓"的例子来自接口文档。本审查未核实。

与黄金 EA 的关系：无。

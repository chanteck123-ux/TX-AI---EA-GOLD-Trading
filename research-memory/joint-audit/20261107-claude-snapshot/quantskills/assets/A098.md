## P0109 部分（FILE 1068–1070 全文：agents/portable-loader.md、README.en.md、README.md；双语 README 逐段对照，内容等价）

要点：把自然语言请求转成 Pandadata 期货 DeepView 调用计划，输出事实与推断分离的中文研判报告。
- 四种模式：席位博弈、结构研判、库存现货、全品种扫描。
- 四道约束：先查契约、小样本试调、同日（trade_date）对齐、事实与推断分离。
- 席位数据须声明披露覆盖度（仅前排名席位）；不输出交易指令。

独立发现（静态阅读）：
1. **接口数量三处不一致**：徽章与正文写"35 个 DeepView 接口"；接口地图标题写"8 组 38 个方法"；按主题表逐行计数为 5+9+5+6+3+5+3+3 = **39** 个方法。（静态计数）
2. **"价/仓/资金同向 = 确认"属叙事型规则**：席位博弈配方把方向一致当作"确认"、相反当作"背离"，但没有说明阈值、统计依据或历史检验，属于规则化推断。README 定位为"数据事实归纳 + 规则化推断"，表述诚实，但读者容易把"确认"当成信号强度。
3. 正面：
   - "同日对齐、禁止跨日拼接"可防止伪信号；
   - "先冒烟后批量"；
   - "'必然上涨'不允许出现"；
   - 推断与事实分开标注，并附方法、参数、数据截止日和行数。
   
   这些报告纪律与本项目"区分已验证/未验证、原始证据留存"一致。

与黄金 EA 的关系：只适用于中国期货席位数据，不进入 XAUUSD 交易路径。"同日对齐"与"事实/推断分离"的报告规范可用于 MCP 监控侧摘要。不引入代码。

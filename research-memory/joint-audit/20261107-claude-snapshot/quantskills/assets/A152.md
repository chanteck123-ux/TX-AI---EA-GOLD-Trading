# A152 skill-overseas-equity-factor-miner（港美股截面因子挖掘，Draft）— 文本审核

范围：P0156 FILE 1595 portable-loader、1596 README.en、1597 README、1598 references/methodology、1599 references/pandadata-overseas-map、1601 SKILL.md 全文。FILE 1600 source_boundary 为 HASH_REUSE。

要点：
- 流程：定调仓日历 → 生成候选因子 → 拼装 PIT 面板 → 截面计算（基本面因子按同业中位数归一）→ 逐个计算 Rank IC、IC IR、衰减和换手 → 按 IC IR 排序并惩罚换手，输出 top-K。
- 港股与美股严格分开，不混用币种；数据缺失写"无数据"，不编造 IC。

发现：
1. **"宽表最新快照"导致前视**：`get_stock_mktfin_indicator` / `_metric` 被描述为"**latest** market-financial snapshot（每个代码一行最新值）"，而价值因子（EV/EBITDA、PE 等）取自这张表。对历史调仓日 t 计算价值因子时用的是**今天**的估值倍数，与 SKILL 自称"强制 PIT"直接矛盾。
2. **口径去重优先选择"Restatement"**：长表默认保留 Recent To Recent，并"优先 Restatement"。重述数据在 t 时并不存在，同样构成前视；A131 已经因为同一问题修复过 PIT 逻辑，"原始公告优先"才是 PIT 的正确做法。
3. **同业中位数的时点不明**：`get_stock_industry_median` / `get_stock_sector_median` 是否按 t 提供历史值，文档没有说明；若只有最新值，归一化本身也会前视。
4. **幸存者偏差的处理无法落实**：文档要求"t 时的存续股票池、不回填今天的指数成分"，但列出的 HK/US 方法中没有历史指数成分接口，执行手段缺失。
5. **样本内挖掘、没有多重检验控制**：文档承认是"样本内描述"，但候选族很宽，又按 IC IR 选 top-K，没有留出期、没有 FDR 校正（对比 A149 预登记加 BH-FDR、A142 的 DSR）；"|IC| ≳ 0.03 且 IR ≳ 0.3"的门槛容易被噪声满足。
6. 有两处优点：一是承认重叠的前瞻收益会使 IC 序列自相关；二是兜底时 Yahoo 只用于价量，并且要标注来源。

**A152 结论**：文本全部覆盖（6 份全文 + 1 份 HASH_REUSE）。纪律写得完整，但宽表快照、重述优先、同业中位数时点不明，三处会**实际破坏 PIT**，挖掘结果不能当作证据。与 EA 无关。

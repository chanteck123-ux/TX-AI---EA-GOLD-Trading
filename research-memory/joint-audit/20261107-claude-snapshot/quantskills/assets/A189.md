# A189 skill-serenity-research-model — Claude 全文审核（2026-11-05）

## P0222 尾段（FILE 1890：README.en；FULL_READ）
- 定位：从**某个具名的公开社交媒体账户**的帖子中逆向提炼"研究逻辑"，流程为 extract → clean → 人工复核 → 自动语义标注 → 前瞻收益评估（1/5/20/60/120 日）→ 报告。是 skill-x-trader-builder 的第一个实例。
- **按用户要求，本审核不引用该账户的昵称或任何真实人物的身份**，只记录方法。
- 初步关注点：
  1. **针对一个具体真实人物做行为画像**：references 中有 `trader_profile.md`（"公开账户画像"），会把公开发言汇总成个人画像，涉及隐私和声誉问题，即便材料是公开的。
  2. 前瞻收益评估以发帖时间为信号时点，需要核实时区处理，以及"发帖时价格是否已经反映"的问题。另外，账户自身的影响力可能本身就推动价格，文档承认"传播本身可能成为催化剂"。
  3. 赢家偏差：只有在采集到失败和撤回的帖子时，"失败观点同等追踪"才能做到，而导出数据可能已被删帖过滤。
- 优点：不核实私人收益，所有公开收益声明都标为"未核实"；区分本人观点与引用；不提供跟单功能。
- 中文 README、references 和 validation 在 P0223 中，待读。

## P0223（FULL_READ；FILES 1891–1903：README（中文）、data_contract、research_template、review_rules、axes、source_boundary、source_notes、trader_profile、tweetclaw_import、SKILL、validation 中的 top200 复核、语义过滤汇总、前瞻研究模型）
- **个人数据说明**：这些文件含有该账户的昵称、主页链接、逐条帖子的 URL、未经核实的自我宣称收益，以及另一个第三方公开仓库的链接。本记录**一律不转录**，只描述方法与统计问题。
- 中英文 README 一致。
- **评估方法问题（关键）**：
  1. **"高质量论点"的标签可能被事后结果污染**：人工复核在 2026-06-10 进行，当时帖子的后续涨跌已经可以看到。自动复核规则就是从这批人工标签学来的（关键词如 photonics、chokepoint、TAM），然后再拿 `keep` 子集的前瞻收益（20 日胜率 76%、60 日平均 +72.9%）来证明"高质量论点更强"。**标签者看过结果，标签本身就有前视**，"高质量组更好"在很大程度上是同义反复。
  2. **样本不独立**：文档承认 Top200 行只来自 10 条帖子，同一只股票会被多次计数（高频股票出现几百次）。2,652 行"高质量"样本的有效独立样本可能只有几十个。
  3. **没有基准或超额收益**：报告的是原始收益，不是相对 SOX、QQQ 或行业基准的超额收益。2026 上半年如果光电板块整体大涨，这些收益主要是**板块 beta**，不是选股能力。
  4. **成交时点**：data_contract 写"取发帖日当天或之后第一个交易日的收盘价"。盘中发帖时，当天收盘价已经包含发帖后的反应（文档承认账户本身会推动小盘股价格）。应改为下一交易日开盘价，或剔除当日反应。
  5. 120 日的高质量样本只有 21 个，文档自己也说"不适合下强结论"。
- 其他：SKILL 自我标注 `status: stable`、`maintainer_type: official`、`validation_level: listed`；文中涉及的 2026 年事件和收益数字**我无法核实**。帖子采集依赖第三方抓取工具，文档要求不导入关注者列表、凭证和私信，这一点做得对。

## A189 结论
- 公开材料加人工复核的信号拆解流程设计得认真（区分引用与本人观点、区分复盘与事前论点、复盘收益不进入前瞻样本）。但**"去污染后的前瞻表现"在统计上不可信**：标签有前视、样本不独立、没有基准、成交时点包含发帖反应。另外，围绕一个具体真实人物建立画像，存在隐私与声誉问题。
- 对 V1.2 没有直接关系。可迁移的教训是：标签或筛选规则如果是在看过结果之后制定的，就不能再用同一批样本来评价它。

## P0224 前段（FULL_READ；FILES 1904–1906：高质量 thesis 写作模板、研究模型 MVP、信号评估汇总）
- 数据来源是**第三方公开 GitHub 仓库整理的该账户全部推文**（5,857 条）。转载和再利用他人发布的内容，以及抓取的合规性，文档都没有讨论。
- 高质量 thesis 的样本来自 685 条唯一推文、2,652 行，说明平均每条推文被拆成约 4 行。证据标签中出现最多的是 `price-volume`（价格和成交量），说明所谓"论点"里有相当一部分是追随价格走势。
- **"写作模板"把具体人物的写作风格做成生成新荐股文章的模板**，可以批量产出同样风格的小盘股推荐文。而文档自己承认"账户影响力会推动小票价格"，所以这个模板有被用来**炒作和推销小盘股**的风险。
- 全量评估只覆盖 30 只高频股票，价格来自 Yahoo 的部分下载，没有基准。

## A189 补充结论
- 方法上的问题（前视标签、样本不独立、没有基准、成交时点）已在上一段列出。额外的风险是：围绕真实个人做画像，以及把其风格做成荐股文章的生成模板。不建议在本项目中引用。

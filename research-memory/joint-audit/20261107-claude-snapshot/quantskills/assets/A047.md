# A047 skill-capital-flow-crowding-monitor（全文审核笔记）
- 读取（P0047）：agents/portable-loader.md——默认离线运行；"绝不编造缺失的资金流观测，要显式报告降级"。其余文件见后续包。
- 续读（P0048）：examples/sample_report.md、README(.en.md, .md)、references/{data-fields, methodology}.md、requirements.txt、SKILL.md。
- 内容：把融资融券（余额变化率的 z）、北向持股（持股比例差分的 z）、大宗交易（机构净承接额取 sign·log10(1+|万元|)，再加折溢价修正）三个来源合成资金强度，计算共识/背离（方向一致度，±0.05 以内视为中性），以及拥挤度的历史分位（相等值计一半，>90% 预警，历史 <20 天标"样本不足"，建议 ≥250 天）。
- 好的做法：
  - **作者实测披露数据现实**：北向个股持股明细自 2024 年 8 月起已停止披露（get_hsgt_hold 返回空），大宗交易对大蓝筹整月为空，实际运行中"三源"往往退化成融资融券单源。
  - 有 `degraded[]` 显式列出降级的数据源；有效源不足时"**不用单源冒充三源共识**"，并降低置信度。
  - 报告同时给出区间累计变化和末日环比，避免只看单日环比造成误读。
- **独立发现**：
  - ①**样例报告用真实股票名称配合合成数字**：案例中写的"贵州茅台""五粮液"，以及"净额 +9320 万""均溢价 +0.76%"等具体数字都来自离线合成样本，而且两只股票都展示成"三源共识"——作者自己说明这在真实数据下基本不可能出现（北向已停披露）。读者容易把合成案例当成真实资金画像。
  - ②**因果叙事未经验证**："北向减仓但两融加杠杆 → 多为散户接盘外资出货"是解读性的断言，文档没有给出任何证据。
  - ③三源等权、对数压缩、±5% 折溢价映射为 ±1 等参数都是人为设定，没有校准依据（作者在局限中承认等权是简化）。
- 对黄金 EA：①**数据源停更或稀疏时必须显式降级**，不能用剩下的单一来源冒充多源共识——对应 NR07/NR08 的多源输入（例如某个宏观数据源停更）；②样例报告用真实标的名称时必须标注"合成数据"。

## 要点
- 市场调整（AR=ret−mkt，默认）与均值调整（估计窗 [−120,−21]）两种模型；CAR 窗 [−1,1]（主）、[−1,0]、[0,1]、[−5,5]、[−10,10]；单样本 t 与二项符号检验；N<20 拒绝、N<50 警告；窗内 AR 缺失 >30% 剔除；事件日非交易日取下一交易日。
- 明确未实现：OLS 市场模型 beta、Fama-French、Boehmer 稳健检验、日历时间组合；重叠事件只提示不聚类；"统计显著≠可交易 α"。
## 独立发现
1. **示例输出应标注为合成数据**：N=55、CAR[−1,1]=2.97%、胜率 94.5%、t=12.98——这种量级明显是演示数据植入的效应；文件未在报告内标注"合成/演示"，容易被误当实证。
2. **公告时点与窗口**：事件日按日期对齐，盘后/晚间发布的公告在 day 0 收益里尚未被市场看到；[0,1] 窗口包含次日开盘跳空，与可交易入场不同。资料只说"统计显著≠可交易 α"，未说明公告时刻对 day 0 定义的影响（与 A058 同类）。
3. **市场代理含样本自身**：缺省用"当日收益面板截面等权均值"作市场收益，样本股票本身计入代理；事件聚集日（财报季）时会把事件效应部分扣掉，CAR 偏向零。
4. **缺失规则口径不一**：事件级"缺失 >30% 才剔除"与"窗口内任一缺失则该窗口 CAR 为 NaN 并剔除"并存，各窗口 N 会不同；示例输出各窗口 N 全为 55，未展示这一情形。
5. 截面 t 检验在财报季事件日期高度聚集时横截面相关严重，资料只对"同股重叠"提示，未提示"同日聚集"（与 A058 的聚类问题相同）。

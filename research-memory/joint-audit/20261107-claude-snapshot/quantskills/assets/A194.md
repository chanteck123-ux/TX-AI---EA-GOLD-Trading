## P0231 后段与 P0232 前段（FULL_READ；FILES 1958–1962：portable-loader、README.en、README、references/profiling-playbook、SKILL）
- 定位：对龙虎榜席位、北向持股、融资余额和大宗交易做描述性画像，并给出"四路资金同向或分歧"的判定。纯文档，`validation_level: documentation`，`status: draft`。中英文 README 内容一致。
- **问题**：
  1. **胜率的入场价含前视**：win_rate_Nd 以上榜当日 T 的收盘价为基准，但龙虎榜在 T 日收盘后才公布，实际最早只能在 T+1 成交。以 T 收盘价为基准，会把 T+1 开盘的跳空算进"胜率"里。
  2. **复权口径错误**：playbook 写"后复权 via `get_stock_daily` adjusted fields"，但 A158 已核实 `get_stock_daily` 是未复权价格，后复权要用 `get_stock_daily_post`。照此执行会把除权缺口算成收益。
  3. 胜率没有对照基准（同期指数或同板块）。上榜股票本身就有强动量和反转特征，不扣基准的胜率没有含义。样本只有 6–12 个月的上榜事件，同一席位样本往往很少。
  4. 合力判定中"≥3 路同向""量级相当"没有阈值。北向 `get_hsgt_hold` 是披露口径，存在滞后（文档已提示），但没有说明合力窗口如何对齐。
  5. 游资别名字典的示例按地名分组（如某地系、某地通道），本身已标注为推断，但容易被当成事实传播。席位名称属于公开的营业部名称，不涉及个人；但如果把"江湖名号"对应到真实个人，就会涉及个人信息。本笔记不转录任何此类名号。
  6. `profiles/seats.json` 作为持久化档案，按 agency 字符串作键。营业部更名或合并后会被分成两条记录，文档没有处理。
- 优点：
  - 边界清楚：不产出因子，不做拥挤度评级；
  - 删除 `side==cum` 行，不让它进入净额计算；

  - 措辞克制；

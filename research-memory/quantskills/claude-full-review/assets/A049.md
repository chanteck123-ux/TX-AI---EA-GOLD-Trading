# A049 skill-cb-analyzer（全文审核笔记）
- 读取（P0049）：agents/portable-loader.md（其余文件见后续包）。
- 要点：
  - 自带 MCP server（mcp_server.py）；示例配置把 `ANTHROPIC_AUTH_TOKEN` 写进 MCP 的 env；
  - **"LLM enabled by default"**——默认对每只转债调用 LLM 分析（付费 API），`--no-llm` 才关闭；
  - "No mock/dry-run mode"——没有离线或模拟运行模式，数据来自 AKShare + Pandadata + LLM API。
- **独立发现**：①默认产生付费 API 调用，且没有 dry-run，安装后直接运行就会消耗额度——本次审核按用户要求**不运行**；②在配置示例中放置 API token 字段，用户容易把真实 token 写进配置文件；③没有离线模式，也就无法离线复现结果。
- 对本项目：与"Python 只做 MCP 监控、不调用付费 API"的边界直接相关——这类 skill 不能直接引入研究环境。
- 续读（P0050）：README(.en.md, .md)、references/{cb-formulas, data-sources, report-template}.md、requirements.txt（全部逐行阅读；中英文 README 内容对应）。
- 内容：全市场约 330 只可转债：21 个信号检测器，按 0.40 估值 + 0.30 条款 + 0.20 联动 + 0.10 结构加权评分，BS Greeks、HV/IV，可选回测（IC、分层、NW t、Fama-MacBeth、**单纯形网格搜索最优权重**、对标中证转债指数、退市追踪），默认对每只转债调用 LLM 做逐券分析。
- 好的做法：
  - 双低值使用 `max(溢价率, 0)`，并解释与集思录口径的差异和理由；
  - 边界情况表完整（YTM 不收敛返回 NaN 并标注来源，IV 没有时间价值时单独标注，各类 floor 都有标记）；
  - 硬编码的阈值列出了代码位置；
  - 单只转债失败时计入 skipped_count 并写入报告；
  - 中文列名统一转成英文，避免 Windows 下 parquet 编码损坏；
  - 措辞禁止"买入"和"目标价"。
- **独立发现（文档层面，未运行）**：
  - ①**价格口径混用的风险**：正股 K 线只有一个来源，就是 Pandadata 的 `get_stock_daily_post`（**后复权**），而强赎触发比 = 正股价 / 转股价、转股价值 = 100/转股价 × 正股收盘价、BS 中 S/K 都要求**未复权**的正股价格与转股价对比。如果 S 取自后复权 K 线，这些比值都会失真（集思录行情里也有正股价，具体用哪一个需要看源码，未核实）。对照 A21/A15 的"涨跌停和比价必须用原始价"。
  - ②**模型设定偏误**：用欧式 BS 给转债的转股期权定价，并据此反推 IV，忽略了强赎、回售、下修等路径依赖条款；票息不读募集说明书，而是**按评级估计的阶梯票息**，评级缺失时默认按 A 级处理（缺失被赋予默认值，而不是 N/A）——YTM 和债底都是模型估计值。
  - ③**缺失当 0**：成交量或成交额获取失败时"显示为 0"，会触发流动性惩罚或让活跃信号失效；配置校验失败只记录非阻塞警告，然后"使用默认值继续"（fail-open）。
  - ④**样本内权重优化**："单纯形网格搜索最优维度权重"之后，回测是否在独立样本上进行没有说明；v1.7 把波动率背离阈值从 10% 下调到 8%、把 Delta 信号改成 Gamma 信号——参数调整没有试验登记。
  - ⑤**阈值不一致**：README 写强赎进度 >1.20 预警、>1.28 高危；cb-formulas 写 ≥1.30 触及强赎、1.20–1.28 预警（1.28–1.30 之间没有定义），§1 还写"CV > 130 触发强赎"。
  - ⑥**ST 规则的跨资产冲突再次出现**：本资产和 A21 都称 2026-07-06 起主板 ST 涨跌幅从 ±5% 改为 ±10%，而 A34（B6）仍按 5%。两份资产独立给出同一说法，可信度提高，但**本次仍未做外部核实**。
  - ⑦营销说法"目前唯一在免费可转债工具中提供完整 BS Greeks"无法核实；"375 个测试"是自述。
  - ⑧默认开启付费 LLM、没有离线模式（见上一包）。
- **A49 逐资产结论**：工程边界处理细致，但定价模型过度简化、价格口径存在风险、缺失值默认化、权重在样本内优化。**源码未读（不在清单内），未运行**；按用户要求不调用付费 API。
- 对黄金 EA：①**比价、触发和保证金计算都必须用原始价格**；②缺失的合约属性（例如保证金率、合约规格）不能用"默认等级"代替，必须标记为 UNKNOWN 并拒绝新单；③配置校验失败不应继续运行（EA 的 OnInit 参数校验失败就应拒绝启动）。

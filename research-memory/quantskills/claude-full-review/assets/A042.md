# A042 skill-buffett-moat-screener（全文审核笔记）
- 读取（P0043）：agents/portable-loader.md、CONTRIBUTING.md、README(.en.md, .md)、references/{api_guide, buffett_methodology}.md、requirements.txt（SKILL.md 见后续包）。
- 内容：A 股和美股的五维连续软评分（ROE 30%、毛利率及稳定性 25%、CapEx/净利润 15%、营业利润率 15%、PE 15%），加上组合复核（最多 8 只、同一已识别行业最多 2 只、等权时最多 1 家银行）。
- **高质量做法（值得借鉴）**：
  - **原子修订**：按 symbol + quarter 选择信号日前最新的"整行"版本，**禁止逐字段跨修订拼值**；同一发布日期有冲突时记录冲突和研究缺口；最新年度缺失时**不得回退到旧年度冒充当前值**。
  - **证据分段且不拼接**：2017 起严格的点时沪深 300；2010–2016 只是固定 18 只名单的诊断（明确有幸存者偏差）；美股是固定研究池（价格收益不含分红）——三段**不得拼成一条曲线**。接口在 2017 年前返回空，就停止或披露缺口，不倒推历史成分。
  - **结构性 N/A 与普通缺失分开**：银行毛利率是 N/A，权重重新分配，不给中性分。
  - **凭证隔离**：凭证只在子进程环境中读取，读取后立即从 os.environ 删除，并阻止 SDK 持久化；日志、HTML 和 Parquet 中都不得出现。
  - **生产写入安全**：按复合主键原子 upsert；旧版本产物只读归档；**失败不覆盖正式文件**。
  - 坦白：旧硬门槛版本的年化更高，但平均只持有 3.4 只且集中于银行；"不得宣称软版普遍优于硬版"。
  - 软评分不取消风险边界：审计否定、归一化利润非正、债务/利润 ≥6 倍、ST 等仍可以阻止新入或触发退出。
  - 新入场的反稀释门槛只限制新入和加仓，**不会因门槛变化强制卖出健康持仓**——新增风险门控与持仓管理分开，与本项目规则同构。
- **独立发现**：
  - ①**覆盖惩罚偏弱**：分数 = 已观测维度的加权平均 × (0.70 + 0.30 × 覆盖率)。如果一家公司只有 PE（权重 15%）可观测，且 PE 得满分，得分为 100 × (0.70 + 0.30 × 0.15) ≈ 74.5，可能高于数据完整但表现中等的公司。缺失虽然没有被填中性分，但"少数维度得高分 + 低覆盖"仍可能排在前面——这是 A002"缺失数据算高分"问题的较弱版本。应该设置最低覆盖门槛，或改用"缺失维度按 0 分计入"的保守口径。
  - ②**统计样本很小**：严格 PIT 区间 2017–2026 是年度信号，大约 9 次调仓，最多 8 只股票；"跑赢沪深 300"的结论统计功效很低（作者已避免泛化，但没有给出显著性）。
  - ③"正常化 EPS = min(最新, 三年中位数)"是保守做法，值得肯定。
- 对黄金 EA：
  - ①**原子修订规则**可以直接用于 NR08 经济日历数据（初值和修正值整行取用，不跨版本拼字段）；
  - ②**分段证据不拼接**——旧 1:100 杠杆报告与 1:1000 新研究、历史 1000 ms 延迟报告与 0–250 ms 报告都应分开呈现，与 AGENTS.md 的要求一致；
  - ③失败时不覆盖正式文件、旧版本只读归档——对应 RiskExecution 的状态持久化；
  - ④"新增风险门控不会强制平掉健康持仓"——与项目规则一致，可作为外部佐证。

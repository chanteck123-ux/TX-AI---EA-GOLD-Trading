# A046 skill-calendar-anomaly-scanner（全文审核笔记）
- 读取（P0047）：agents/{claude-code, codex, openclaw, portable-loader}.md、README(.en.md, .md)、references/{methodology, source_boundary}.md、requirements.txt、SKILL.md（全部文件）。
- 内容：检验星期、月份、月初/月末、turn-of-month（月末加月初前 3 个交易日）等日历效应。每个 bucket 用"bucket 均值 − 其余日期均值"作对比，用虚拟变量回归分别计算经典 t 和 **Newey-West HAC t**，另外报告**移动区块 bootstrap p**；**只用 HAC p 值在所有 bucket 上统一做 BH-FDR**；再检查按时间切成两半后方向是否一致。
- 结论分级：ROBUST_ANOMALY（FDR 显著且两个半样本同向）→ ANOMALY_AFTER_FDR → RAW_ONLY_ANOMALY（原始 |t| ≥ 2 但没有通过 FDR）→ NO_CLEAR_ANOMALY。作者坦白："日历效应在历史上已被大量挖掘，FDR 必要但不充分"；显著不代表扣除成本后可交易。
- 好的做法：拒绝重复日期；工具不绑定数据供应商；demo 用确定性的合成数据；没有网络和凭证依赖。
- **独立发现**：
  - ①**结论分级两处写法不一致**：README 只列了三级（ROBUST → RAW_ONLY → NO_CLEAR），methodology 有四级（多了 ANOMALY_AFTER_FDR）。
  - ②各个 bucket 之间并不独立（turn-of-month 与月末重叠，星期与月份交叉）。BH 在正相关依赖下仍然成立，但文档没有说明这一前提。
  - ③"两个半样本同向"是比较弱的稳健性检查（不要求显著）。
- 对黄金 EA（相关）：XAUUSD 的**时段、星期、月初/月末、美国数据发布日**等效应研究可以直接沿用这套分级（HAC + 区块 bootstrap + BH-FDR + 时间半样本）；任何时段过滤条件必须写明检验了多少个 bucket，并做 FDR 校正——属于研究候选，未登记。

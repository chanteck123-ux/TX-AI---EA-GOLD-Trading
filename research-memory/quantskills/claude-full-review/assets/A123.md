## P0127 部分（FILE 1302 portable-loader、1303 README.en、1304 README 全文）

中英文 README 等价。

要点：
- A 股机构调研热度：
  - 频次（事件数）与广度（不同机构数）分开列示；
  - 机构类型只按原文判定，None 记为"未披露"；
  - 报告字段缺失率，广度只在已披露子集上计算；
  - "被调研 = 关注度，不是背书"。

独立发现：
1. **广度可能被系统性低估**：一次调研往往有几十家机构参与，若 `institute` 字段是一个多机构拼接的字符串，或只记录牵头机构，那么对 institute 去重会把整串当作一家。文档没有说明拆分规则。
2. **右删失（时点）**：调研活动的披露晚于活动日。若按活动日设窗口，最近几天的事件尚未披露，热度会被低估；若按公告日设窗口，则与"活动区间"的说法不一致。文档要求标注"快照日/活动区间"，但没有说明用哪个日期筛选，也没有要求处理最近一段的不完整数据。
3. 在字段稀疏（示例中 participant、institute 均为 None）的情况下，"只在已披露子集上计算广度"会使不同公司之间不可比：披露习惯不同的公司，广度也不同。
4. 定时任务建议"18:00 Asia/Shanghai 之后"运行，以捕捉当日公告——这只是假设，没有说明披露时点。

## P0128 补读（FILE 1305 research-playbook、1306 SKILL.md 全文）

补充与更正：
- playbook 规定 `date` = **公告发布日**，并用作窗口筛选——即按公告日设窗口。P0127 发现 2 修正为：按公告日筛选不存在右删失，但报告文字又称"活动日期/活动区间"，**活动日与公告日两个概念混用**；单票时间线若按公告日排序，与实际调研日之间存在滞后。
- 广度：对拼接字符串"按常见分隔符保守拆分"——P0127 发现 1 部分得到处理；但分隔符规则、机构名称别名（同一机构的全称与简称）没有归一，仍可能重复计数或少计。
- 精确重复行（同一 symbol + date + institute）在计数前去重。
- 类型规则按关键词匹配：
  - "资产管理"同时出现在公募和保险两类信号中，存在歧义；
  - "资本"与"投资管理"会命中大量非私募主体；
  - "英文机构名"判为外资，但内资机构也常使用英文名。
  
  分类可能有系统误差，文档只要求"不匹配时记为未披露"。

# A025 skill-alpha-a06-hotmoney-reversal（全文审核笔记）
- 读取（P0026）：agents/portable-loader.md、README(.md, .en.md)、SKILL.md、开发产物/{references/data_guide.md, SKILL.md}、生产产物/{SKILL.md, 发布验收报告.md}。
- 内容：龙虎榜游资"冷却反转 + 协同突破"因子：factor = (−z(净买入/成交额) − z(ret5) − z(ret10))/3 + 0.25·watch + 3.0·buy。
- 好的做法（与 A22 对比）：
  - **执行口径正确**：t 日收盘后形成信号，t+1 开盘买入，开盘价 ≥ 涨停价×0.999 或停牌则跳过，t+2 收盘卖出。生产文档明确禁止"t+1 close 偷价"口径。
  - 双边成本 0.30%，压力测试 0.50%，另有 1.0% 的信息性测试。
  - 生产读取端不允许重新拉数或重算；新数据发布验收失败时停止新增仓位。
- **独立发现（基于报告数字，未运行）**：
  - ①**样本极小**：3 年只有 31 个原始 buy 信号，可成交 17 笔。"buy 平均净收益 4.02%、胜率 64.71%"建立在 17 笔交易上，最大回撤 −24%。
  - ②**样本外反而强于训练期**（0.55% vs 6.44%），且由 2025 年单年（11.75%）主导；作者承认"2025 年贡献较高"。这更像是体制或偶然，而不是稳定的 alpha；Rank IC 从 0.095（训练）降到 0.038（OOS）。
  - ③**规则手工阈值多**：前 10%、≥1 个重复席位、≥3 个买方席位、≥500 万、净买比 ≥0.55、剔除机构/股通/外资——未披露这些阈值是怎么确定的、试过多少组，存在研究者自由度过拟合的风险。
  - ④`+3.0·buy` 让 factor_value 几乎由二元规则决定，z 分量只起排序作用。
  - ⑤五层**扣成本后全部为负**（L5 = −0.07%），只有稀疏的 buy 子集为正。
  - ⑥"发布结论：通过"——门槛的具体数值没有在 md 中给出（在 json 里，未读到）；用 17 笔交易通过发布门槛，统计上站不住。
- 对黄金 EA：
  - ①可直接对照的执行口径（信号闭柱后，下一根开盘成交，开盘即触及限制则跳过）——与 M5 闭柱确认一致。
  - ②**反例教训**：小样本 + OOS 由单一年份主导 + 多个手工阈值 → 不能晋级；对应我们 §11 的"交易数不等于独立样本"和每轮试验登记。
  - ③"发布验收失败 → 停止新增仓位、已有仓位照常管理"与项目规则一致。

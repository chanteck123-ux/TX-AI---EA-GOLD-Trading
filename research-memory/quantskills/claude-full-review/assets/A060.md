# A060 skill-dl-autoencoder-anomaly
## 阅读范围（P0060 FILE 611–617 全文）
docs/superpowers/plans（实施计划）、docs/superpowers/specs（设计）、docs/verification.md、README.md、references/need_used_api.md、requirements.txt、SKILL.md。scripts/tests 不在清单。
## 要点
- 沪深300每晚扫描：8 维日频特征（ret、log_vol、amplitude、turnover、gap、距涨停、距跌停、excess_ret）×20 日 = 160 维；MLP AE 160→96→48→32→…→160，每次用 T-60…T-1 重训（不存 checkpoint），按 T 日重建 MSE 取 Top-10，per-feature MSE 给出主导特征。
- 防泄露：训练集 `date < T`；z-score 参数只在训练集估计；停牌缺失 >5 日剔除。种子 42。
- 数据：get_factor（OHLCV/turnover/market_cap）+ get_stock_daily_post（pre_close/limit_up/limit_down/trade_status）join；need_used_api 称"两个数据源都是后复权，直接 join 不需要再对齐"。
## 独立发现
1. **"复权跳变"解释与证据不符（关键）**：SKILL.md 记录 20260729 榜单国电电力 ret_T=+318、中国巨石 +18.9、兆易创新 +4.27，并归因于复权跳变。真实除权除息对日收益的影响通常为几个百分点，不可能产生 +31,800%。这种量级只可能来自 close 与 pre_close 处于不同价格基准（如 get_factor 的 close 为未复权、get_stock_daily_post 的 pre_close 为后复权，或反之）——恰与"两源都是后复权、无需对齐"的断言相矛盾。资料本身也记录"get_factor 实际不返回 name 列（文档写有但响应无）"，说明文档化契约与实际返回不一致。v0.2 计划的 `|ret| < 0.11` 过滤只会掩盖拼接错误；同理 gap、amplitude、dist_limit_up/down 都依赖 pre_close/limit 价，均可能被同一基准错配污染，"距涨停恒 ≥0"测试在错配下也不成立。
2. `|ret| < 0.11` 软过滤本身也错：沪深300含创业板/科创板成分，涨跌幅限制 ±20%，真实的 11%–20% 波动会被误删。
3. 窗口口径前后不一：plan 写 get_prev_trade_date n=60、样本 300×40；SKILL.md/spec 写 n=80（60 训练日+20 特征日）。
4. 训练/验证 80/20 随机划分，而同一股票相邻样本的 20 日窗口重叠 19 天，验证集与训练集高度相关，early stopping 的验证 MSE 偏乐观（不影响打分方向，但"val_MSE>0.30 欠拟合"阈值缺乏依据）。
5. 凭证预检脚本输出 `OK: user=$PANDA_DATA_USERNAME`（账号即手机号）进入 agent 记录，与 check_env "不打印凭证" 原则矛盾；且 `source ~/.zshrc` 会执行用户 shell 配置中任意命令；路径硬编码 /Users/since/…。本审查未执行任何命令。
6. "沪深300天然非 ST"不严谨：成分股被 ST 后到下次调样前仍可能在指数内。
7. 可复现性：资料自认 MPS/CPU 浮点差异；Dropout 与设备非确定性使"Top-10 顺序完全一致"只在同设备成立。
## 对黄金EA
- 直接教训：多源数据 join 前必须验证价格基准一致（复权/未复权、点值、时区）；异常值先查拼接错误再找"市场解释"，不能用阈值过滤掩盖。与本项目 MT5/LEAN 跨引擎核对（价格口径、点值）同类。
- 重叠窗口样本做随机验证划分会泄露——与 Codex [216] 重叠窗口重复日期问题同源。

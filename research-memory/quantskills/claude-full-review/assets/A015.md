# A015 agent-ssquant（全文审核笔记）
- 读取（P0019）：AGENTS.md、README(.md, .en.md)、references/core/{api-return-types, project-contract, verification}.md、references/data/{async-history-tasks, cache-and-missing-data, raw-and-adjustment}.md、references/futures/{futures-workflow, rollover-cost}.md、references/live-ctp/{live-guardrails, rollover-and-kline-source}.md、references/reporting/{chinese-report-template, report-debugging}.md。
- 许可：资产包为 GPL-3.0，上游 SSQuant 为 MIT，两者已明确区分（这一点比 A007/A009 写得清楚）。
- **证据门禁**：每类工作都要有可核验产物（环境诊断、py_compile + 策略校验、回测命令及报告路径、数据行数或 SQL、实盘的进程/日志/授权）；"代码应该能跑"、只有配置未启动、其他运行的旧日志都**不算证据**。完成清单：逐项列需求 → 找到对应证据 → 亲自检查 → 未验证项明确写出。与 AGENTS.md 的七状态区分一致。
- **实盘门禁**：查询、SIMNOW、实盘分三档风险；下单或撤单前复述模式、账户、具体合约、动作、开平、手数、类型、价格、超时，再取最终确认；连续合约（888/777）在解析到具体可交易合约并经用户确认前不下单。
- **数据身份** = symbol + period + adjust_type + range/limit；缺数据要有冷却或"服务器无更多数据"标记，防止无限重请求；SQLite WAL 状态下不能只复制主库文件。
- **复权语义**：服务端可能返回原始价、客户端本地复权；策略连续性价格与执行/记账价格可以刻意不同；未直接检查服务器响应前，不能断言服务器发送的是复权价。
- **换月成本**：`auto_roll_enabled`（实盘迁移）与 `backtest_rollover_cost_enabled`（回测成本）是两回事；只依据 real_symbol 判断换月；**盈亏用原始价**以免受复权价污染；默认关闭以保持旧结果可复现。
- **报告**：不隐藏缺数据、交易不足、拒单、不现实成本、报告生成缺陷；对比运行须统一品种、周期、区间、数据模式、成本和基准；必须披露同 bar 信号与成交风险；没有基准就直说。
- 黄金 EA 用途：①证据门禁和"不算证据"清单可直接对照我们的七状态报告；②下单前复述清单与 RiskExecution 的意图日志字段对应（只作参考，不改冻结 v1.0 接口）；③XAUUSD CFD 没有换月问题，但"盈亏用原始价、复权价只用于信号"的原则适用于任何调整过的价格序列。
- 续读（P0020）：skills/ssquant/SKILL.md（兼容入口）。核心规则与 AGENTS.md 一致；另加两条硬边界：**盈利的回测不得自动迁移到 SIMNOW 或实盘，迁移是另一项受门禁控制的任务**；凭证不得出现在策略、报告、截图、提交和聊天摘要中。
- **A15 逐资产结论（全文后）**：规则型资产，没有可运行的源码进入本次阅读范围（scripts/*.py 不在 4524 份文本清单内，或另行记录），所以只有文档审核，没有静态实现核查。主要价值是证据门禁、实盘门禁、复权与执行价分离；期货专属内容（换月、CTP）对黄金 CFD 只作类比参考。

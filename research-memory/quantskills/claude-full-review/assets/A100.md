## P0111 补读（FILE 1087 README.md 全文；1088 references/agent-integration.md；1089–1096 共 8 份"专家框架"文件全文）

**专家文件阅读方式**：8 份文件是 4 个人物框架的中英双语版本，共用同一骨架：角色与边界、核心理念、优先证据、决策框架、风险纪律、分工、降级、输出契约、禁止行为。我逐份全文阅读并对照差异：
- 各份的差异只在 id/显示名/archetype、4–5 条核心理念、优先证据字段、决策问题和 3 条风险规则；
- 中英文对应版本内容等价；
- 公共部分（降级、输出契约、禁止行为）逐字一致。

按项目约定，本笔记**不列出被引用的真实人物姓名**，仅以 archetype 指代：global_macro_risk、systematic_trend_risk、physical_supply_demand、commodity_macro_industry。

要点（README）：
- 证据层级：确定性量化特征 > 期货结构 > 现货与基本面 > 宏观 > 专家框架解释；
- 专家叙事不能覆盖缺失数据；
- 三个趋势视角引用同一条均线信号时，不能当作三份独立证据；
- 至少保留一个风险视角和一个反方情景；
- `confidence` 表示证据质量，不是涨跌概率；
- 实时数据失败时报告不可用，不会悄悄改用历史 CSV。

独立发现（静态阅读）：
5. **以真实人物命名的"专家立场"存在归属风险**：
   - 专家文件要求 LLM 以"基于某真实人物公开思想提炼的视角"输出 `expert: <人物 id>` 和 `stance: bullish/bearish/neutral/wait`，报告中会出现"专家观点"章节；
   - README 与文件都声明"不是真实人物模拟、不代表其观点或背书"，但每个框架**没有列出所依据的公开资料来源**，提炼内容无法核验；
   - 人名与看多/看空立场并列展示，读者仍可能误读为该人物的观点。
6. **安装预置二进制 wheel**：README 指示安装仓库内的 `scripts/vendor/panda_data-0.0.9-py3-none-any.whl`。这是不经包索引的预编译包，属于供应链风险。其版本也与其他资产（0.0.12、≥0.1.0）不一致。
7. **配置路径说法不一致**：
   - 四个运行时说明和 portable-loader 写"`settings.yaml` / `settings/smoke.yaml`"（似在仓库根目录）；
   - README 写 `scripts/skill_futures_investment_council/settings.yaml`。
8. **趋势扫描与同族资产的实测相冲突**：扫描器按均线排列、ADX、20/55 突破、RSI 给"趋势更强"的品种排序，隐含趋势会延续的假设。A097 在中国商品上报告 1–3 月尺度以反转为主（经订正后仍显著），本资产没有引用任何检验来支持其趋势排序。README 说明"是研究候选排序，不是买卖信号"，但没有讨论这一冲突。
9. 多数人物框架偏好的字段（供需平衡、产量、消费、进出口、宏观增长、流动性）不在 README 列出的量化维度中，实际运行时这些维度多半是 `unknown`，框架会按降级规则削弱。设计诚实，但"委员会"的有效视角可能常常只剩趋势与风险两类。

与黄金 EA 的关系：
- 可借鉴：证据层级、"同一信号不重复计票"、`confidence` 与概率分离、缺失即 `unknown`、强制写出反方证据与失效条件。可用于 MCP 监控报告和 Critic 复审格式。
- 不采用：以人物框架为输出单元。本项目不引用、不模拟具体交易员人格。

结论：A100 文本已读至 FILE 1096。SKILL.md、report-format、research-boundaries、feature-contract、expert_router 及其余专家文件在后续 pack 继续补读；脚本**未核查、未运行**。

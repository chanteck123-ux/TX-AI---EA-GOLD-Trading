# A059 skill-dividend-yield-scan

## 要点
- 四接口拼接：get_stock_cash_dividend（div_cash_gross 为每 round_lot 税前现金，每股=÷round_lot，忘除放大10倍）、get_stock_dividend（div_type 区分现金/送转）、get_stock_dividend_amount（预案/实施阶段）、get_stock_split。
- 滚动股息率 = 近12月 ex_date 落窗现金 DPS ÷ 最新收盘；标窗口、价格日、"仅现金不含送转"；预案≠已派；后视非预测；round_lot 缺失不猜10、跳过该股。
## 独立发现
1. **送转/拆分未调整 DPS（关键）**：公式直接把窗口内每股现金相加后除以最新收盘价。若12个月内发生送转（如10转10），送转前的每股派息按旧股本计，而最新价已按新股本除权，股息率会被高估（10转10 时约2倍）。资料只把 get_stock_split 当"背景"，公式未要求用 cum_adj_factor 把 DPS 调整到同一股本口径。
2. "无收盘价时用最近可得收盘"——停牌股会用陈旧价格，股息率失真；只要求标注日期，未要求标停牌。
3. 同一金额会在预案与实施阶段各出现一次（资料已提示），但 payout 计算未明确只取实施阶段，存在重复计数风险。
4. 税前口径：A 股红利税按持有期差别征收，税前股息率高估个人实得收益；资料未提。
5. 连续分红年数"按 ex_date 年或 quarter"两种口径未二选一，中期+年度分红会让年份计数口径不一致。
6. 定时任务"已存在则覆盖重写"，无版本留存。

# A050 skill-commodity-carry-cta（全文审核笔记）
- 读取（P0051）：agents/portable-loader.md、README(.en.md, .md)、references/factor-spec.md、requirements.txt、SKILL.md（source_boundary 为 hash 复用，见 REUSE 行）。
- 内容：跨品种的 carry（年化基差，接口没有年化字段时用 basis_ratio 代理并必须披露）、时序动量、截面动量、基差动量、库存/仓单因子，逐日截面 z 等权合成；头部做多、尾部做空，品种内按反向波动率缩放风险；每次换月扣 roll_cost_bp。
- **好的做法（与 A23、A27 的问题形成对照）**：
  - **主连接续明确写对了**：在每个合约内部计算收益再链接（换月日按比例后复权），并打 roll_flag；新合约在切换前已有行情时，用新合约自己的前收计算换月日收益；缺少前收时换月日收益置零并保留标志，**绝不用新合约价除以旧合约价**——这正是 A23（季节性）和 A27（持仓）没有处理的问题。
  - 库存和仓单按披露滞后做 PIT 对齐；用风险缩放避免过配不流动的品种。
  - 作者实测并记录了接口参数的差异（哪些接口用 underlying_symbol，哪些用 symbol）。
- **独立发现**：
  - ①**验证结论过度**：README 的"真实数据测试结论"只基于一周的沪铜基差字段解析，加上一个 toy 面板的回测（Sharpe 0.61、年化 14.6%、MDD −11%），就得出"数据链路真实可用，代码可靠"——toy 回测数字与"真实数据验证"写在同一段，容易让人误以为是真实回测结果。
  - ②carry 用 basis_ratio 代理（不是年化值），不同到期期限的品种之间不可直接比较，作为截面排序会有偏差（作者要求披露，但没有给出修正方法）。
  - ③换月成本只是一个 bp 桩，作者承认实际应按近远月价差加手续费估算。
- 对黄金 EA：①**如果用 GC 期货连续合约做研究或跨引擎核对，必须采用这里的"合约内算收益再链接"规则**（XAUUSD CFD 本身没有换月，但有隔夜 swap 的成本，需要在回测中单独计入）；②验证报告要把 toy 结果和真实数据结果分开。

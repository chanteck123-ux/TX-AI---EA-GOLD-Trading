# A027 skill-alpha-f1-position-change（全文审核笔记）
- 读取（P0030）：README(.en.md, .md)、references/data_guide.md、requirements.txt。
- 内容：期货前 20 席位多空持仓变化率因子。factor = 多头变化率 − 空头变化率；变化率 ≥ 2% 或 ≤ −2% 时给 buy/sell 信号；z 值经 logistic 映射为 score；当日品种数 N < 5 时降级为 hold。评估口径：forward_return = close(t+1)/open(t+1) − 1（t 日收盘后出信号，t+1 开盘入场，当日收盘平仓）。
- 好的做法：11 条因子契约断言；无效代码被 SDK 静默跳过时，本 Skill 主动报错；CI 可离线运行；14 轮修复记录公开（第 1 轮就修了"IC 自相关 / 回测无价格 / alpha 0 证据 / 阈值不一致"）；自述不做 walk-forward。
- **独立发现（文档层面，未运行）**：
  - ①**信号规则存在冲突**：buy 条件是"多头 ≥ +2% **或** 空头 ≤ −2%"，sell 条件是"多头 ≤ −2% **或** 空头 ≥ +2%"。多空同时增仓（例如都 +3%）时两个条件同时成立，文档没有给出优先级。
  - ②**前 20 席位的成员每天会变**：Σ前 20 名持仓的日变化，混入了"谁进入或退出前 20"造成的成分变化，而不只是同一批席位的增减仓。
  - ③**主力合约换月**：持仓按品种的主力合约统计；主力切换当天，持仓总和会因合约切换跳变，产生伪信号。文档要求"换月规则不明确时先咨询"，但没有给出处理方法。
  - ④前一日持仓为 0 时变化率设为 0——缺失被当作"无变化"。
  - ⑤IC 稳定性只检查"前后半段同号且 |IC| > 0.02"，是很弱的门槛；默认窗口只有最近 90 天。
  - ⑥中国期货有夜盘：t 日"收盘后"出信号、t+1"开盘"成交——日线的 open 通常是前一晚夜盘的开盘价，而持仓排名数据一般在日盘收盘后公布，可能赶得上，但作者没有核实（文档也提到 update_time 硬编码为 15:30）。
- validation 徽章写"L2 contract-checked"（自评）。**未做静态实现核查，未运行**。
- 对黄金 EA：COT（CFTC 持仓报告）是黄金最接近的类比——①成员或口径变化会被误当成持仓变化；②COT 按周二数据、周五才发布，**可得时点必须按发布时间而不是数据日期**（对照 A19 的 T+1 规则）；③信号规则必须写清优先级。属于 NR07/NR08 的候选考虑项，未登记。
- 续读（P0031）：SKILL.md。补充：
  - 硬性要求写得正确：不许偷价（t 日收盘后才知道的信号不能按 t 日收盘价成交）；forward_return 必须从 t+1 开始取，避免与持仓自相关形成伪 IC；必须用 get_future_daily 的真实价格，不得用持仓差分作代理；作者明确提醒持仓数据收盘后才发布。
  - **文档不一致**：SKILL.md 写"check_factor_contract（10 条契约断言）"，README 写 11 条；SKILL.md 称 validate"含样本外 IC 稳定性检验"，而 README 说"不进行样本外 walk-forward，仅前后半段 IC 同号"——把前后半段同号称为"样本外"属于夸大。

## P0061 补读（FILE 619–628 全文）：CHANGELOG、INSTALL、README.en、README、references/data_guide、methodology、need_used_api、source_boundary、requirements、requirements-dev
### 要点
- 15 个 panda_data 接口；特征最终 298 维（价量 20×14=280 + 基本面7 + 情绪3 + 宏观4 + 关系4；CHANGELOG 写"28 维/日"、portable-loader 写"32 特征"，口径不一）。
- 训练：GATs_ts（2层GRU→4头GAT→MLP）、MF-IAMGCN；Adam；EarlyStopping patience=20；梯度裁剪；Winsorize 1/99 与 z-score 只用训练集。回测：T 日预测，T+1 开盘进、T+2 开盘出，等权日调仓，佣金0.03%、卖出印花税0.1%、滑点0.1%，涨跌停限制。
- Fail-closed：推断时 NaN 特征剔除股票；API 失败中止。凭证加载后从进程环境删除。
### 独立发现
1. **"按股票划分训练/验证可防止时间泄露"是错误表述**：按股票划分意味着训练与验证共享同一批日期，全市场同日冲击在两边同时出现；GNN 的消息传递还会把验证节点的特征经图边传给训练节点（直推式设置）。这不是时间外样本，验证损失和 early stopping 都偏乐观。正确做法是按时间切分（并留出标签期间隔）。
2. **标签期未在 `date<T` 规则内**：资料只保证"特征日期 <T"。若训练标签是 T+1 开盘→T+2 开盘（与回测一致），则 T-1、T-2 日样本的标签需要 T 及以后的价格，在 T 日收盘扫描时尚不可得。文档未给标签定义与截断（purge）规则，无法确认；脚本不在清单。与 Codex [147]/[216] 讨论的标签窗口重叠同类。
3. **PIT 声明自相矛盾**：methodology 称基本面"每个日期只用当时已公告版本"；source_boundary 却承认"API 返回最新可得数据（如重述财报）、行情未做版本快照"。宏观"从最新发布日前向填充"，但同生态 A56 已确认宏观接口只有 period_date、没有发布日——发布日从何而来未说明，存在前视。
4. **图结构前视**：概念板块成分与申万行业映射来自当前接口（get_concept_constituents/get_stock_industry 无日期参数），概念常在题材上涨后才设立或纳入成分，用当前成分构建历史图边会把事后分类带入训练——与 A26/A34 概念 in_date 问题同类且更严重（这里连 in_date 都没有）。前十大股东共持边按季报发布滞后，文档未要求公告日对齐。
5. 自相矛盾：CHANGELOG 称"纯 PyTorch，无 torch_geometric 依赖"，requirements.txt 却要求 torch_geometric>=2.5；methodology "train_days 为日历日，默认 252 个交易日"；epochs 默认 100（INSTALL）vs 示例 10、patience=20——epochs=10 时早停永不触发；README 免责称"不感知涨跌停、停牌、滑点"，同文件又称回测已模拟涨跌停与滑点。
6. 停牌 ≤5 日前向填充价格→该期收益为 0，回测若允许在填充日成交则不现实；文档未说明回测是否禁止停牌成交。
7. "文献报告相对沪深300年化超额 +28.9%"为引用他人结果，非本实现证据；"验收状态"全是工程项（测试通过、可复现），无样本外收益证据——与 A62 ADR-0003"工程完成≠alpha证据"正好形成对照。
8. 日频等权调仓 + 单边约 0.13%–0.23% 成本，换手成本可能吞掉信号；文档未报告成本前后对比。

# A021 skill-a-share-tradability-auditor（全文审核笔记）
- 读取（P0022）：agents/portable-loader.md、README.en.md（其余文件见后续包）。
- 内容：用 A 股的执行现实回放回测成交日志，把账面盈亏拆成**可执行盈亏**和**幻影盈亏**，逐笔给出证据。
- **高价值规则**：
  - `fill_ratio = min(库存比例, 市场比例, 参与率比例)`——取**最小值而不是乘积**，因为三层并不独立，相乘会低估成交。
  - 覆盖率低于 `--min-coverage` 时返回 `insufficient-evidence`："没发现问题"和"没能检查"绝不能混为一谈（与 A18 的 UNKNOWN≠低风险是同一原则）。
  - 引擎缺陷类计数（T+1 违规、无库存卖出、成交价超出涨跌停带）**非零就先修引擎，再谈收益**。
  - 涨跌停带**按 bar 日期取当时的规则**，而不是按今天的规则（`BOARD_RULE_HISTORY` 生效日表）。资料称：主板 ST 股 ±5% 于 2026-07-06 起改为 ±10%（依据 2026-04-24 发布的修订版《交易规则》）。**这是资料陈述，未独立核实。**
  - 拒绝复权价：涨跌停价 = pre_close × (1 ± pct)，在复权序列上计算会出错而且不会报错。
  - 从空仓开始回放：有初始持仓的策略必须先补开仓买入，否则第一笔卖出会被误报为裸卖空。
  - 先剔除幻影盈亏，再做显著性检验（否则 Deflated Sharpe 折扣的是错误的分子）。
  - 日线状态机只是**乐观上界**，无法模拟排队位置和封板强度。
  - 资料称有 42 个单元测试和端到端冒烟测试（validation/README.md 待读）。
- 对黄金 EA（高相关）：
  - ①"规则按 bar 日期取历史版本"→ GOLD 的保证金、合约规格、交易时段、杠杆（1:100→1:1000）在回测中都应按日期生效，不能用今天的规格回放历史。
  - ②"可执行盈亏 vs 账面盈亏"→ 可对照我们的 0–250 ms 延迟、点差和 stop level 压力测试：把因延迟或冻结距离无法成交的部分单列。
  - ③"引擎缺陷计数非零先修引擎"→ 对应 RiskExecution 的对账测试（例如成交价超出当时 bid/ask 区间）。
  - ④"insufficient-evidence"状态 → 对应七状态里的"未执行"。
  - 以上只是研究候选，**不改冻结 v1.0 接口**。
- 续读（P0023）：README.md、references/{boundary, data-map, limit-rules, methodology, output-schema}.md、requirements.txt、SKILL.md。
- 补充规则：
  - 状态判定优先级：覆盖率 < min_coverage → insufficient-evidence；有 critical → fail；phantom > fail_decay → fail；有 high/medium/low → warning；无发现 → pass（pass 只表示已执行的检查无发现）。
  - critical 和 high 必须附可定位证据，否则 validate_audit 判契约违规；`limitations` 和 `next_actions` 不得为空。
  - 同日先卖后买的重放规则写在 assumptions.intraday_order 中；同样的输入必须得到逐字节相同的报告。
  - 涨跌停价用 Decimal 和 ROUND_HALF_UP 算到 0.01，避免浮点数在 .005 边界取整出错。
  - 新股窗口只在提供 list_date 时生效（避免第一天把整个股票池误标）。
  - 参与率是情景参数，至少给两组取值做敏感性分析。
  - 顺延重估本身有偏差，所以顺延后的曲线仍是上界。
  - 盘后固定价格交易（资料称 2026-07-06 扩展到全 A 股，未核实）会让 H1/H2 判定偏保守。

# A114 skill-hk-us-dividend-events — 文本审核

阅读范围：**全文**——FILE 1248 portable-loader、1249 README.en、1250 README（与英文版等价）、1251 dividend-guide、1252 pandadata-map。

要点：
- 港股、美股分红日历，包括未来 30/60/90 日除息、近期派息、按币种分池的 TTM 股息率榜，以及 DRIP 算术示意；
- 不外推，不年化单次分红；
- 币种不同时不计算合并收益率；
- 降级规则清楚。

独立发现：
1. **`excute_date` 的语义不确定**：指南用它"判断未来除息/执行日期"。但对分红来说，除息日（ex-date）、登记日、派付日是不同的日期，"执行日"可能指派付日。若实为派付日，"即将除息"日历会系统性偏晚。文档没有要求核实这个字段的真实含义。
2. **收益率分母前后矛盾**：
   - pandadata-map："取**除息日或邻近交易日**收盘价"作为 TTM 收益率分母；
   - dividend-guide："对应币种价格分母"，未指明日期；
   - 常规的 TTM 股息率使用当前价格。用除息日价格（每次分红可能不同）作分母会混合多个时点。
3. **拆股未调整**：TTM 每股分红直接按事件累加。若 12 个月内拆股，拆股前的每股分红没有复权，与当前价格（拆股后）相比会高估收益率。文档没有提到拆股调整（与 A113 发现 2 同类）。
4. TTM 窗口按 publish_date 还是 excute_date 划定，没有说明；跨窗口边界的分红是否计入，口径不明。
5. validate_report 只检查章节、来源、免责声明等格式。scripts 与 SKILL.md 不在本 pack 中，需在后续 pack 中确认。

与黄金 EA 的关系：无（XAUUSD 没有分红）。

待续：SKILL.md 在后续 pack 中读取（若在 manifest 中）。

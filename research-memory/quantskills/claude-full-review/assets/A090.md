独立发现（静态阅读，代码片段推导）：
1. **复盘以验证段爬山为成绩，却不讨论验证段过拟合**：
   - 示例"分数 +0.05 → +0.63（67 轮）"正是 val 段反复选择的累积结果；
   - 文档要求"永远以 val 段评分为准"；"距离主分上限还有空间，无需立即 phase transition"会鼓励继续在 val 上搜索；
   - test 段被一律禁止，却没有任何"在什么条件下由人类调用 judge 做一次 test 评估"的指引；
   - 也没有把累计试验数（67 轮）折算为对 val 分数的选择偏差打折。
   
   这是 A084 发现 3 在复盘层面的延续。
2. **因子族关键词分类有确定的误判（代码片段推导）**：
   - `classify_factor` 按字典顺序做子串匹配，"波动率"族关键词含 `vol_`，排在"量能分布"之前。`neg_vol_cv_120` 会被归为"波动率"，与 report-template 和 structural-analysis 示例表中"量能分布"的归类相矛盾。
   - `ep`、`sp`、`bp` 作为子串会误配大量名称（如含 "rep""step""spread" 的名称）；
   - `size` 被归为"流动性"，规模与流动性是不同的族。
   
   族覆盖统计因此不可靠。
3. **状态标签不一致**：代码统计 `status == "CRASH"`，正文与模板写 "CRASHED"。若日志用 CRASHED，CRASH 率会被算成 0。
4. 相关性矩阵计算方法与 A084 相同（逐日秩展平后求 Pearson），同样有池化口径问题。
5. "接受率 >60% 是在挑软柿子"、"平均 |ρ| 0.30/0.50"等阈值属经验判断。
6. 优点：
   - REJECTED 和 CRASH 也视为研究信号；
   - 假设必须引用 Layer 2 发现并给出预期区间；

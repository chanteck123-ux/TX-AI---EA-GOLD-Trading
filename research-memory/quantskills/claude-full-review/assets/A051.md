# A051 skill-concept-rotation-monitor（全文审核笔记）
- 读取（P0051）：agents/portable-loader.md、README.en.md（其余文件见后续包）。
- 内容：从成分股收益**自下而上**构造概念动量（默认等权中位数）和广度（上涨占比），轮动信号 = 短窗动量 − 长窗动量；检测新概念。
- 好的做法：**调用 get_concept_constituents 时传入 date= 取快照日的成分**，避免用今天的成分回看历史（比 A26/A34 只按 in_date 过滤更完整）；明确说明不存在官方概念指数；提示概念之间重叠、不可加总；新概念历史太短要标注。
- 续读（P0052）：README.md、references/concept-rotation-playbook.md、SKILL.md。
- 补充：成分数设下限（例如 ≥5），小概念单列；成分缺数据就剔除并报告剔除数，剩余太少时标"样本不足"；快照日不可用时退到最近的可用快照并注明，**绝不静默改用今天的成分**；新概念单独一节，不与成熟概念同榜。
- **独立发现**：
  - ①**快照日选在窗口末端，仍有选择偏差**：playbook 要求"成分快照日与收益窗口的**终点**一致"。但概念成分常常是**在股票上涨之后**才被纳入（题材炒作后才"加入概念"）。用窗口终点的成分计算窗口内收益，会把窗口内因上涨而新纳入的股票也算进去，动量被高估。严格做法是用窗口**起点**的成分，或至少分开报告"窗口内新纳入的成分"的贡献。
  - ②**收益用的是 get_stock_daily 的收盘价**（未复权）：`r_i = close_t/close_{t−W} − 1`，跨越除权除息日时会把分红送转误算为下跌（对照 A52：复权一致性）。
- **A51 逐资产结论**：时点意识强（快照日、新概念单列、重叠不可加总），但窗口内纳入偏差和未复权收益两点会系统性扭曲动量。validate_report.py 不在清单内，**未做静态核查，未运行**。
- 对黄金 EA：领域无关；通用教训是"**成员资格要取窗口起点的时点**"，例如用于跨市场对照的成分篮子。

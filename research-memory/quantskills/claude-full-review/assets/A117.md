独立发现（静态核查确认，**未运行**）：
1. **百分比标度判断是全列一次性决定，十分脆弱**：
   - 127 行：只要整列（整个市场所有股票）的最大绝对值 ≤ 1，就整体乘以 100；
   - 若源数据为 0–1 标度，只要有一个异常值 > 1（例如重复计数造成 1.05），整列都不会转换；
   - 结果是所有正常值被当作 0–100 中的 0.x%，largest_holder < 20、HHI 极小，全部股票被判为 fragmented 或 broad——系统性误分类，而且该异常行本身也不一定被标为 anomaly。
   
   应按行或按字段语义确定标度。
2. **HHI 只用前 `max_rank` 名股东计算**（默认 20，见 25、240 行），属于截断 HHI（下界），并且依赖各股票返回的排名深度。dominance 阈值（HHI ≥ 0.10）在不同深度的股票之间不完全可比。
3. **分类阈值**为 largest ≥ 20% 或 HHI ≥ 0.10 判为 dominant；concentration ≥ 50% 且两者都低判为 broad（262–270 行）。SKILL 要求"至少两种阈值做敏感性测试"，但脚本中阈值写死，没有参数化（grep 无相应 CLI 参数）。敏感性测试需要改代码。
4. **超过 100% 一律视为异常**：美国机构持股合计超过 100% 是已知的真实现象（融券再出借、13F 重复申报）。把它们都列为不可排名的 data_anomaly，会系统性剔除高融券股票。这种设计偏保守，但会造成样本偏差。
5. **13F 的 45 天滞后**是法定最晚期限，作为"保守"可得日基本合理；但 13F/A 修正申报更晚，未处理。港股（SFC 权益披露）的滞后由"其他申报类型"规则处理，具体口径未说明。
6. 仓库提交了全样本股东排名明细（16.3 万行，含股东名称，可能包括个人），且**没有许可证**。数据再分发与隐私问题与 A115 同类。
7. SKILL 中"至少 30 秒分析"的代理指令与 A115 相同，判断为同一作者的模板。

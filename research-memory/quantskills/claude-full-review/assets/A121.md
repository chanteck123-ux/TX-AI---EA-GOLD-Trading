# A121 skill-index-rebalance-event-study — 文本审核

## P0126 部分（FILE 1289 portable-loader、1290 README.en、1291 README、1292 methodology、1294 pandadata-integration 全文）

要点：
- 指数纳入、剔除及权重调整的描述性事件研究，在公告日与生效日分别设锚点，计算 AR/CAR 与成交量比；
- 明确不做统计推断，也不控制事件重叠；
- 不得把首次观测日冒充公告日；
- 数据不足时返回 insufficient-evidence。

独立发现：
1. **权重快照差分会把价格漂移识别为"权重变化"**：
   - `get_index_weights` 相邻日期的 weight 差分 → add/delete/weight_change；
   - 但市值加权指数的成分权重每天都会随价格变化，相邻快照几乎总有差异；
   - 没有阈值或"去除价格贡献"的规则时，weight_change 事件会几乎每天触发，与真正的指数调整混在一起；
   - 正确做法：用 weight(t) 对比 weight(t−1) × (1+r_i)/(1+r_index) 的残差，或使用官方调整公告。
2. 纳入/剔除事件的时点用的是"首次出现/消失的快照日期"，即生效日附近，而非公告日。文档已承认需要补充公告；但若用户只用 PandaData 运行，公告日锚点实际上不可用。
3. AR = return − benchmark_return 是简单的市场调整模型，未做 beta 调整。纳入股票往往 beta 偏高，会混入市场因素。由于定位是描述性研究，问题不大，但应写入 limitations。
4. 引用的外部方法文档（S&P 指数数学、Nasdaq-100 调整）只作为参考链接，**未核实**内容。

## Core trading framework implied by the recap material

A complete GSM decision is not based on one indicator or one pattern. The technical material is organized around:

`Market context -> structure -> location/zone -> confirmation -> execution -> risk/management`

The exact implementation differs by Scalping, Intraday and Swing and must be documented in each engine's specific SOP when finalized.

## Discipline / review loop

The GSM classroom slides also emphasize:

- System over impulse.
- Loss is part of trading cost.
- No valid setup -> no forced trade.
- Keep records and review them.
- Continuously optimize logic using evidence.

For the EA project this maps to:

`SOP -> Candidate -> Compile -> Real Tick -> Audit -> Champion comparison -> Keep/Reject`

## Important separation from GitHub Research

This GSM curriculum is the project's source doctrine.

GitHub repositories are external research material. They may suggest better implementations or optional Candidate modules, but they are not allowed to redefine the GSM source doctrine automatically.
